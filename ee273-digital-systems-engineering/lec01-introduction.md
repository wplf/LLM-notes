## 1.2 什么是数字系统工程

系统级的电气设计，四件事：

| 主题 | 要解决的问题 |
|---|---|
| 噪声管理 | 让信号保持干净 |
| 信号传输 | 把比特从这里送到那里 |
| 时序 | 怎么知道新的一位到了 |
| 电源分配 | 用直流电压供应交流电流 |

## 1.3 为什么重要

- **时钟更快**：导线变成传输线；偏斜和抖动占掉时钟周期的很大一部分；很多电缆比一个时钟周期还"长"。
- **电压更低**：同样功率下电流更大，裕量更小。
- **引脚是瓶颈**：每个信号都得物尽其用。
- 这些问题不再只属于超级计算机；做不对系统就不工作；照"菜谱"做不够，需要分析。

## 1.4 这门课教什么

- 理解现象 → 建立可用于仿真和分析的工程模型 → 提出并评估方案。
- 让系统第一次就可靠工作：**噪声预算**和**时序预算**。
- 在需要的地方把性能推到极限：信号速率、同步延迟与失效概率、电源分配。

## 1.5 眼图：同时看噪声、信号和时序

- 把很多位的波形叠在一起，"1"和"0"之间的空白就是**眼**。
- 眼高 $V_e$ 受电压噪声压缩，眼宽 $t_e$ 受时序噪声压缩，两者同时存在时眼更小。
- 后面所有内容都可以看成在想办法把眼睁大。

## 1.6 一个噪声计算的例子

250 mV 差分信号（差分摆幅 500 mV），求误码率：

| 项目 | 比例 | 数值 (mV) |
|---|---|---|
| 差分摆幅 | | 500 |
| 毛裕量（摆幅的一半） | | 250 |
| 相邻线串扰 | 5% | 25 |
| 反射造成的码间干扰 | 5% | 25 |
| 高频衰减 | 15% | 75 |
| 比例噪声合计 $K_N$ | 25% | 125 |
| 接收器失调 + 灵敏度 | | 20 |
| 有界噪声合计 | | 145 |
| **净裕量** | | **105** |
| 高斯噪声（RMS） | | 10 |
| 电压信噪比 VSNR = 105/10 | | 10.5 |

## 1.7 信号传输要回答的四个问题

1. 符号怎么表示？例："0" = −2.5 mA，"1" = +2.5 mA。
2. 线的两端怎么端接？例：两端都接 $Z_0$。
3. 参考怎么产生？例：差分信号，自带参考。
4. 接收器怎么检测？例：检测端接电阻上的电压。

## 1.8 时序与同步

- 问题：怎么判断一个符号何时有效、新符号何时到达？
- **同步时序**：所有触发器由一个时钟驱动（每芯片约 10⁵ 个、系统约 10⁷ 个），导线可能长于一个周期，偏斜是大问题。
- 其他方式：流水线时序、自定时设计、多时钟域（跨域信号必须同步）。

## 1.9 电源分配

思考题：100 颗 20 A 的芯片（共 2 kA），400 MHz 时钟（$t_{ck}$ = 2.5 ns），电流可能在一个周期内降到零。

- $di/dt = 2\,\text{kA}/2.5\,\text{ns} = 8\times10^{11}$ A/s（笔者计算）。
- 电源路径上串 1 nH 电感，压降 $L\,di/dt = 800$ V（笔者计算），显然不可接受。
- 怎么解决是第 14、15 讲的内容（分级旁路电容、本地稳压）。

## 1.10 导线是传输线：三条规则

1. 波沿线向两个方向传播。
2. 除非端接匹配，波会反射。
3. 线上电压是这些波的叠加。

反射系数：

$$k_r = \frac{Z_T - Z_0}{Z_T + Z_0}$$

| 端接 | $k_r$ | 现象 |
|---|---|---|
| $Z_T = Z_0$ | 0 | 无反射 |
| 开路 | +1 | 全正反射，末端电压加倍 |
| 短路 | −1 | 全负反射 |
| 450 Ω 接 50 Ω 线 | 0.8 | 大部分反射 |

## 1.11 网格图（Lattice Diagram）

例：450 Ω 源阻抗驱动 50 Ω、5 ns 的线，远端开路，输入 1 V 阶跃。

- 入射波幅度 $1\,\text{V}\times 50/(450+50) = 0.1$ V。
- 远端 $k_{rB}=1$，近端 $k_{rA}=0.8$，波在两端之间来回反射，每来回一次幅度乘 0.8。
- 远端电压依次为 0.2、0.36、0.488、… V，呈阶梯状慢慢爬向 1 V。
