# 第 3 讲 导线（续）：多点总线、平衡线与测量

> 2001-01-22 · [原讲义 PDF](http://cva.stanford.edu/classes/ee273/Previous_273/2001/ee273_2001_handouts/L03_012201.pdf) · 课后阅读：6.1–6.3

## 3.1 概览

- **多点总线**：支线和不连续点，频率受限。
- **平衡线**：共模与差模激励，奇模与偶模阻抗。
- **导线建模**：抓住相关的电气特性，忽略无关的，取决于上升时间。
- **时域反射计（TDR）**：示波器加脉冲发生器，以及怎么读结果。

## 3.2 多点总线

总线上每个模块带来三个问题：支线（stub）、阻抗不连续、附加负载降低等效阻抗和速度。

典型例子：

| 参数 | 数值 |
|---|---|
| PCB 走线 | 50 Ω，C = 100 pF/m，L = 300 nH/m |
| 支线 | 长 10 cm（0.7 ns），末端 20 pF 负载 |
| 模块间距 | 3 cm |

- 约束：上升时间必须远大于支线延迟（> 3 ns）和间距延迟（> 1 ns）。
- 每 3 cm 挂 30 pF，等效电容升到 1100 pF/m，于是 $Z = 16.5$ Ω，$v = 5.5\times10^7$ m/s。
- 驱动器朝两个方向看，实际负载是 8.25 Ω。

结论：

- 总线速度由几何形状（支线长度和间距）决定。
- 拔掉一个模块就产生一个不连续点。
- 点对点传输在电气上干净得多，而且允许并发传输。
- **对总线"说不"**；非用不可就把支线"折叠"起来（缩到最短）。

## 3.3 平衡传输线

- 所有传输线的回流路径都有电感，会让回流端电压沿线偏移。
- 平衡线的回流电感等于信号电感。给平衡线加 1 V 阶跃：信号电感上降 0.5 V，回流电感上降 0.5 V。
- 记住：只能把**一个点**叫做地。

## 3.4 耦合线模型

两根耦合线（例如两层地平面之间的一对带状线）：

- $M$ 和 $C_d$：两根线之间的耦合（互感、线间电容）。
- $L$ 和 $C_c$：每根线对其他导体的自感和电容。

## 3.5 共模与差模激励

任何激励都可以分解为差模信号和共模信号的叠加。例：一根线上 1 V 阶跃、另一根不动，等于 $V_c = 0.5$ V 加 $V_d = \pm 0.5$ V。

## 3.6 奇模与偶模阻抗

共模和差模信号看到的阻抗不同：

$$Z_E = \sqrt{\frac{L+M}{C_c}},\qquad Z_O = \sqrt{\frac{L-M}{C_c + 2C_d}}$$

（偶模时两线同向变化，线间电容不起作用、互感相加；奇模时线间电压加倍、互感相减。）

| 名称 | 定义 |
|---|---|
| 偶模阻抗 $Z_E$ | 共模信号在**每根线**上看到的阻抗 |
| 奇模阻抗 $Z_O$ | 差模信号在**每根线**上看到的阻抗 |
| 差分阻抗 $Z_D = 2Z_O$ | 差模信号在**两线之间**看到的阻抗 |
| 共模阻抗 $Z_C = Z_E/2$ | 共模信号在**线对与公共回流之间**看到的阻抗 |

线间距越小，$Z_E$ 和 $Z_O$ 分得越开；间距大时两者都趋于单线阻抗。

## 3.7 同时端接奇模和偶模

问题：$Z_O = 50$ Ω、$Z_E = 100$ Ω 的线对上来一个 1 V 阶跃，怎么端接才没有反射？只匹配一种模式会造成**模式耦合**。

用 π 形网络：每根线对地接 $R_1$，两线之间接 $R_2$：

$$R_1 = Z_E,\qquad R_2 = \frac{2Z_E Z_O}{Z_E - Z_O},\qquad Z_O = R_1 \parallel \frac{R_2}{2}$$

本例 $R_1 = 100$ Ω，$R_2 = 200$ Ω（笔者计算）。

## 3.8 导线建模

- 真实系统的信号路径：芯片 → 封装 → PCB → 连接器 → 背板。
- 模型要能用于手算和 SPICE，必须抓住传输线特性、主要的不连续点和端接，忽略不相关的（如很短的不连续）。
- **好模型在抓住相关行为的前提下尽量简单。**

示例模型：50 Ω 源 → 封装（3 nH、1 pF）→ PCB（45 Ω、1 ns，0.5 pF）→ 连接器（55 Ω、1 ns，1 pF、5 nH、1 pF）→ 背板（50 Ω、1 ns）。

模型从哪来：手算、厂商提供的元件/连接器/封装模型、CAD 工具、对实际系统的测量。

## 3.9 时域反射计（TDR）

- 快速阶跃发生器（通常 20 ps 边沿）加高速示波器。
- 向被测线注入阶跃，观察反射回来的波形。

**由电压算阻抗**（1 V 源经 $Z_0$ 驱动）：

$$V = \frac{Z}{Z + Z_0}\quad\Rightarrow\quad Z = Z_0\frac{V}{1 - V}$$

**观察时间是往返时间**：$t$ 时刻看到的是距离 $x = vt/2$ 处的阻抗。

**电感和电容**：

- 串联电感 → 向上的凸起，时间常数 $\tau = L/(2Z_0)$。
- 并联电容 → 向下的凹陷，时间常数 $\tau = Z_0 C/2$。

## 3.10 上升时间退化

- 上游的 L、C 对信号做低通，边沿变缓。
- 这会影响下游元件的反射：边沿变慢、响应被展宽（与慢边沿卷积）、L/C 的响应达不到满幅。
- 后果：难以精确提取 L、C 值，测不到很小的不连续。
- 但是：**TDR 看不见的，信号也看不见。**

## 3.11 提取流程

1. 把 TDR 曲线分段：平坦段是传输线，上凸是电感，下凹是电容。
2. 从源端开始，确定最近一个元件的 $Z$ 和延迟（或 L、C）。
3. 仿真验证，并得到新的上升时间；必要时迭代。
4. 再处理下一个元件。

模型的分辨率不需要比你最快的上升时间更高。讲义给了同一条线分别用 20 ps 和 200 ps 边沿测得的波形对比：慢边沿下很多细节消失。
