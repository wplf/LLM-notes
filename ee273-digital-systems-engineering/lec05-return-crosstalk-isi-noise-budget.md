# 第 5 讲 回流串扰、码间干扰与噪声管理

> 2001-01-29 · [原讲义 PDF](http://cva.stanford.edu/classes/ee273/Previous_273/2001/ee273_2001_handouts/L5_102901.PDF) · 课后阅读：7.1、7.3

## 5.1 概览

- **信号回流串扰**：共用回流线上的电流造成信号间干扰；大量信号同时翻转时噪声可观。
- **码间干扰（ISI）**：传输系统"记得"历史，之前的位留下的残余状态会扭曲当前位。
- **噪声管理**：按两个轴划分噪声，对有界噪声做预算得到净裕量，再与统计噪声的标准差相比得到误码率。

## 5.2 信号回流串扰

- 单端信号中，多个信号的回流电流常常共用路径。
- 设 $N$ 个驱动器共用一条寄生电感为 $L_R$ 的回流路径，每个在 $t_r$ 内切换电流 $i$。
- 除一个之外全部同时翻转时，那一个看到的噪声是 $(N-1)L\,di/dt$。
- 要高速工作就需要大量回流路径。
- 与电源串扰密切相关，也叫"地弹（ground bounce）"或"同步开关输出（SSO）噪声"。

**例**：$L_R = 5$ nH，$i = 10$ mA，$t_r = 200$ ps → $di/dt = 5\times10^7$ A/s，$L\,di/dt = 0.25$ V，所以 $V_{RXN} = 0.25(N-1)$ V。几个信号同时翻就足以淹没小摆幅信号。

## 5.3 回流串扰与上升时间

- **阻性负载**（传输线）：噪声与上升时间成反比，$V_{RXN} = NL\,i/t_r$。
- **容性负载**：电流 $i \approx CV_S/t_r$，噪声与上升时间的**平方**成反比，$V_{RXN} = NLCV_S/t_r^2$。
- 把信号**边沿**放慢（不是放慢时钟周期）可以大幅降低噪声。

## 5.4 码间干扰

理想的传输系统没有记忆。现实中系统状态受之前的位影响，三种机制：

1. 传输线上的反射；
2. 被激起的谐振的幅度和相位；
3. 周期结束时信号还没到达电源轨。

**阻抗失配**

- 之前位的回波在线上来回反射。
- 失配比例为 $x$ 时，一阶近似的反射系数 $k_R = x/2$。
- 整串回波最坏情况叠加：

$$k_{ir} = \sum_{i=1}^{\infty} k_R^{\,i} = \frac{k_R}{1 - k_R}$$

**谐振电路**

- LC 槽路和传输线的谐振段会振荡，由信号跳变激起，可能干扰后面的跳变。
- 上升时间越慢，注入谐振的能量越少；电阻提供阻尼。
- 下一位从一个依赖历史的状态出发。

**惯性延迟**

- 有些电路在周期结束时还没稳定，下一位的起点依赖历史（残余电压）。
- 同时带来电压噪声和时序噪声；常见原因是上升时间控制做得不好。

## 5.5 其他噪声源

- **α 粒子**：5 MeV 的粒子向衬底注入约 730 fC 电荷，单个节点通常收集不到 50 fC。
- **热噪声（Johnson）和散粒噪声**：与带宽成正比，通常在 μV 量级。
- **参数失配**：$V_T$ 和 $\beta$ 的偏差与 $1/\sqrt{WL}$ 成正比；系统性偏差取决于版图。

## 5.6 用噪声预算管理噪声

| | 比例噪声 | 独立噪声 |
|---|---|---|
| **有界** | 平行线串扰、ISI | 接收器失调、接收器灵敏度 |
| **统计** | 垂直线串扰 | 电源噪声、热噪声 |

- 有些来源放哪一类都可以（如对垂直走线的串扰）。
- 给各来源分配噪声额度，再约束设计使其满足预算。

预算的结构：信号摆幅 400 mV → 毛裕量 200 mV → 减去比例噪声（20%，80 mV）和固定有界噪声（50 mV）→ 净裕量 70 mV → 与 RMS 噪声相比得到 $\text{VSNR} = \text{净裕量}/\text{RMS 噪声}$。

## 5.7 最坏情况分析

假设所有噪声源都取最大值，并且朝同一方向叠加。这在某一台设备的某一瞬间不太可能发生，但只要造得够多、跑得够久，就一定会发生。

| 项目 | 数值 |
|---|---|
| 信号摆幅 | 400 mV |
| 接收器失调 + 灵敏度 | 50 mV |
| 未抵消的电源噪声 | 20 mV |
| 独立噪声合计 $V_{NI}$ | 70 mV |
| 串扰 | 0.1 |
| 反射 | 0.1 |
| 比例系数合计 $K_N$ | 0.2 |
| $K_N V_S$ | 80 mV |
| 毛裕量 | 200 mV |
| 总有界噪声 $V_N$ | 150 mV |
| **净裕量** | **50 mV** |
| **裕量比** | **0.25** |

## 5.8 裕量与裕量比

- **毛裕量** $V_{GM}$：摆幅的一半。
- **净裕量** $V_{NM}$：毛裕量减去所有有界噪声。
- **裕量比** $V_{NM}/V_{GM}$：好的品质指标，表示噪声源还能按比例增大多少而不出错。
- "总噪声裕量"这种说法没有意义；数据手册给的是毛裕量减去接收器失调和灵敏度。

## 5.9 统计分析：高斯噪声

- 对某些噪声源，考虑其取值的概率分布而不是最坏值：真正随机的（热噪声、散粒噪声），以及互不相关的有界噪声（串扰、电源噪声）。
- 通常用零均值高斯分布建模，关键参数是标准差（RMS 值）。
- 多个零均值高斯源相加：**加方差，不是加标准差**。

$$V_{RMS} = \sqrt{\sum_i V_i^2}$$

例：10 mV 与 20 mV 的 RMS 源合成 22.4 mV。

## 5.10 误码率

净裕量 $V_{NM}$，总高斯噪声 $V_{GN}$，则 $\text{VSNR} = V_{NM}/V_{GN}$。噪声超过裕量的概率是高斯分布的尾部积分，可以用指数来估上界：

$$P_{error} = Q(\text{VSNR}) \;<\; \exp\!\left(-\frac{\text{VSNR}^2}{2}\right)$$

VSNR 较大时，这个指数上界和精确值在对数坐标上很接近。

## 5.12 噪声预算与设计规则

不需要对每个信号都做预算。预算是对**一类信号**做的，这类信号遵守同一套设计规则：

- 分类：板间信号、板内（芯片间）信号、片上全局信号、片上局部信号、特殊信号（如多米诺逻辑或 RAM 位线）。
- 每类的规则：线的几何形状与间距、最大平行长度、地屏蔽、阻抗与端接容差、驱动器与接收器规格。
- 只要每个信号满足规则，就满足预算，误码率至少和算出来的一样好。
