# 第 12 讲 同步

> 2001-02-26 · [原讲义 PDF](http://cva.stanford.edu/classes/ee273/Previous_273/2001/ee273_2001_handouts/L12_022601.PDF) · 课后阅读：10.3

## 12.1 概览

- **同步**：判定事件的先后顺序。用途是把信号搬进一个时钟域，以及异步仲裁。
- **同步失效**：两个信号的时间间隔越小越难判断谁先；同步器可能挂在亚稳态无法决定；电路的不同部分可能对结果有不同的解读。
- **失效概率**：
    - 与"易受攻击时间"所占比例成正比；
    - 随等待时间**指数下降**；
    - 随触发器时间常数**指数上升**；
    - 失效率与事件率成正比。

## 12.2 什么是同步

- 同步器判定两个信号上事件的顺序：谁先来？
- 这重要吗？有时候根本不需要同步。
- 通常其中一个信号是时钟：数据是在时钟上升之前还是之后变高的？
- 这个问题为什么难？因为两者可以任意接近。

## 12.3 同步的用途

- **用时钟采样异步输入**：例如粒子计数器、按键。
- **跨时钟域**：用另一个时钟采样一个同步信号；如果两个时钟都是周期性的，问题会容易一些（下一讲）。
- **异步信号的仲裁**：例如共享资源的请求线、抢答器。

## 12.4 同步失效

- A 上的事件和 B 上的事件谁先？比赛越接近越难裁决。
- 两个事件非常接近时，同步器可能进入**亚稳态**。
- 同步器可能需要**任意长**的时间才能离开这个状态。
- 在此期间，同步器的输出可能被下游电路**不一致地**解读（有的看成 0，有的看成 1）。

## 12.5 NAND 仲裁器

用一个 NAND 构成的 RS 触发器当仲裁器：

- A 比 B 早到很多：AFirst′ 变低，把 B 锁在外面；
- B 比 A 早到很多：BFirst′ 变低，把 A 锁在外面；
- A 和 B 几乎同时变高会怎样？

**动态过程第一步：初始电压**

A、B 几乎同时变高时，两个输出节点之间的电压差与时间差成正比：

$$\Delta V_1 = K_S\,\Delta t$$

**第二步：指数再生**

A、B 都为高之后，交叉耦合的正反馈把初始电压差指数放大：

$$\Delta V(t) = \Delta V_1\,e^{t/\tau_S}$$

**建立时间**

放大到满幅（归一化为 1）所需的时间：

$$t_S = -\tau_S \ln(K_S\,\Delta t)$$

$\Delta t \to 0$ 时 $t_S \to \infty$：初始差越小，决定所需时间越长，**没有上界**。

## 12.6 静态触发器的动态过程类似

- 初始电压差取决于数据跳变与时钟沿的时间差 $\Delta t$。
- 时钟上升后电压差按指数增长。
- 所以任何触发器都可能进入亚稳态。

## 12.7 暴力（等待式）同步器

用时钟采样一个异步信号 A：

1. 用 FF1 采样，它可能进入亚稳态；
2. 等待时间 $t_w$，让可能的亚稳态衰减；
3. 用 FF2 采样 FF1 的输出。

如果 FF2 打拍时 FF1 仍在亚稳态，就发生**同步失效**。概率是多少？

## 12.8 计算同步失效概率

$$P(\text{失效}) = P(\text{进入亚稳态}) \times P(\text{等待 } t_w \text{ 后仍在亚稳态})$$

**进入亚稳态的概率**

输入跳变落在触发器孔径时间内才可能进入亚稳态，概率是孔径时间占周期的比例：

$$P_E = \frac{t_a}{t_{cy}} = t_a f_{cy}$$

**停留在亚稳态的概率**

初始电压差太小、在等待时间内没被放大到满幅，才会仍在亚稳态。"太小"的那部分占全部电压范围的比例：

$$P_S = \exp\!\left(-\frac{t_w}{\tau_S}\right)$$

**失效概率与失效率**

$$P_F = P_E P_S = t_a f_{cy}\exp\!\left(-\frac{t_w}{\tau_S}\right)$$

每个事件都可能失效，失效率等于事件率乘以失效概率：

$$f_F = f_e P_F = t_a f_e f_{cy}\exp\!\left(-\frac{t_w}{\tau_S}\right)$$

## 12.9 例：失效率计算

500 MHz 时钟采样 10 MHz 的异步信号，触发器的孔径时间和再生时间常数都是 100 ps。

| 量 | 数值 |
|---|---|
| $t_a$ | 1.0×10⁻¹⁰ s |
| $f_{cy}$ | 5.0×10⁸ Hz |
| $\tau_S$ | 1.0×10⁻¹⁰ s |
| $t_w$（一个周期） | 2.0×10⁻⁹ s |
| $P_E$ | 5.0×10⁻² |
| $P_S = e^{-20}$ | 2.1×10⁻⁹ |
| $P_F$ | 1.0×10⁻¹⁰ |
| $f_e$ | 1.0×10⁷ Hz |
| $f_F$ | 1.0×10⁻³ /s |

即大约每 1000 秒（17 分钟）失效一次，不可接受。再多等一个周期，$P_S$ 再乘 $e^{-20}$，失效间隔就变成约 1.5 万年（笔者计算）。这说明等待时间的指数效应有多强。

## 12.10 常见陷阱

同步器很容易设计错，最常见的两个：

1. **用了不再生（或再生很慢）的触发器**：$\tau_S$ 必须小，因为它在指数上。
2. **没有把触发器的反馈环路隔离开**：环路节点上挂了额外负载会增大 $\tau_S$，输出也可能在亚稳态期间被下游看到中间电平。

## 12.11 完成检测

- 同步器稳定所需的时间**无法给出上界**。
- 但可以**检测**同步器何时已经稳定（两个输出节点的电压差足够大）。
- 这只有在下游逻辑能使用这个异步的完成信号时才有用（即自定时电路）。
