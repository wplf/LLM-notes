# 第 3 章 阿尔法模型：宽客如何盈利

> 本章是全书核心：量化策略的收益从哪里来？

**阿尔法（Alpha）**：扣除市场等系统性收益后，靠择时与选股能力获得的超额收益。**阿尔法模型**就是用来预测资产未来走势、从而产生超额收益的模型。

## 两类阿尔法模型：理论驱动型和数据驱动型

| 维度 | 理论驱动型（Theory-driven） | 数据驱动型（Data-driven） |
|---|---|---|
| 出发点 | 先有对市场的经济学解释，再用数据验证 | 先从数据中挖掘规律，不预设解释 |
| 典型方法 | 趋势、均值回归、价值、质量等 | 机器学习、模式识别、统计挖掘 |
| 优点 | 可解释，逻辑稳健，不易被噪声误导 | 能发现人想不到的模式，适应性强 |
| 缺点 | 想法易被模仿而拥挤 | 易过拟合，难以解释，失效时难诊断 |
| 普及程度 | 绝大多数宽客采用 | 较少，门槛高（多见于高频领域） |

## 理论驱动型阿尔法模型

作者用两个维度对理论驱动策略分类：**输入数据类型**（价格数据 / 基本面数据）× **交易现象**。

### 基于价格数据

1. **趋势跟踪（Trend Following）**
   - 逻辑：市场参与者对信息的反应是渐进的（共识形成需要时间），因此价格会朝一个方向持续一段时间。
   - 典型实现：移动平均线交叉、突破策略。
   - 风险：趋势反转、震荡市来回止损。期货 CTA 是代表。
2. **均值回归（Mean Reversion）**
   - 逻辑：短期供需失衡导致价格偏离"合理"水平，之后会回归。
   - 典型实现：统计套利、配对交易（两只相关股票价差偏离时做多弱者、做空强者）。
   - 风险：偏离可能是结构性变化而非噪声。
3. 趋势与均值回归往往在**不同时间尺度**上同时存在：短期回归、中期趋势，长期又回归。

### 基于基本面数据

1. **价值 / 收益率（Value / Yield）**
   - 便宜资产（高盈利收益率 E/P、高账面市值比、高股息）长期跑赢昂贵资产。
   - 外汇中的**套息交易（Carry Trade）**也属此类：买高息货币、卖低息货币。
2. **成长 / 情绪（Growth / Sentiment）**
   - 买入盈利增长快、分析师上调预期的资产；"成长股的溢价有理由"。
3. **质量（Quality）**
   - 偏好财务稳健、盈利质量高、杠杆低、管理层行为良好的公司。
   - 在危机中常表现为"质量逃逸"（flight to quality）。

## 数据驱动型阿尔法模型

- 不先假设规律，而是用统计/机器学习方法从数据中寻找可预测的模式（如：在过去类似的价格形态之后，市场通常如何变化）。
- 优点：可以发现非直觉、非线性的关系；适合高频、数据量大的场景。
- 挑战：
  - **过拟合**：数据中噪声远多于信号。
  - **可解释性差**：模型失效时难以判断原因。
  - 需要大量高质量数据与算力。

## 实施策略

同一个思想，不同的实现会带来截然不同的结果。作者强调的关键实施维度：

- **预测目标**：方向、幅度、持续时间、概率，或相对排名。
- **投资期限**：从毫秒级到数月；期限越短，交易成本越重要。
- **下注结构**：
  - 绝对（单个资产方向）vs 相对（资产间相对强弱，如多空配对）。
  - 相对下注可降低市场暴露，但需定义"相对于谁"（行业、相似股票组）。
- **投资范围（Universe）**：资产类别、地区、流动性门槛。范围选择本身就影响策略特征。
- **模型定义与参数**：例如"趋势"用多少天的均线、如何判断信号强弱。
- **条件变量（Conditioning Variables）**：用另一个变量调整信号的使用方式（如只在低波动环境中使用均值回归）。
- **运行频率**：多久更新一次模型、重新估计参数。

## 混合型阿尔法模型

多数成熟宽客会组合多个阿尔法信号，主要方法：

1. **线性模型**：信号加权求和（权重可固定，也可通过回归估计）。最常见、最稳健。
2. **非线性模型**：
   - 条件模型：一个信号决定另一个信号是否使用/权重大小。
   - 旋转模型：根据市场环境切换不同的信号。
3. **机器学习方法**：让算法学习如何组合信号；灵活但易过拟合。

- 组合多个低相关信号可提高收益稳定性（分散化）。
- 也有宽客不在阿尔法层面合并，而是给每个策略分配独立资金（多策略结构）。

## 小结

- 阿尔法来源本质上只有少数几类：**趋势、回归、价值/收益率、成长、质量**（以及高频中的微观结构）。
- 宽客之间的差异主要来自**实施细节**：数据、期限、下注结构、范围、参数和信号组合方式。
- 评估一个量化策略，首先要问：它赚的是哪种钱？为什么这种钱会持续存在？
