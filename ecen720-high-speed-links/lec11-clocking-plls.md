> [原讲义 PDF](https://people.engr.tamu.edu/spalermo/ecen689/lecture11_ee720_clocking_arch_plls.pdf) · 参考：Casper 的高速链路时钟教程、PLL 分析论文、Mansuri 的 PLL 博士论文；Fischette 的 PLL 教程

## 11.1 时钟术语

| 类型 | 含义 | 应用 |
|---|---|---|
| 同步（synchronous） | 每个芯片得到相同的频率**和**相位 | 低速总线 |
| 同频异相（mesochronous） | 频率相同、相位未知，需要相位恢复电路（可以有也可以没有完整的 CDR） | 高速内存、系统内部接口、MAC/包接口 |
| 准同步（plesiochronous） | 频率几乎相同，相位缓慢漂移，需要 CDR | **高速链路中广泛使用** |
| 异步（asynchronous） | 没有时钟，用请求/应答握手 | 嵌入式系统、Unix、Linux |

（与 EE273 第 13 讲的同步层级是同一套概念。）

## 11.2 三种 I/O 时钟架构

- **公共时钟**（同步）；
- **前向时钟**（源同步）；
- **嵌入式时钟**（时钟恢复）。

不同应用需要不同的 I/O 带宽，用不同的架构；一颗处理器可能同时有这三种 I/O；同一套电路常可以复用来模拟不同的 I/O 方案。

### 公共时钟 I/O

- 早期计算机系统中常见；按设计就是同步系统（不做主动去偏斜）。
- 公共总线时钟控制芯片间传输；到各芯片的走线要等长以减小时钟偏斜。
- 速率一般限制在约 100 Mb/s。
- **局限**：时钟偏斜和传播延迟难以控制；要满足周期时间就得严格控制绝对延迟；对片上电路和板上走线的延迟变化都敏感；片上和片外延迟的相关性低，难以补偿。片上通信常用，但在 I/O 中速度有限。

### 前向时钟 I/O

- 高速参考时钟从发送芯片转发到接收芯片，是同频异相系统。
- 用于处理器-内存接口和多处理器通信：Intel QPI、HyperTransport。
- 需要一条额外的时钟通道。
- **"相干"时钟**使抖动跟踪可以从低频一直覆盖到高频。
- 时钟经过信道会衰减，需要好的时钟接收放大器。

**局限**：时钟偏斜（驱动强度和负载失配、互联长度失配）；低通信道造成抖动放大；前向时钟的占空比变化。

**去偏斜**：逐通道去偏斜可以大幅提高速率。调整采样时钟使之对准数据眼的中央。实现方式：DLL + 相位插值器，或注入锁定振荡器。相位获取可以基于 BER（不需要额外的相位采样器），也可以基于鉴相器（额外的相位采样器定期上电）。

**电路**：发送 PLL、发送时钟分配、复制的发送时钟驱动器、信道、前向时钟放大器、接收时钟分配、去偏斜电路（DLL/PI 或注入锁定振荡器）。

### 嵌入式时钟 I/O

- 可用于同频异相或准同步系统。
- 时钟频率和最佳相位从输入数据流中提取，鉴相一直在运行。
- CDR 实现：每通道一个 PLL；全局 PLL + 本地 DLL/PI 的双环；本地相位旋转 PLL。
- **局限**：抖动跟踪受 CDR 带宽限制。工艺进步使 CDR 带宽可以更高，从而跟踪更高频的抖动。一般比前向时钟实现的硬件多（额外的输入相位采样器）。
- 全局 PLL 方案需要把接收时钟分配到各个通道。

### 实例：Xilinx 0.5–32 Gb/s 收发器（Upadhyaya VLSI 2016）

- LC-PLL 带两个 LC-VCO 覆盖高速率（8–32 Gb/s）；环形 PLL 覆盖低速率；
- CML 时钟分配，用有源电感负载降低抖动。

| 参数 | 数值 |
|---|---|
| 工艺 | 16 nm FinFET CMOS |
| 速率范围 | 500 Mb/s – 32.75 Gb/s |
| 四通道面积 | 2.625 mm × 2.218 mm |

## 11.3 PLL 概述

- 锁相环（PLL）是一个负反馈系统，使振荡器产生的信号与参考信号**相位和频率都锁定**。
- **应用**：频率合成（把 100 MHz 参考乘到 10 GHz）；偏斜消除（内部时钟与 I/O 时钟对齐相位）；时钟恢复；调制解调（无线）；扩频时钟。

### 设计挑战

- 板级参考时钟频率很少提高，156 MHz 很常见。
- 采用 PAM4 和 ADC 前端后，接收 CDR 带宽难以提高，典型只有 2–4 MHz。
- PLL 带宽要小于 10 MHz 以保证稳定并滤除参考抖动。
- 低频偏处由闪烁噪声造成的 VCO 相位噪声必须被抑制。

32.75 Gb/s 收发器 PLL 的仿真抖动（Turker ISSCC 2019）：

| 接收器类型 | PLL 在 1 MHz 处相噪 | CDR 带宽 | RJ | RJ（UI） |
|---|---|---|---|---|
| 模拟接收器 | −92.4 dBc/Hz | 12.7 MHz | 160.7 fs | 5.26 mUI |
| ADC 接收器 | −92.4 dBc/Hz | 2 MHz | 407 fs | 13.3 mUI |

CDR 带宽越低，能跟踪掉的 PLL 抖动越少。

## 11.4 电荷泵 PLL

- 常见实现：鉴频鉴相器（PFD）→ 电荷泵 → 环路滤波器 → VCO → 1/N 分频器 → 回到 PFD。
- **二型**（两个积分器）使输入相位和反馈相位之间理想上零相差。
- 需要一个由滤波电阻实现的稳定零点；常再加一个次级电容 $C_2$ 做额外滤波以减小参考杂散。
- 建模为三阶系统。

## 11.5 线性 PLL 模型

- 相位是关心的变量：在环路某点注入激励后的输出相位响应；相位误差的响应也有参考价值。
- 线性"小信号"分析适用于：PLL 已锁定（或接近锁定），且输入相位偏差足够小，仍在锁定范围内。
- **频率响应**告诉我们 PLL 在输入相位以某个频率变化时跟得有多好。输出对环路中不同注入点的传递函数不同。

电荷泵 PLL 的各部分：

$$K_{PD} = \frac{I_{CP}}{2\pi},\qquad F(s) = \frac{1}{C_2}\cdot\frac{s + \frac{1}{RC_1}}{s\left(s + \frac{C_1 + C_2}{RC_1C_2}\right)},\qquad \text{VCO} = \frac{K_{VCO}}{s},\qquad \text{分频} = \frac1N$$

闭环传递函数：

$$H(s) = \frac{\phi_{out}}{\phi_{in}} = \frac{\frac{K_{PD}K_{VCO}}{C_2}\left(s + \frac{1}{RC_1}\right)}{s^3 + \frac{C_1 + C_2}{RC_1C_2}s^2 + \frac{K_{PD}K_{VCO}}{NC_2}s + \frac{K_{PD}K_{VCO}}{NRC_1C_2}}$$

### 14 GHz PLL 例子

| 参数 | 数值 |
|---|---|
| $F_{ref}$ | 156.25 MHz |
| N | 90 |
| $F_{VCO}$ | 14 GHz |
| 单位增益频率 $f_u$ | 2 MHz |
| 相位裕度 $\phi_m$ | 60° |
| 闭环 −3 dB 带宽 | 3.1 MHz |
| $K_{VCO}$ | 2π × 1 GHz/V |
| R / $C_1$ / $C_2$ | 4 kΩ / 74 pF / 5.8 pF |
| $I_{CP}$ | 310 μA |

## 11.6 PLL 噪声源与噪声传递函数

四个主要噪声源：输入参考相位噪声 $S_{\phi_{in}}$、电荷泵电流噪声 $S_{i_{CP}}$、环路滤波电阻电压噪声 $S_{v_R}$、VCO 相位噪声 $S_{\phi_{VCO}}$。输出相噪是各自乘以对应噪声传递函数模平方之和：

$$S_{\phi_{out}}^{Total} = S_{\phi_{in}}|NTF_{IN}|^2 + S_{i_{CP}}|NTF_{CP}|^2 + S_{v_R}|NTF_R|^2 + S_{\phi_{VCO}}|NTF_{VCO}|^2$$

记环路增益为 $LG(s)$：

$$NTF_{IN} = \frac{N\,LG}{1 + LG},\quad NTF_{CP} = \frac{N}{K_{PD}}\cdot\frac{LG}{1 + LG},\quad NTF_R = \frac{K_{VCO}/s}{1 + LG},\quad NTF_{VCO} = \frac{1}{1 + LG}$$

- 输入参考噪声和电荷泵噪声被**低通**；
- 环路滤波器噪声（VCO 输入噪声）被**带通**；
- VCO 输出相位噪声被**高通**。

### 由相位噪声得到抖动

时域抖动由输出相噪积分得到：

$$\sigma_{j,Total}^2 = \frac{2}{\omega_0^2}\int_{f_{start}}^{f_{stop}} S_{\phi_{out}}^{Total}(f)\,df,\qquad \sigma_{j,Total}^2 = \sum_i\sigma_{j,i}^2$$

### 收发器中的抖动建模

- 决定系统时序裕量的是**接收 CDR 产生的采样时钟与输入数据之间的相对抖动**（动态相位误差）。
- CDR 的高通响应提供额外滤波；IEEE 802.3 和 OIF-CEI 把它建模为 4 MHz 的一阶响应：

$$\sigma_{jSYS,i}^2 = \frac{2}{\omega_0^2}\int_0^{f_0/2} S_i(f)\,|NTF_i(f)|^2\,|CDR(f)|^2\,df$$

### 各噪声源的贡献（14 GHz PLL 例子）

| 噪声源 | 说明 | PLL 输出（10 kHz–10 MHz） | 计入 CDR 后（100 Hz–7 GHz） |
|---|---|---|---|
| 参考时钟 | Silicon Labs 超低抖动晶振，156.25 MHz，自身 226 fs | 217 fs | 45 fs |
| 电荷泵 | 噪声电流只在 PFD 复位时间内注入环路滤波器；白噪声按 $T_{rst}/T_{ref}$ 缩放，1/f 噪声按 $(T_{rst}/T_{ref})^2$ 缩放（$T_{rst}$ = 40 ps，$T_{ref}$ = 6.4 ns） | 61 fs | 22 fs |
| 环路滤波电阻 | 4 kΩ 电阻 $4kTR$ ≈ −162 dB(V²/Hz) | 128 fs | 81 fs |
| VCO | LC-VCO：谐振腔品质因数有限、交叉耦合对、尾电流源 | 257 fs | 125 fs |
| **合计** | | **365 fs** | **157 fs** |

- 电阻噪声、环路滤波电容大小和电荷泵噪声之间有取舍：电阻小，电容就要大（面积大），电荷泵电流也要大（噪声大）。
- PLL 输出处：低频由参考时钟主导，环路带宽附近及以上由 VCO 主导。
- 计入 CDR 后：VCO 噪声明显占主导，环路电阻噪声的比例也变大。

### 要点

- PLL 怎样整形相位噪声取决于噪声从环路哪里注入。
- 为一个噪声源优化环路带宽，可能会放大另一个噪声源。
- 一般而言：输入相噪被低通，VCO 输入电压噪声被带通，VCO / 时钟缓冲器输出相噪被高通。

## 11.7 振荡器噪声

### 相位噪声模型

$L(\Delta f)$ = 10 log（噪声谱密度 / 载波功率），单位 dBc/Hz。Leeson 模型：

$$L(\Delta f) = 10\log\left[\frac{2FkT}{P_{sig}}\left(1 + \left(\frac{f_0}{2Q\Delta f}\right)^2\right)\left(1 + \frac{\Delta f_{1/f^3}}{|\Delta f|}\right)\right]$$

更好的模型见 Hajimiri 的论文。

### 开环 VCO 抖动（McNeill）

- 测量时钟过阈值时刻的分布，画出抖动 σ 随延迟 ΔT 的变化。
- 开环时 $\sigma_{\Delta T} = \kappa\sqrt{\Delta T}$，κ 是 VCO 的时域品质因数。

### 闭环 PLL 中的 VCO 抖动

PLL 把延迟超过环路时间常数 $\tau_L = 1/(2\pi f_L)$ 后的抖动限制住，不再增长。

### 以参考时钟为基准与以自身为基准

- 一般关心的是相对参考时钟的抖动；但相对输出时钟的延迟版本测量往往更容易。
- 因为两个沿都有噪声，后者比相对参考时钟的抖动大 $\sqrt2$ 倍。

### 由相位噪声换算抖动（Mansuri）

- 积分范围取决于应用带宽：$f_{min}$ 由假设的 CDR 跟踪带宽决定，$f_{max}$ 为奈奎斯特频率（$f_0/2$）。
- 最精确的做法，累积 ΔT 后的 RMS 抖动：

$$\sigma_{\Delta T}^2 = \frac{8}{\omega_0^2}\int_0^\infty S_\phi(f)\sin^2(\pi f\Delta T)\,df$$

ΔT 趋于无穷时，$\sin^2$ 项平均为 1/2，退化为上面的积分式；有系统抖动传递函数时把 $|H_{sys}(f)|^2$ 乘进去。

## 11.8 时域模型

- 时域模型能刻画 PLL 架构的离散时间行为：电荷泵与环路滤波器的相互作用、**周跳（cycle slipping）**行为；也能建模非线性控制系统，如动态环路带宽控制、自动频带选择。
- 工具：MATLAB Simulink、CppSim、Cadence。
- **Simulink 模型**：对输入频率阶跃的 VCO 控制电压响应。$K_{VCO}$ = 2π × 1 GHz/V（LC 振荡器）和 2π × 10 GHz/V（环形振荡器）两种情况。电压尖峰是电荷泵电流流过环路滤波电阻造成的；初始频差大时，锁定过程中会发生周跳。
- **CppSim**（[cppsim.com](https://cppsim.com/)）：基于 C++，能快速仿真先进架构，带很多现成模块（Perrott / Meninger）。
- **Cadence Verilog-A 模型**：如输出方波的 VCO。

## 附录 A：PLL 环路设计

> 讲义注明：以下是 ECEN 620 的内容，可能对项目有用，但不在第二次考试的详细范围内。

### 环路增益

$$LG(s) = \frac{K_{PD}F(s)K_{VCO}}{Ns} = \frac{K_{PD}K_{VCO}\,(s + \omega_z)}{NC_2\,s^2\,(s + \omega_{p3})},\qquad \omega_z = \frac{1}{R_1C_1},\ \omega_{p3} = \frac{C_1 + C_2}{R_1C_1C_2}$$

两个极点在原点。相位裕度：

$$\phi_m = \tan^{-1}\frac{\omega_u}{\omega_z} - \tan^{-1}\frac{\omega_u}{\omega_{p3}}$$

### 使相位裕度最大的设计步骤（Hanumolu TCAS-I 2004）

在给定 $f_u$ 和 $\phi_m$ 下：

1. **由相位裕度定电容比**：

$$K_C = \frac{C_1}{C_2} = 2\tan^2\phi_m + 2\tan\phi_m\sqrt{\tan^2\phi_m + 1}$$

$\phi_m$ = 60° 时 $K_C$ = 12.9。

2. **由 $\omega_u$ 定滤波器**，R 按低噪声选：$\omega_z = \omega_u/\sqrt{1 + K_C}$，$C_1 = 1/(\omega_z R)$，$C_2 = C_1/K_C$。$f_u$ = 2 MHz 时 $f_z$ = 536 kHz；取 R = 4 kΩ，得 $C_1$ = 74 pF、$C_2$ = 5.8 pF。

3. **定 $I_{cp}$ 以获得所需环路增益**：

$$I_{cp} = \frac{2\pi NC_2\omega_u^2}{K_{VCO}}\sqrt{\frac{\omega_{p3}^2 + \omega_u^2}{\omega_z^2 + \omega_u^2}}$$

（$f_{p3}$ = 7.45 MHz）得 $I_{cp}$ = 310 μA。

仿真结果：$f_u$ = 2 MHz、$\phi_m$ = 60°，闭环 $f_{3dB}$ = 3.1 MHz。

## 附录 B：鉴相器

- 检测反馈时钟与参考时钟的相位差。环路滤波器会对鉴相器输出做滤波，所以用**平均输出**来表征鉴相器增益：$\text{avg}\{v_e(t)\} = K_{PD}\,\Delta\phi$。
- 单位：配无量纲滤波器时为 V/rad；与电荷泵合在一起时为 A/rad（或按平均值算的 rad⁻¹）。$K_{PD}$ 随具体的鉴相电路而变。

### 模拟乘法器鉴相器

两个同频正弦相乘，滤掉高频项后：

$$y(t) = \frac{\alpha A_1A_2}{2}\cos\Delta\phi$$

在 π/2 锁定点附近 $y \approx \frac{\alpha A_1A_2}{2}\left(\frac\pi2 - \Delta\phi\right)$，$K_{PD} = \alpha A_1A_2/2$。

### 异或鉴相器

- 逻辑 1 记作 +1、0 记作 −1，平均输出为 0 时锁定。一般 π/2 是稳定锁定点，−π/2 是亚稳点。
- 对时钟占空比敏感；超前和滞后的相位差产生的脉宽相同。

### 周跳

- 输入参考和反馈信号有频差时，鉴相器会在增益不同（甚至符号相反，变成正反馈）的区域之间跳动，PLL 不再是线性系统。
- 频差太大 PLL 可能锁不上。

### 鉴频鉴相器（PFD）

- 锁定范围宽，可能覆盖整个 VCO 调谐范围。
- 三态工作，有 UP、DN 两个输出；上升沿触发，所以对占空比不敏感。
- 平均传递特性在 ±2π 内斜率恒定，且关于零相位极性不对称，因此能在很宽的频率范围工作。平均 PFD 增益为 $1/(2\pi)$（rad⁻¹）。

### PFD 死区

- 相差很小时 PFD 输出脉冲很窄，无法有效地打开电荷泵开关，形成"死区"：环路增益低，抖动增大。
- **解决办法**：在 PFD 复位路径上加延迟，强制 UP 和 DN 有最小脉宽。锁定时 UP、DN 电流源都开 $T_{rst}$，理想上不向环路滤波器注入净电流。

### 接近 2π 时的问题

- 复位期间 PFD 对输入上升沿没有反应，可能漏掉一个沿，下一个沿把环路往错误方向推。
- 复位延迟会增加锁定时间，并限制 PFD 的最高工作频率：

$$T_{rst,max} = \frac{T_{ref}}{2},\qquad f_{PFD,max} = \frac{1}{2T_{rst}}$$

## 附录 C：电荷泵

- 把 PFD 输出转换成电荷，电荷量正比于 PFD 脉宽。
- 未平均的电荷泵增益为 $I_{CP}$（A）；平均增益 $I_{CP}/(2\pi)$（A/rad），与 PFD 合起来同为 $I_{CP}/(2\pi)$。换用其他鉴相器时这个增益会变。

### 简单电荷泵的问题

- UPB 和 DN 控制信号之间的偏斜；
- UP/DN 电流源的匹配；
- 开关的时钟馈通和电荷注入耦合到 $V_{ctrl}$；
- 电流源漏极节点电容与 $V_{ctrl}$ 之间的电荷共享。

### 偏斜补偿

- 在 DN 路径加传输门，使其延迟与 UPB 路径相等，UP 和 DN 电流源重叠更好；但 UPB 和 DN 的边沿速率匹配差。
- UP 路径用 3 级反相器、DN 路径用 2 级扇出更大的反相器，延迟和边沿速率都能匹配好。

### 电荷泵失配

- 有失配时 PLL 会带静态相位误差锁定，$V_{ctrl}$ 上有额外纹波，在偏离载波参考频率处产生频域杂散。
- 设 $I_{UP} = I_{CP} - \Delta I/2$，$I_{DN} = I_{CP} + \Delta I/2$，锁定时净电荷为零：$I_{UP}T_{os} = \Delta I\,T_{rst}$，所以：

$$\phi_{os} = 2\pi\frac{\Delta I}{I_{CP} - \Delta I/2}\cdot\frac{T_{rst}}{T_{ref}}$$

### 改进匹配的电荷泵

- 并联路径让电流源一直导通；放大器使电流源的 $V_{DS}$ 保持恒定，减小瞬态电流失配（电荷共享）（Young JSSC 1992）。
- **数字漏电补偿**（Fan ISSCC 2019）：电荷泵关断时的漏电会让 PLL 带静态相差锁定；用额外的数字控制电荷泵电流脉冲补偿，由 TDC 检测输入参考与反馈时钟的相差。
- **开关反接的电荷泵**（Ingino JSSC 2001）：交换开关位置减少电荷注入；MOS 电容提供额外的时钟馈通抵消；辅助管快速关断电流源；哑支路匹配 PFD 负载。对电荷注入有帮助，但电荷共享仍是问题。

## 附录 D：环路滤波器

- 最常用的是简单的无源 PI 滤波器（单端或全差分）：
    - 低频相位误差积分到 $C_1$ 上，决定平均频率；
    - 电阻（比例增益）把相位校正和频率校正分开；
    - 主电容 $C_1$ 影响 PLL 带宽，零点频率影响稳定性；
    - 电阻带来热噪声，被 PLL 带通滤波。
- **为什么要 $C_2$**：平滑控制电压纹波。不能太大，否则环路不稳定：稳定要求 $C_2 < C_1/10$，低抖动要求 $C_2 > C_1/50$。
- **电容选择**：为省面积想用密度最高的电容，但薄氧 MOS 电容的栅漏电（相当于并联一个非线性电阻，随电压和温度变化）会带来额外相噪和杂散。金属电容或厚氧电容更好，代价是面积（金属电容密度可能不到薄氧电容的 1/10）。PLL 带宽一般 1–50 MHz，对滤波电容的频率响应要求不高。

## 附录 E：VCO

- 时域：$\omega_{out}(t) = \omega_0 + K_{VCO}v_{ctrl}(t)$，相位 $\phi_{out}(t) = \int K_{VCO}v_{ctrl}(t)dt$；拉普拉斯域 $\phi_{out}/v_{ctrl} = K_{VCO}/s$。

| | 环形振荡器 | LC 振荡器 |
|---|---|---|
| 集成 | 容易 | 面积大 |
| 调谐范围 | 宽（5 倍） | 窄（20–30%） |
| 相位噪声 | 较高 | 较低 |

### 巴克豪森振荡判据

持续振荡的两个条件：振荡频率 $\omega_0$ 处环路增益为 1；环路总相移为 360° 的整数倍。

**环形振荡器例子**：四级，$H(s) = -A_0^4/(1 + s/\omega_o)^4$。相位条件：每级 45°，所以 $\omega_{osc} = \omega_o = 1/(RC)$；代入增益条件得到单级增益与 $g_mR$ 的关系（讲义抽取出的数字有歧义，请看原讲义第 94 页）。

**LC 振荡器例子**：

- 当 LC（加 R）谐振腔负载呈纯实数阻抗（零相移）时满足相位条件；
- 把电感的串联损耗电阻换算成等效并联电阻 $R_P$，相位条件在 $\omega = 1/\sqrt{L_PC_P}$ 处满足；
- 增益条件 $g_mR_P \ge 1$；
- 也可以看成损耗电阻为 $2R_P$ 的谐振腔与 $-2/g_m$ 负阻并联，振荡条件 $g_mR_P \ge 1$。

### 几种环形振荡器

- **电源调谐**（Sidiropoulos VLSI 2000）：$T = 2nC(V_{DD} - V_{th})/\ldots$，$K_{VCO} \propto 1/(nC_{stage})$；
- **电流饥饿型**；
- **电容调谐型**；
- **对称负载**（Maneatis JSSC 1996、2003）：在优良的电源噪声抑制下实现频率调谐；Maneatis 的自偏置技术可以得到恒定的阻尼系数和环路带宽（为参考时钟的固定百分比）。

### LC 振荡器的调谐

- 常用可变电容（变容管）调节振荡频率：$\omega_{osc} = 1/\sqrt{L_P(C_{tune} + C_{fixed})}$，固定电容会缩小调谐范围。
- **PN 结变容管**：避开正偏区，以免振荡器非线性。
- **MOS 变容管**：积累型比反型的 Q 更好。

## 附录 F：分频器

- 时域：$\phi_{fb}(t) = \phi_{out}(t)/N$，在线性模型中是无量纲的 1/N。

### 二分频

- 用一个触发器接成"负反馈"即可；分频器要在最高输出时钟频率**加上一定余量**下正确工作。
- **TSPC 触发器**：较快、紧凑、无静态功耗，只需一相时钟；但每个输入周期信号要穿过 3 级门，需要满摆幅 CMOS 输入；动态触发器在低频（测试模式）下可能因漏电失效（不同时钟相位下各节点悬空，例如 CLK 为低时 Q_bar 悬空）。
- **CML 触发器**：每个输入周期只穿过 2 级 CML 门，接受 CML 电平；但面积更大、有静态功耗，需要差分输入和尾电流偏置。加并联峰化电感可以再提速 50% 以上。

### 异步与同步二进制分频器

| | 异步 | 同步 |
|---|---|---|
| 功耗 | 各级频率递减，功耗低，高频时钟负载小 | 所有触发器都跑在最高频率，功耗高，高频时钟负载大 |
| 抖动 | 沿各级 clock-to-Q 延迟累积；额外的分频器延迟还会降低 PLL 相位裕度 | 分频输出被高频时钟"重采样"，抖动与 VCO 输出相近，延迟最小 |

### 双模预分频器（Razavi）

- 2/3 分频（MC = 0 时 ÷3，MC = 1 时 ÷2）；
- 15/16 分频：同步 3/4 预分频器后接异步 ÷4。÷15 时，15 个周期内第一级 ÷3 一次、÷4 三次。

### 注入锁定分频器

- 超谐波注入锁定振荡器可以做分频器，比触发器分频器更快、功耗更低，但注入锁定范围可能有限。
- 例：LC 振荡器型 ÷2（Verma JSSC 2003，Rategh JSSC 1999）；环形振荡器型 ÷3（Lo CICC 2009）。
