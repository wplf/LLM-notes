# 第 7 讲 均衡概述与发送端 FIR 均衡

> [原讲义 PDF](https://people.engr.tamu.edu/spalermo/ecen689/lecture7_ee720_eq_intro_txeq.pdf) · 参考：均衡综述与电路论文

提纲：均衡理论与电路（概述；发送 FIR、接收 FIR、接收 CTLE、接收 DFE 四种实现）→ 发送 FIR 均衡（时域与频域；MMSE 系数选择；电路结构）。

## 7.1 带均衡的链路

串行器 → 发送端均衡 → 信道 → 接收端均衡 → 解串器。信道损耗让眼图闭合（第 1 讲的例子）。

## 7.2 信道均衡的目标

把频率响应**拉平到奈奎斯特频率**，消除时域 ISI。

## 7.3 四种均衡方式的优缺点

### 发送 FIR 均衡

- 发送 FIR 滤波器预先扭曲发送脉冲以抵消信道失真，代价是发送信号被衰减（去加重，de-emphasis）。
- 以 IBM 的 4 抽头 FFE 为例，输出电压是各抽头电流按数据极性的加权和：

$$V_{out} = \left[I_{-1}D(1) + I_0 D(0) + I_1 D(-1) + I_2 D(-2)\right]\frac{R_{TERM}}{2}$$

| 优点 | 缺点 |
|---|---|
| 实现简单 | 受峰值功率限制，只能衰减低频成分 |
| 能消除前标 ISI 和滤波器长度以外的 ISI | 需要"反向信道"来调整抽头 |
| 不放大噪声 | |
| 可做到 5–6 位精度 | |

### 接收 FIR 均衡

| 优点 | 缺点 |
|---|---|
| 动态范围足够时可以放大高频（而非衰减低频） | 放大噪声和串扰 |
| 能消除前标 ISI 和滤波器长度以外的 ISI | 模拟延迟难实现 |
| 抽头系数可以自适应调整，不需要反向信道 | 抽头精度有限 |

（例：Hernandez-Garduno，ISSCC 2007，1 Gb/s 5 抽头横向均衡器。）

### 接收 CTLE

| 优点 | 缺点 |
|---|---|
| 以很低的功耗和面积提供增益和均衡 | 一般只能做一阶补偿 |
| 能同时消除前标和长尾 ISI | 放大噪声和串扰 |
| | 对 PVT 敏感，难调 |

### 接收 DFE

| 优点 | 缺点 |
|---|---|
| 不放大噪声和串扰 | 不能消除前标 ISI |
| 抽头系数可以自适应，不需要反向信道 | 反馈路径时序关键 |
| | ISI 减法的时序使 CDR 鉴相更复杂 |

## 7.4 均衡效果

在一组信道上比较不同均衡组合，观察到：

- 2 抽头发送均衡带来很大的初始提升；
- 只用发送均衡时，2 抽头到 4 抽头差别不大；
- 接收均衡，特别是 DFE，能进一步提升性能；
- 但要注意：快速 DFE 很难做，因为反馈路径时序关键。

## 7.5 发送 FIR 均衡的时域视角

10 Gb/s 例子的系数：

$$W(z) = -0.131 + 0.595z^{-1} - 0.274z^{-2}$$

- 低频响应（各抽头直接相加）：$-0.131 + 0.595 - 0.274 = 0.190$；
- 奈奎斯特频率响应（各抽头按交替极性相加）：$0.131 + 0.595 + 0.274 = 1$。

## 7.6 频域视角

令 $z = e^{j2\pi fT_s}$：

- $f = 0$ 时 $|W| = 0.190$，即 −14.4 dB；
- $f = 1/(2T_s)$ 时 $|W| = 1$，即 0 dB。

均衡器有 **14.4 dB** 的频率峰化：把直流衰减 14.4 dB，奈奎斯特频率以 0 dB 通过。（$T_s = T_b$ = 100 ps）

## 7.7 发送 FIR 系数选择：MMSE

一种设系数的方法是最小均方误差（MMSE）算法。

**矩阵表示**

- 输入符号向量 $c$（长度 $l$）；
- 均衡矩阵 $W$：行数 $n + l - 1$（$n$ 为抽头数），列数 $l$；
- 信道矩阵 $H$：由信道脉冲响应（长度 $k$）构成的卷积矩阵，行数 $k + n + l - 2$，列数 $n + l - 1$；
- 输出 $y = H\,W\,c$。

**目标**：输出无 ISI，即期望输出 $Y_{des}$ 只在主标位置为 1，其余为 0。主标位置 = 信道前标采样数 + 均衡前标抽头数 + 1。

**孤立脉冲均衡**：取 $l = 1$（$c = [1]$），这时 $W$ 就是抽头向量 $w$。例：信道有 5 个前标、10 个后标采样，3 抽头均衡器（1 个前标抽头），期望输出在第 5 + 1 + 1 = 7 个位置为 1。

**求解**：误差 $E = Hw - Y_{des}$，对 $\|E\|^2$ 求导并令其为零：

$$\frac{d\|E\|^2}{dw} = 2H^TH\,w - 2H^TY_{des} = 0\quad\Rightarrow\quad w_{ls} = (H^TH)^{-1}H^TY_{des}$$

- 这样得到的 $w$ 使输出主标为 1，相当于一个**有增益**的 FIR 滤波器；
- 发送端有峰值功率限制，必须按抽头绝对值之和归一化：

$$w_{norm}(i) = \frac{w_{ls}(i)}{\sum_n |w_{ls}(n)|}$$

## 7.8 抽头精度

- 用上述 MMSE 算法对改进的服务器信道在 10 Gb/s 下求得 $W = [-0.131,\ 0.595,\ -0.274]$（前标、主标、后标），是 $w_{ls}$ 除以 2.6609 归一化的结果。
- 发送 DAC 精度一般只有 4–6 位，把系数映射到这个精度可能影响性能。

## 7.9 发送 FIR 电路结构

| | 直接 FIR | 分段 DAC |
|---|---|---|
| 做法 | 每个抽头一个并联输出驱动器 | 先在数字域组合抽头，再用 DAC 输出 |
| 输出管尺寸 | 每个驱动器都要按它可能的最大电流设计 | 只需按总峰值电流的最小尺寸 |
| 输出电容 | 较大 | 最小 |
| 功耗与复杂度 | 低 | 最高，需要映射表（RAM） |
| 灵活性 | 一般 | 非常灵活 |

**分段 DAC 例子**（Casper ISSCC 2006）：映射表每行对应一个 4 位数据图样，每列是 6 位权重；即"遇到这个 4 位图样，就发送这个 6 位数"。等于 4 个滤波后的位以 6 位精度并行输出，输出级只按最大总电流设计。

## 7.10 电压模式发送 FIR 驱动器

电压模式驱动器有串联阻抗，实现 FIR 均衡通常更难。

| 方案 | 做法 | 缺点 |
|---|---|---|
| 方案 1（Wong JSSC 2004，Sredojevic JSSC 2011） | 带对地分流路径的输出分压器，产生 FIR 需要的各个电压电平并保持阻抗受控 | 输出分段需要大量预驱动逻辑，复杂度随抽头精度增长；从 $V_{REF}$ 电源取的电流随时间变化 |
| 方案 2（Dettloff ISSCC 2010） | 加一条跨在两线之间的分流路径，同时保持阻抗受控、且从 $V_{REF}$ 取恒定电流 | 输出分段的预驱动逻辑更复杂 |
| 混合式（Song TCAS-II 2012） | 主抽头用电压模式（同样摆幅电流更小）；高精度预加重抽头用并联的电流模式驱动器，预驱动复杂度最低 | 仍有一些动态电流变化，但比方案 1 小 |

## 7.11 阻抗调制均衡（Sredojevic JSSC 2011；ISSCC 2014 论文 26.5）

> "An 8-to-16Gb/s 0.65-to-1.05pJ/b 2-Tap Impedance-Modulated Voltage-Mode Transmitter with Fast Power-State Transitioning in 65nm CMOS"

- 去加重越大，信号功率越低：**跳变位**时输出阻抗为 50 Ω（最大摆幅）；连续相同的位输出阻抗更高（去加重摆幅）。
- **相对均衡效果**取决于信道：反射严重的信道（中间走线的背板）残余 ISI 可能多 20% 以上；阻抗控制良好的信道（单板共面波导）几乎一样。
- **抽头控制**：分段的预驱动和输出级会随均衡精度提高而显著增加动态功耗。论文提出不分段的实现，用全局的阻抗调制/控制环和稳压器做模拟控制，把功耗摊销掉。
- 两种工作状态：跳变位时最大输出摆幅；游程长度大于 1 时用模拟控制产生去加重摆幅。
