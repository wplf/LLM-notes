# 第 12 讲 时钟数据恢复（CDR）

> [原讲义 PDF](https://people.engr.tamu.edu/spalermo/ecen689/lecture12_ee720_cdrs.pdf)

提纲：CDR 概述 → CDR 鉴相器 → 单环模拟 PLL 型 CDR → 双环 CDR → 相位插值器 → CDR 的抖动特性。

## 12.1 CDR 概述

- CDR 产生采样输入数据所需的时钟：有效频率必须等于输入数据率（10 Gb/s 对应 10 GHz），**或者**用多个间隔 100 ps 的时钟；还可能需要额外相位用于鉴相。
- 采样时钟必须有足够的时序裕量以达到目标 BER，CDR 本身的等效抖动要小。

### 两种主要实现

| | PLL 型 CDR | 双环 CDR |
|---|---|---|
| 结构 | 一个环路，鉴相器（PD）→ 环路滤波器 → VCO → 时钟 | 频率合成 PLL（全局）+ 每通道的相位恢复环（相位插值器 / 相位旋转器） |
| 特点 | 简单，但频率捕获范围有限 | 频率由全局 PLL 提供，相位由本地环调整，每通道独立 |

- 时钟频率和最佳相位从输入数据中提取，鉴相持续运行。
- **抖动跟踪受 CDR 带宽限制**；工艺进步使 CDR 带宽更高，源同步系统的抖动跟踪优势随之减弱。
- 其他实现：独立的 PLL；"双环"架构（PLL 或 DLL + 相位插值器）；相位旋转 PLL。

## 12.2 CDR 鉴相器

- CDR 与 PLL 的主要区别：输入**数据**不像 PLL 的参考时钟那样是周期性的。
- CDR 鉴相器必须在输入数据**缺失跳变**的情况下也能正常工作。

鉴相器比较输入数据与采样该数据的恢复时钟的相位，给出调整采样时钟相位的信息。分两类：

- **线性**鉴相器给出采样相位误差的**符号和大小**：Hogge。
- **非线性**鉴相器只给出误差的**符号**：Alexander（2 倍过采样，又称 bang-bang）。
- 另外还有过采样（> 2 倍）和波特率鉴相器。

### Hogge 鉴相器（线性）

- 在有数据跳变、且时钟为全速率的前提下：**late** 信号产生的脉冲宽度正比于输入数据与采样时钟的相位差。
- 同时用一个 $T_b/2$ 延迟产生 $T_b/2$ 参考信号。若时钟采样偏早，late 脉冲比 $T_b/2$ 短；偏晚则更长。
- 相位传递：0 rad 对应最佳采样点（采样时钟与数据之间 $T_b/2$，即 π）。

$$\phi_e = \phi_{in} - \phi_{clk} - \pi$$

- $K_{PD} = 1/(\pi\,TD)$，TD 为**跳变密度**：没有跳变就没有信息，随机数据取 0.5。
- 用 XOR 输出直接驱动电荷泵（Razavi），需要较高速度的电荷泵。

### Alexander（2 倍过采样）鉴相器

- 最常用的 CDR 鉴相器；非线性（二值）bang-bang，只给符号不给大小。
- 用 2 个数据采样加 1 个边沿采样：

| 条件 | 结论 |
|---|---|
| $D_n \ne D_{n+1}$（有跳变）且 $E_n = D_{n+1}$（或 $E_n \ne D_n$） | 时钟采样**偏晚** |
| $D_n \ne D_{n+1}$ 且 $E_n = D_n$（或 $E_n \ne D_{n+1}$） | 时钟采样**偏早** |

- 理想无噪声时，鉴相器只输出晚或早的脉冲，脉宽不变，零相位误差处增益无穷大。
- 有噪声时，总传递特性是理想 PD 特性与噪声 PDF 的卷积，噪声把鉴相器在峰峰抖动对应的相位范围内**线性化**：

$$K_{PD} \approx 2\,P_J\,TD$$

其中 $P_J$ 是峰峰抖动。TD 为跳变密度，随机数据取 0.5。

### Mueller-Muller 波特率鉴相器

- 波特率鉴相器每个符号只需要一个采样时钟。
- 思路：设法让脉冲前后采到的样本幅度相等。

$$\text{MM 输出} \propto \hat d_k \hat d_{k-1} - \hat d_k \hat d_{k+1}$$

（讲义写为 $\hat a_k\hat a_{k-1} - \hat a_k\hat a_{k+1}$ 形式的"有效 $h_{-1} - h_1$"。）

- 若结果为正，说明有效后标 ISI 偏大，采样偏早；为负说明前标 ISI 偏大，采样偏晚。
- 实现（Spagna ISSCC 2010）：比较当前样本与期望参考电平得到 $e_n$，再与相应数据样本 $d_n$ 做相关，得到前/后标信息：$e_n$ 给出 $d_{n-1}$ 的后标（$h_1$）信息，$e_{n-1}$ 给出 $d_n$ 的前标（$h_{-1}$）信息。
- 这需要额外的、阈值为 $|V_{REF}|$ 的误差采样器。
- 简化版 MM-PD 只考虑跳变图样：若连续两个误差样本不同，相位误差的极性由 $e_j$ 给出。

## 12.3 单环模拟 PLL 型 CDR

- 用线性化的 $K_{PD}$（Lee 的教程）。
- 用非线性鉴相器时，CDR 的"带宽"会随输入相位变化幅度而变；最终性能验证要用**时域非线性模型**。

### 实例：56 Gb/s PAM4 模拟 PLL 型 CDR（Roshan-Zamir JSSC 2019）

- 四分之一速率架构；3 个数据采样器做 PAM4 判决，1 个边沿采样器供 CDR 和 DFE 自适应，1 个误差采样器供阈值自适应（第 6 讲 6.11 有整体框图）。
- 用 PLL 型 CDR 降低功耗；bang-bang 鉴相器只对**对称的 PAM4 跳变**工作，以减少检测错误。
- **并行电荷泵**减小逻辑和环路延迟。
- LC-VCO 加额外的源极 LC 滤波改善相位噪声；CML 分频器产生 8 相四分之一速率时钟；2 倍过采样时钟发生器。

## 12.4 双环与相位插值器

### 单环 CDR 的问题

- 鉴相器的频率捕获范围有限，导致锁定时间长甚至锁不上；
- 可能锁到正确时钟频率的谐波上；
- 只用鉴相器时，VCO 频率范围随 PVT 的变化可能超出 PLL 的锁定范围。

### 基于相位插值器（PI）的 CDR

- 频率合成环可以是**全局** PLL。
- 但多相时钟长距离分配困难：要保持相位间隔，且时钟分配功耗随相位数增加。
- 如果 CDR 需要超过 4 个相位，就考虑本地产生相位。

### 用 DLL 本地产生相位

- 全局 PLL 只分配差分时钟；本地 DLL 产生相位插值器所需的多相时钟。
- DLL 可以每通道一个，也可以几个（如 4 个）共享。
- 前向时钟系统中可以直接用前向时钟替换频率合成 PLL，架构相同。

### 相位旋转 PLL

- 相位插值器在功耗和面积上都比较贵。
- 相位旋转 PLL 把**一个**插值器放在 PLL 反馈路径里，同时调整 VCO 的全部输出相位。
- 代价是频率合成环和相位恢复环耦合在一起，需要 PLL 带宽高于相位环；好处是有滤除 VCO 噪声的作用。

### 相位插值器

- 实现数字到相位的转换（DPC），输出是两个输入时钟相位的加权和。
- 常见结构：尾电流求和插值、电压模式插值。
- 码映射方式：正弦映射、线性映射。

**正弦插值**：输入 I/Q 两路正交时钟 $X_I = A\sin(\omega t)$、$X_Q = -A\cos(\omega t)$，加权求和：

$$Y = a_1X_I + a_2X_Q = A(a_1\sin\omega t - a_2\cos\omega t) = A\sin(\omega t + \phi),\quad \phi = \tan^{-1}(a_2/a_1)$$

只要 $a_1 = \cos\phi$、$a_2 = \sin\phi$ 且 $a_1^2 + a_2^2 = 1$，就能得到任意相位。

**正弦与线性映射**：$a_1^2 + a_2^2 = 1$ 的电路难做，实际常用线性加权 $a_1 + a_2 = 1$，代价是相位非线性。

**插值器模型**（Weinlader）：插值线性度取决于相位间隔 $\Delta t$ 与输出时间常数 RC 之比。输出时间常数太小（太快）会影响相位混合质量；输入是理想阶跃时 vs 有限跳变时间时结果不同。

**电路**

- **尾电流求和 PI**（Bulzacchelli JSSC 2006）：控制 I/Q 极性可以覆盖 360° 相位旋转，相位步进由加权 DAC 的分辨率决定。要在宽频率范围内线性，关键是控制输入或输出的时间常数（摆率）。
- **电压模式求和 PI**（Joshi VLSI 2009）：同样要注意时间常数控制。

### 延迟锁定环（DLL）

- DLL 锁定压控延迟线（VCDL）的延迟，通常锁到一个或半个输入时钟周期。锁到半个周期时对时钟占空比敏感。
- DLL **不自己产生**输出时钟，只延迟输入时钟。
- **延迟传递函数**：延迟线不引入（低频）极点，所以是一阶环路；参考与反馈信号之间的延迟被低通滤波。只要连续时间近似成立（$\omega_n < \omega_{ref}/10$）就无条件稳定（Maneatis）。

## 12.5 CDR 的抖动特性

### 抖动传递（jitter transfer）

- 指输入抖动有多少"传递"到输出；如果 PLL 的相位传递函数有峰化，抖动甚至会被**放大**。
- 测量方法（Walker）：给系统输入时钟加正弦相位调制，测量恢复时钟上的正弦输出。

### 抖动产生（jitter generation）

- 指 CDR 自己"产生"多少抖动，一般认为由 VCO 主导，假设输入数据无抖动：

$$|H(s)| = \left|\frac{\phi_{out}}{\phi_{VCO}}\right| = \left|\frac{s\left(s + \frac{\zeta\omega_n}{2}\right)}{s^2 + \zeta\omega_n s + \omega_n^2}\right|$$

CDR 中 N 取 1。这是高通传递函数，抖动会累积到 $1/\text{PLL 带宽}$ 对应的时间。SONET 规范要求输出 RMS 抖动 ≤ 0.01 UI。

### 抖动容限（jitter tolerance）

- 指 CDR 在仍能达到给定 BER 的前提下能"容忍"多大的正弦抖动：

$$JTOL(\omega) = \frac{\phi_{in}}{\phi_{out} - \phi_{in}} = \frac{1}{1 - T(s)}\quad\text{（讲义形式）}$$

直观地说，容限等于允许的最大相位误差除以 (1 − 抖动传递函数)。

- **测量方法**：随机抖动和正弦抖动由调制 BERT 的时钟加入，确定性抖动由数据经过信道加入。对每个频率，逐步增大正弦抖动幅度，直到达到最低可接受的 BER（10⁻¹²）。
- 曲线在 CDR 带宽以内随频率下降，带宽以外变平坦。

## 12.6 要点

- CDR 提取出采样输入数据符号所需的正确时钟频率和相位。
- 需要专门针对随机数据符号设计的鉴相器。
- 常用双环 CDR，既能优化抖动性能，又能提供稳健的频率捕获。
- 抖动容限是 CDR 的重要指标，提高环路带宽可以改善它。
