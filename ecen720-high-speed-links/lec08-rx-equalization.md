# 第 8 讲 接收端 FIR、CTLE、DFE 与自适应均衡

> [原讲义 PDF](https://people.engr.tamu.edu/spalermo/ecen689/lecture8_ee720_rx_adaptive_eq.pdf)

提纲：接收 FIR 均衡 → 接收 CTLE → 接收 DFE → 均衡自适应技术 → 高级调制与其他技术。

## 8.1 接收 FIR 均衡

- 把模拟输入信号延迟，乘以均衡系数后求和。
- 优缺点见第 7 讲 7.3 节。

### 接收均衡的噪声增强

- 线性接收均衡器不区分信号、噪声和串扰。
- 信号与失真（ISI）之比改善了，但 **SNR 不变**。

### 模拟接收 FIR 实例

Hernandez-Garduno，ISSCC 2007：5 抽头，抽头间隔 $T_b/2$，用三阶延迟单元实现，1 Gb/s 实测。

### 数字接收 FIR

- 用高速、中低精度 ADC 把输入数字化，在数字域做均衡：数字延迟、乘法器、加法器。
- 受 ADC 精度限制；ADC 很快、数字滤波器也要很快，功耗可能很高。
- **实例**（Harwood ISSCC 2007）：65 nm，12.5 GS/s、4.5 位 flash ADC，2 抽头 FFE + 5 抽头 DFE。收发器总功耗（含发送）330 mW，其中模拟 245 mW、数字 85 mW。

## 8.2 接收 CTLE

- 用无源 R-C（或 L）网络实现高通传递函数来补偿信道损耗；
- 能同时消除前标和长尾 ISI；
- 可以纯无源，也可以和放大器结合提供增益。

### 无源 CTLE

$$H(s) = \frac{R_2}{R_1 + R_2}\cdot\frac{1 + sR_1C_1}{1 + s\dfrac{R_1R_2}{R_1 + R_2}(C_1 + C_2)}$$

- 零点 $\omega_z = 1/(R_1C_1)$，极点 $\omega_p = (R_1 + R_2)/[R_1R_2(C_1 + C_2)]$；
- 直流增益 $R_2/(R_1 + R_2)$，高频增益 $C_1/(C_1 + C_2)$，峰化 = 高频增益 / 直流增益。
- 线性极好，但在奈奎斯特频率处**没有增益**。

### 有源 CTLE

- 带 RC 源极退化的输入放大器（Gondi JSSC 2007）。

$$H(s) = \frac{g_m}{C_P}\cdot\frac{s + 1/(R_SC_S)}{\left(s + \dfrac{1 + g_mR_S/2}{R_SC_S}\right)\left(s + \dfrac{1}{R_DC_P}\right)}$$

- 零点 $\omega_z = 1/(R_SC_S)$；第一极点 $\omega_{p1} = (1 + g_mR_S/2)/(R_SC_S)$；第二极点 $\omega_{p2} = 1/(R_DC_P)$。
- 直流增益 $g_mR_D/(1 + g_mR_S/2)$，理想峰值增益 $g_mR_D$，理想峰化 $1 + g_mR_S/2$。
- 在奈奎斯特频率处能提供增益；可能受放大器增益带宽限制；放大器要按输入线性范围设计。
- 通常发送均衡也会提供一些低频衰减。
- 对 PVT 敏感，难调；一般只能做一阶补偿。

### 有源 CTLE 的调节

调节退化电阻和电容来移动零点和第一极点，从而设定峰化和直流增益：

- **增大 $C_S$**：零点和第一极点一起移向低频，（理想情况下）峰化不变；
- **增大 $R_S$**：零点移向低频，峰化增大（直流增益降低），对第一极点影响很小。

## 8.3 接收 DFE

- DFE 是**非线性**均衡器：判决器先做符号判决（量化输入），然后用反馈 FIR 滤波器把 ISI 直接从输入中减掉：

$$z_k = y_k - w_1\tilde d_{k-1} - w_2\tilde d_{k-2} - \cdots - w_n\tilde d_{k-n}$$

| 优点 | 缺点 |
|---|---|
| 可以提升高频成分而不放大噪声和串扰 | 不能消除前标 ISI |
| 抽头系数可以自适应，不需要反向信道 | 有误码传播的可能（实际链路 BER 10⁻¹² 时很小） |
| | 反馈路径时序关键 |
| | ISI 减法的时序使 CDR 鉴相更复杂 |

### DFE 系数

- 只用 DFE 时，DFE 抽头应等于**未均衡**信道脉冲响应的后标值 $[a_1, a_2, \dots, a_n]$。
- 与其他均衡器一起用时，DFE 抽头应等于 DFE **之前**的脉冲响应后标值。
- DFE 给其他均衡电路的优化带来灵活性：例如优化发送均衡时可以不管 DFE 会处理的那些 ISI 项。

### 直接反馈 DFE 实例（TI，Payne JSSC 2005）

- 6.25 Gb/s，4 抽头，半速率架构，自适应抽头算法；
- 第 1 抽头的时序在**半个 UI**内闭合，以便自适应抽头和 CDR 都能收敛；
- 抽头精度：TAP1 5 位；TAP2 4 位 + 符号；TAP3、TAP4 3 位 + 符号。

**关键路径**：必须在一个位周期内完成判决并反馈：

$$t_{CLK\text{-}Q,SA} + t_{MUX} + t_{PROP} < 1\ \text{UI}$$

（TI 的设计实际上在 0.5 UI 内完成。）

### DFE 循环展开（推测）

- 不在 1 UI 内反馈并减去 ISI，而是把环路展开，**预先算好两种可能**（1 抽头 DFE）：用两个阈值分别为 $+w_1$ 和 $-w_1$ 的判决器，再根据上一位的判决结果选一个。
- 抽头越多，比较器数量按 $2^{\text{抽头数}}$ 增长。

### DFE 求和器

- **电阻负载求和器**：求和器性能对 DFE 至关重要，必须在一定精度（> 95%）内建立才能消除 ISI。摆幅（$IR$）和建立时间（$RC$）之间有取舍，可能需要很大的输入和抽头偏置电流。
- **积分求和器**（Park ISSCC 2007）：把电流积分到负载电容上，消除 RC 建立时间。因为 $T/C > R$，同样摆幅下偏置电流可以减小，典型减小 3 倍。

### 带 IIR 反馈的 DFE（Liu ISSCC 2009）

- 2 抽头 FIR 反馈的 DFE 只能消除前两个后标的 ISI。
- **"平滑"信道**（如片上导线、硅载板导线）的长尾 ISI 可以近似为指数衰减 $e^{-t/\tau}$，用 FIR 反馈需要很多抽头。
- 做法：大的第一后标 H1 用普通 FIR 抽头消除；从第二后标开始的平滑长尾用**低通 IIR 反馈滤波器**消除。前提是信道足够平滑（反射不多）。
- 实现：积分求和器加再生 PMOS，实现部分判决（合并的求和器与部分判决器）；低通时间常数由 $R_D$、$C_D$ 实现，幅度由 $R_D$ 和 $I_D$ 控制；通过多路器实现 2 UI 延迟，从第二后标开始消除。

## 8.4 均衡器的自适应

- 最简单的做法是针对具体系统固定均衡值（抽头、零极点），按实验室测量选最优值；但对制造和环境变化敏感。
- **自适应**可以针对不同的信道、环境条件和速率优化均衡器。
- 关键问题：
    - 提取均衡的修正（误差）信号；
    - 自适应算法和硬件开销；
    - 把修正信息送到均衡器电路。

### 发送 FIR 自适应：误差提取（Stojanovic JSSC 2005）

- 调发送 FIR 时要在接收输入端测量响应。
- 自适应（误差）信息通常通过比较接收输入与期望的符号电平 dLev 得到。
- 这需要接收端额外的、阈值可编程的采样器。

### 符号-符号 LMS 算法

实现简单，常用于抽头自适应：

$$w_{k+1}^{(n)} = w_k^{(n)} + \mu\,\text{sign}(e_k)\,\text{sign}(d_{k-n})$$

其中 $e_k$ 是相对期望电平的误差，$d_{k-n}$ 是接收数据，$n$ 为抽头序号。期望电平取决于发送摆幅和信道损耗，事先不一定知道，也要自适应：

$$dLev_{k+1} = dLev_k + \mu\,\text{sign}(e_k)$$

### 反向信道

要把抽头更新信息送回发送端，需要一个反向信道：

- **共模反向信道**（Stojanovic JSSC 2005）：在同一对差分线上，用低速（约 10 Mb/s）共模信号从接收端传回发送端。
- **数据编码反向信道**（Stonick JSSC 2003）：用接收端那一侧的高速发送通道把信息传回；利用数据编码的灵活性（8B10B/Q），在不增加数据开销的前提下传送低速的抽头信息。

### CTLE 的调节

| 方法 | 原理 |
|---|---|
| 功率谱密度测量（Lee JSSC 2006） | 理想随机数据的低频功率和高频功率之比是可预测的（$s_x(f) = T_b\,\text{sinc}^2(fT_b)$，分界频率 $f_m \approx 0.28/T_b$），用两者的误差做伺服环调 CTLE |
| 输出幅度测量（Uchiki ISSCC 2008） | 把均衡后的数据近似为正弦波，比较低频和高频的平均幅度，调到高频峰峰摆幅等于低频峰峰摆幅 |
| 数据边沿分布监测（Gerfers JSSC 2008） | 用亚周期精度过采样数据，得到边沿分布的宽度和形状；目标是使边沿分布的标准差最小（等价于眼开度最大） |

### DFE 的调节

- **FIR 反馈 DFE**（Payne JSSC 2005）：在边沿处 2 倍过采样均衡后的信号，既可以提取自适应 DFE 的信息，也可以驱动 CDR；用符号-符号 LMS 调 DFE 抽头。
- **IIR 反馈 DFE**：Huang ISSCC 2011 给出了对应的自适应方法。

## 8.5 高级调制与其他技术

### 高级调制

- 消除 ISI 的思路是把信道响应拉平到奈奎斯特频率。
- 想要频率相关损耗小一些，就用更高级的调制把奈奎斯特频率降下来：4-PAM（或更高）、双二进制（duo-binary）。见第 4 讲。

### 多音（multi-tone）信号

- 不再均衡到基带奈奎斯特频率，而是把信道分成多个频带，每个频带内的频率相关损耗较小，均衡复杂度更低；需要上/下变频。
- 离散多音（DMT）用在信道极差的 DSL 调制解调器中：速率较低，可以跑高性能 DSP。
- 最近一些高速链路研究原型也开始采用：例如 2 个频带共 30 Gb/s（10 Gb/s 双二进制 + 2 个正交载波，Beyene AdvPack 2008）；15 个频带共 56 Gb/s（Kim ISSCC 2019）。
