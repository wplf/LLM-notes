## 2.1 信道元件

一条背板信道依次经过：发送芯片封装 → 线卡走线 → 线卡过孔 → 边缘连接器 → 背板过孔 → 16″ 背板走线 → 背板过孔 → 边缘连接器 → 线卡过孔 → 线卡走线 → 接收芯片封装。

### 芯片封装

| 封装类型 | 引脚数 |
|---|---|
| 小外形封装（SOP） | 8–56 |
| 四方扁平封装（QFP） | 64–304 |
| 塑料球栅阵列（PBGA） | 256–420 |
| 增强球栅阵列（EBGA） | 352–896 |
| 倒装焊球栅阵列（FC-BGA） | 1089–2116 |

- 封装技术的引脚数增长赶不上片上总带宽的增长，导致设计受 I/O 限制，每个引脚的速率只能越来越高。
- 键合线是最常见的贴片方式；倒装焊散热更好；芯片上的二维焊球阵列可以引出更多信号，信号和电源阻抗也更低。

**封装模型**

- 键合线：L ≈ 1 nH/mm，有互感 K，耦合电容约 20 fF/mm；
- 封装走线：L ≈ 0.7–1 nH/mm，有互感，对层电容约 80–90 fF/mm，耦合电容约 40 fF/mm。
- 倒装焊封装的芯片接口阻抗低得多（Intel 的对比数据）。

### 印制电路板（PCB）

- 元件焊在正面（和背面）。典型板子有 4–8 个信号层和同样数量的电源/地层；背板可以超过 30 层。
- **叠层**：信号通常在表层和底层；内部是电源/地平面对和信号层对交替。
- 典型铜厚：信号层 "0.5 oz"（17.5 μm），电源层 "1 oz"（35 μm）。

### 连接器

- 用于板间传信号，差分对密度典型为 16–32 对 / 10 mm。
- 连接器内部要保持合适的差分阻抗；串扰可能成为问题。

### 过孔

- 连接 PCB 各层：钻孔后孔壁镀铜；焊盘连接信号层走线，避让孔避开电源层。
- 对信号密度和完整性都很"贵"：占用好几条走线通道；阻抗通常偏低，并产生**残桩（stub）**。
- **连接器处过孔残桩的影响**：老式背板用普通直通过孔，残桩造成很深的频率零点，严重破坏信号完整性；改进的背板用昂贵的**背钻**过孔去掉残桩。

### PCB 走线形式

- **微带线**：在 PCB 外表面，不封闭，容易受串扰；
- **带状线**：夹在两层地平面之间，隔离更好。

## 2.2 导线模型

（与 EE273 第 2 讲基本相同，这里只列要点和新数据。）

- **电阻** $R = \rho l / (wh)$：由电阻率和几何形状决定，造成损耗和延迟。
- **电容**：由介电常数和几何形状决定；介电常数越低越好（电容小、速度快）。
- **电感**：由磁导率和**闭合回路**几何决定；均匀介质中 $LC = \mu\varepsilon$。

**模型选择**：理想 / 集总 C、R、L / RC 线 / LC 线 / RLGC 线。频率高于 $f_0 = R/(2\pi L)$ 时用 LC 或 RLGC 模型。

| 导线 | R | L | C | $f_0$ |
|---|---|---|---|---|
| AWG24 双绞线 | 0.08 Ω/m | 400 nH/m | 40 pF/m | 32 kHz |
| PCB 走线 | 5 Ω/m | 300 nH/m | 100 pF/m | 2.7 MHz |
| 片上最小宽度 M6（0.18 μm） | 40 kΩ/m | 4 μH/m | 300 pF/m | 1.6 GHz |

片上线直到 1.6 GHz 都是 RC 线。

## 2.3 传输线

### RLGC 传输线方程与时谐解

假设角频率为 ω 的正弦行波，传输线方程变为：

$$\frac{d^2V(x)}{dx^2} = \gamma^2 V(x),\qquad \gamma = \alpha + j\beta = \sqrt{(R + j\omega L)(G + j\omega C)}$$

解为前向波和反向波之和：$V(x) = V_f e^{-\gamma x} + V_r e^{\gamma x}$。

- 实部 α：每单位长度的衰减（Np/m）；
- 虚部 β：每单位长度的相移（rad/m）；
- 相速度 $v = \omega/\beta$。

### 特性阻抗

$$Z_0 = \sqrt{\frac{R + j\omega L}{G + j\omega C}}$$

无限长线上的电压电流比；驱动一根端接 $Z_0$ 的线等同于驱动无限长线。

### 无损 LC 线

R = G = 0 时 $\gamma = j\omega\sqrt{LC}$，$Z_0 = \sqrt{L/C}$，$v = 1/\sqrt{LC}$。波无畸变传播，速度和阻抗与频率无关，阻抗为纯实数。

### 低损耗 RLC 线

当 $R/(\omega L)$ 和 $G/(\omega C)$ 都远小于 1 时：

$$\alpha \approx \frac{R}{2Z_0} + \frac{GZ_0}{2} = \alpha_R + \alpha_D$$

- 行为接近理想 LC 线，但有电阻损耗和介质损耗；
- 传播速度随频率变化造成色散：快速的阶跃之后跟一条慢慢爬升的直流尾巴。

## 2.4 频率相关的损耗

$$V(x) = V(0)\,e^{-(\alpha_R + \alpha_D)x}$$

两项都随频率增大，但增速不同。

### 趋肤效应（电阻损耗）

- 趋肤深度 $\delta = 1/\sqrt{\pi f \mu\sigma}$，随 $\sqrt f$ 减小。
- 在临界频率 $f_s$（趋肤深度等于导体厚度的一半或半径）以上，电阻和损耗按 $\sqrt f$ 增长：

$$R(f) = R_{DC}\sqrt{f/f_s},\qquad \alpha_R = \frac{R_{DC}}{2Z_0}\sqrt{f/f_s}$$

- 例：5 mil 带状线 $R_{DC}$ = 7 Ω/m，$f_s$ = 43 MHz；30 AWG 双绞线 $R_{DC}$ = 0.08 Ω/m，$f_s$ = 67 kHz。

### 介质吸收

- 交变电场使介质分子转动，以热的形式吸收信号能量。
- 用损耗角正切表示：$\tan\delta_D = G/(\omega C)$；
- $\alpha_D = \dfrac{GZ_0}{2} = \pi f\sqrt{LC}\tan\delta_D$，与频率**成正比**。

### 总损耗与先进板材

- 高频时介质损耗占主导。
- 先进板材在 56 GHz 下的损耗：PTFE（Teflon）约 1.1 dB/in，Tachyon 约 1.6 dB/in，Megtron 6 约 2 dB/in。
- 按 25 dB 的损耗预算算可走的距离：Megtron 6 为 12.5″，Tachyon 15.6″，PTFE 22.7″。
- **电缆**互联可以支持约 1.5 m。

### 电缆背板

用电缆替代背板走线、配合很短的子卡，可以在 224 Gb/s 下支持约 1 m 的距离（Ghiasi，IEEE 802.3，2017）。

## 2.5 反射与电报方程

把线等效为戴维南源（$2V_i$ 串 $Z_0$）接到端接 $Z_T$ 上，用 KCL 解出：

$$k_r = \frac{V_r}{V_i} = \frac{Z_T - Z_0}{Z_T + Z_0}$$

## 2.6 端接实例

源阻抗 $R_S$、线 $Z_0$ = 50 Ω、$t_d$ = 1 ns、端接 $R_T$，输入 1 ns 时刻开始的阶跃：

| 情况 | $R_S$ | $R_T$ | 现象 |
|---|---|---|---|
| 理想 | 50 Ω | 50 Ω | 无反射 |
| 开路 | 50 Ω | ∞ | 远端全正反射 |
| 短路 | 50 Ω | 0 | 远端全负反射 |
| 任意 | 400 Ω | 600 Ω | 远端依次为 0.111、0.205、0.278 V…，最终"振铃"到直流分压值 0.6 V |

**反射模式**（看两端反射系数的符号）：

| $R_S$ | $R_T$ | $k_{rS}$ | $k_{rT}$ | 波形 |
|---|---|---|---|---|
| 25 Ω | 25 Ω | < 0 | < 0 | 收敛 |
| 25 Ω | 100 Ω | < 0 | > 0 | 振荡 |
| 100 Ω | 25 Ω | > 0 | < 0 | 振荡 |
| 100 Ω | 100 Ω | > 0 | > 0 | 阶梯式爬升 |

## 2.7 端接方案

| 方案 | 特点 |
|---|---|
| 不端接 | 几乎没有东西吸收线上的能量，可能振荡；线长必须远小于跳变时间，满足 $t_r > n \cdot 2l\sqrt{LC}$，n = 4–6。片外很少用 |
| 源端端接 | 源端输出分两步上升；用于中速点对点连接 |
| 接收端端接 | 接收端无反射；要注意中途的阻抗不连续，驱动端几乎不吸收反射 |
| **两端端接** | 反射最少，两端都吸收反射；摆幅只有单端端接的一半。**高性能串行链路最常用** |

## 2.8 差分信号

（与 EE273 第 6 讲相同。）

- 优点：自带参考、抑制共模噪声、摆幅加倍、自身引起的电源噪声更小。
- 信号引脚是单端的 2 倍，但电源/回流引脚比例更低，总引脚开销通常是 1.3–1.8 倍。

## 2.9 奇模与偶模

- **偶模**：两线以相同电压驱动，只激起偶模。
- **奇模**：两线以等幅反相电压驱动，只激起奇模。对差分对（奇模），两导体之间存在一个**虚拟参考平面**，提供连续的回流路径；电场垂直于该平面，磁场与之相切。

**平衡传输线**

- 偶模（共模）激励：等效电容 $C_C$，等效电感 $L + M$；
- 奇模（差模）激励：等效电容 $C_C + 2C_d$，等效电感 $L - M$。

$$Z_{even} = \sqrt{\frac{L+M}{C_C}},\qquad Z_{odd} = \sqrt{\frac{L-M}{C_C + 2C_d}},\qquad Z_{DIFF} = 2Z_{odd},\quad Z_{CM} = \frac{Z_{even}}{2}$$

## 2.10 π 形端接与 T 形端接

**π 形**：每根线对地接 $R_1$，两线之间接 $R_2$：

$$R_1 = Z_{even},\qquad R_2 = \frac{2Z_{even}Z_{odd}}{Z_{even} - Z_{odd}}$$

**T 形**：两线各串 $R_1$ 到中点，中点再经 $R_2$ 到地：

$$R_1 = Z_{odd},\qquad R_2 = \frac{Z_{even} - Z_{odd}}{2}$$

两者都能同时匹配奇模和偶模。
