## 10.1 眼图与规范模板

- 链路必须在电压域**和**时间域都有裕量才能正常工作。
- 为了让发送器和接收器能独立设计（互操作），规范里用**眼图模板**。
- 接收采样器处的眼图会被接收时钟的时序噪声（抖动）进一步压缩。

## 10.2 抖动的定义

抖动是"信号相对其理想时间位置的短期变化"。

| 测量 | 定义 | 用途 |
|---|---|---|
| 周期抖动 $J_{PER}$ | 测得的周期与理想周期之差 | |
| 周期间抖动 $J_{CC}$ | 相邻两个周期之差 | 片上数字电路周期时间预算 |
| 累积抖动 $J_{AC}$ | 测得的时钟与理想触发时钟之差 | **与高速链路最相关** |

## 10.3 抖动的统计参数

- **均值**：可以理解为固定的时序偏移（偏斜），一般可以校正，不太重要。
- **RMS 抖动**：适合描述抖动的随机分量。
- **峰峰抖动**：同时取决于确定性（有界）和随机（无界）分量；因为随机部分无界，**必须在给定 BER 下给出**。

### 计算例子

| | n=1 | 2 | 3 | 4 | 均值 | RMS | 峰峰 |
|---|---|---|---|---|---|---|---|
| $J_{PER}$ | −0.06 | 0.02 | −0.06 | 0.12 | 0.005 | 0.085 | 0.18 |
| $J_{CC}$ | 0.08 | −0.08 | 0.18 | – | 0.06 | 0.131 | 0.26 |
| $J_{AC}$ | −0.07 | −0.05 | −0.11 | 0.01 | −0.055 | 0.05 | 0.12 |

## 10.4 抖动直方图

- 用来提取抖动的 PDF：统计阈值（过零）时刻的分布。
- 它同时包含确定性和随机分量；要准确估计给定 BER 下的抖动，必须把两者分解开。

## 10.5 抖动的分类

```
总抖动 TJ
├── 随机抖动 RJ
└── 确定性抖动 DJ
    ├── 正弦/周期抖动 SJ (PJ)
    ├── 数据相关抖动 DDJ
    │   ├── 占空比失真 DCD
    │   └── 码间干扰 ISI
    └── 有界不相关抖动 BUJ
```

## 10.6 随机抖动（RJ）

- 无界，用高斯分布建模，假设均值为零，用 RMS 值 $\sigma_{RJ}$ 描述：

$$PDF_{RJ}(t) = \frac{1}{\sigma_{RJ}\sqrt{2\pi}}\exp\!\left(-\frac{t^2}{2\sigma_{RJ}^2}\right)$$

- 峰峰值必须在给定 BER 下给出。
- 来自器件噪声：热噪声、散粒噪声、闪烁噪声。

## 10.7 确定性抖动（DJ）

- 有界，峰峰值可以预测。
- 成因：传输线损耗、占空比失真、扩频时钟、串扰。

### 正弦 / 周期抖动（SJ 或 PJ）

- 以固定频率重复，来自调制效应：扩频时钟、PLL 参考时钟馈通。
- 可以分解为正弦的傅里叶级数：$SJ(t) = \sum_i A_i\cos(\omega_i t + \theta_i)$。
- 单个正弦产生的抖动 PDF 是"浴盆形"（两端高中间低）：

$$PDF_{SJ}(t) = \frac{1}{\pi\sqrt{A^2 - t^2}},\quad |t| < A$$

### 数据相关抖动（DDJ）

与发送数据图样或攻击者（串扰）数据图样相关，成因包括串行化时钟的相位误差、信道滤波和串扰。

**占空比失真（DCD）**

- 来自发送串行化时钟的占空比误差和串行化后缓冲器的上升/下降延迟失配。
- PDF 是两个 δ 函数之和：

$$PDF_{DCD}(t) = \frac12\left[\delta\!\left(t - \frac{DCD}{2}\right) + \delta\!\left(t + \frac{DCD}{2}\right)\right]$$

**码间干扰（ISI）**

- 来自信道损耗、色散和反射。均衡可以改善 ISI 抖动（讲义对比了无均衡和 2 抽头发送均衡的抖动）。

### 有界不相关抖动（BUJ）

- 与数据流在时间上不对齐，最常见的来源是串扰。
- 叫"不相关"是因为它与攻击信号相关，而与受害信号（数据流）无关。
- 虽然不相关，但仍是有界的，有可量化的峰峰值。

## 10.8 总抖动（TJ）

总抖动 PDF 是随机抖动和确定性抖动 PDF 的**卷积**：

$$PDF_{TJ} = PDF_{RJ} * PDF_{DJ},\qquad PDF_{DJ} = PDF_{SJ} * PDF_{DCD} * PDF_{ISI} * PDF_{BUJ}$$

## 10.9 抖动与误码率

- 抖动包含确定性和随机分量，总抖动必须在给定 BER 下给出。
- 讲义的例子：BER = 10⁻¹² 时抖动约 1675 ps，眼宽裕量约 200 ps；系统可能在达到 BER = 10⁻¹⁸ 之前都不受抖动限制。

## 10.10 双狄拉克抖动模型

- 做系统级抖动预算时，双狄拉克模型用一个简化形式近似复杂的总抖动 PDF，便于分别预算确定性和随机抖动。
- 确定性部分近似为相距 $DJ(\delta\delta)$ 的两个 δ 函数，与高斯随机抖动卷积：

$$PDF_{TJ}(t) = \frac{1}{2\sigma_{RJ}\sqrt{2\pi}}\left[e^{-\frac{(t - DJ/2)^2}{2\sigma_{RJ}^2}} + e^{-\frac{(t + DJ/2)^2}{2\sigma_{RJ}^2}}\right]$$

### 给定 BER 下的抖动

同时考虑前沿和后沿：

$$BER(t) = \frac{\rho_T}{2}\left[\text{erfc}\!\left(\frac{t - DJ/2}{\sqrt2\sigma_{RJ}}\right) + \text{erfc}\!\left(\frac{UI - t - DJ/2}{\sqrt2\sigma_{RJ}}\right)\right]$$

其中只有靠近各自边沿的那一项占主导，$\rho_T$ 是跳变密度。

### 从测量提取模型参数

- 把测得的抖动 PDF 画在 **Q 刻度**上：$Q(BER) = \sqrt2\,\text{erfc}^{-1}(2BER/\rho_T)$，跳变密度通常取 0.5。
- 两侧的尾巴（在 Q 刻度上是直线）用来提取 $\sigma_{RJ}$；
- 外推到 Q = 0，得到双狄拉克 δ 函数的间隔 $DJ(\delta\delta)$。
- 注意 $DJ(\delta\delta)$ 是模型参数，与实际确定性抖动的峰峰值 $DJ_{pp}$ 不同。
- 提取出的双狄拉克模型与测得的抖动 PDF 吻合良好。

## 10.11 系统抖动预算

系统要达到最低 BER，需要：

$$UI \ge DJ_{sys}(\delta\delta) + 2Q(BER)\,\sigma_{RMS,sys}$$

- 各个确定性抖动分量的卷积近似为**线性相加**：$DJ_{sys} = \sum_i DJ_i$；
- 各个随机抖动分量的卷积给出**平方和开根**：$\sigma_{sys} = \sqrt{\sum_i\sigma_i^2}$。

### 例：PCI Express 系统

$$DJ_{sys} = DJ_{TX} + DJ_{channel} + DJ_{RX} + DJ_{clock}$$

$$\sigma_{sys} = \sqrt{\sigma_{TX}^2 + \sigma_{channel}^2 + \sigma_{RX}^2 + \sigma_{clock}^2}$$

讲义按 Hall 书上的 PCIe 抖动模型给出各项数值；BER = 10⁻¹² 时随机抖动按 $2\times7.03 = 14.069$ 倍 σ 计入。
