# 第 9 讲 噪声源

> [原讲义 PDF](https://people.engr.tamu.edu/spalermo/ecen689/lecture9_ee720_noise_sources.pdf) · 参考：Stateye 理论论文

本讲前半部分与 EE273 第 4、5 讲高度重合（同样基于 Dally 教材），后半部分的**统计 ISI 分析**是新增内容。

## 9.1 高速链路中的噪声

多种噪声源会削减链路的时序裕量和幅度裕量。

## 9.2 噪声源概览

| 噪声源 | 成因 |
|---|---|
| 电源噪声 | 开关电流流过有限的电源阻抗，造成随时间和位置变化的电压降 |
| 接收器失调 | 器件随机失配 |
| 串扰 | 攻击信号干扰受害信号：片上（容性）耦合；片外（传输线）耦合，分近端和远端 |
| 码间干扰 | 信号色散造成信号自己干扰自己 |
| 随机噪声 | 热噪声、散粒噪声；时钟抖动分量 |

## 9.3 有界噪声与统计噪声

| | 有界（确定性）噪声 | 统计（随机）噪声 |
|---|---|---|
| 特点 | 有理论上可预测的值和明确的最坏界，可以做简单（但偏悲观）的最坏情况分析 | 当作随机过程（来源可能是伪随机的），常用高斯统计描述：RMS 值、概率密度函数 |
| 例子 | 对少量通道的串扰、ISI、接收器失调 | 热噪声、时钟抖动分量、对大量通道的串扰 |

**分清一个噪声源是有界的还是随机的，对准确估计链路性能至关重要。**

## 9.4 比例噪声与独立噪声

- **比例噪声**（与信号摆幅成正比）：串扰、同时开关的电源噪声、ISI。不能靠加大信号压过去。
- **独立噪声**：接收失调、非 I/O 的电源噪声。可以压过去。

$$V_N = K_N V_S + V_{NI}$$

## 9.5 电源噪声

- 电路从 VDD 网络取电流、把电流还给 GND 网络；供电网络阻抗有限；随时间变化的开关电流引起电源电压波动。
- 一个电路看到的电源噪声取决于它在供电网络中的位置。

### 电源布线（Hodges）

| 布线方式 | 结果 |
|---|---|
| 差 | 模块 B 经过模块 A 取电，噪声过大 |
| 较好 | B 只看到一半噪声，代价是穿过模块的电源走线加倍 |
| 更好 | A、B 看到相近的电源噪声 |
| 最好 | A、B 更加隔离 |

### 电源引起的延迟变化

- CMOS 延迟大致与 VDD 成反比关系变化：

$$t_{PHL} \approx \frac{C_L\,V_{DD}/2}{I_{DSAT}} \propto \frac{C_L V_{DD}}{W v_{sat} C_{ox}(V_{DD} - V_{TN})}$$

- 电源噪声使时钟和数据产生**确定性抖动**；延迟越大，确定性抖动越大。

### 同时开关噪声（SSO）

- 噪声与同时翻转的输出数 $n$ 成正比，与信号跳变时间 $t_r$ 成反比：

$$V_N = nL\frac{di}{dt} = \frac{nLV_s}{Z_0 t_r}$$

## 9.6 接收器输入等效失调

- 主要由 $V_{th}$ 失配决定（见第 6 讲 6.9 节）：$\sigma_{V_t} = A_{V_t}/\sqrt{WL}$。失调减半需要面积乘 4，所以需要失调校正。
- 理想情况下 A 系数由工艺设计包给出，用蒙特卡洛提取失调 σ。没有的话：$A_{V_t}$ ≈ 1 mV·μm × 栅氧厚度（nm），90 nm 工艺约 2.8 mV·μm；$A_\beta$ 约 2%·μm。

## 9.7 串扰

- 由攻击信号引起、干扰受害信号的噪声。
- 主要来源：片上（容性）导线之间的耦合；片外（传输线 / 信道）导线之间的耦合；信号回流耦合。
- 串扰是**比例噪声**，不能靠缩放信号电平减小；要靠正确的信号约定、改进信道和供电网络、良好的电路设计和版图。

### 对容性线的串扰

- **悬空受害线**（采样节点、多米诺逻辑）：攻击线翻转时信号经电容分压耦合过来，且不会恢复：

$$\Delta V_B = k_c\,\Delta V_A,\qquad k_c = \frac{C_c}{C_c + C_O}$$

- **被驱动的受害线**：串扰以时间常数 $\tau_{xc} = R_O(C_c + C_O)$ 衰减。峰值串扰与攻击线跳变时间 $t_r$ 和驱动强度 $1/R_O$ 成反比。有限上升时间时：

$$V_B(t) = k_c\frac{\tau_{xc}}{t_r}\left(1 - e^{-t/\tau_{xc}}\right)\ (t < t_r);\qquad V_B(t) = k_c\frac{\tau_{xc}}{t_r}\left(e^{-(t-t_r)/\tau_{xc}} - e^{-t/\tau_{xc}}\right)\ (t \ge t_r)$$

### 容性串扰对延迟的影响

攻击线在受害线翻转附近翻转，会调制受害线的等效负载电容，从而调制延迟，产生确定性抖动：

| 攻击线 | 等效负载 |
|---|---|
| 静止 | $C_L = C_{gnd} + C_C$ |
| 同向翻转 | $C_L = C_{gnd}$ |
| 反向翻转 | $C_L = C_{gnd} + 2C_C$ |

### 减轻片上容性串扰

- 相邻金属层互相垂直走线（曼哈顿布线）；
- 限制最大平行走线长度；
- 避免悬空信号，动态逻辑用保持管；
- 尽量加大信号跳变时间（与抖动敏感度权衡）；
- 差分信号周期性"扭绞"，让串扰变成共模；
- 敏感信号隔开；用屏蔽线；
- 把直流信号耦合到合适的电源上。

### 传输线串扰

- **容性耦合**：$\dfrac{dV_B}{dt} = k_{cx}\dfrac{dV_A}{dt}$，$k_{cx} = C_C/(C_S + C_C)$。把耦合能量的一半送往每个方向，**极性相同**。
- **感性耦合**：$\dfrac{dV_B}{dx} = -k_{lx}\dfrac{dV_A}{dx}$，$k_{lx} = M/L$。把耦合能量的一半送往每个方向，**前向波为负、反向波为正**。

### 近端与远端串扰

- **近端串扰（NEXT）**：从攻击线跳变时刻开始，持续一个往返延迟。两种耦合同极性，NEXT 与攻击信号同极性。
- **远端串扰（FEXT）**：沿受害线和入射信号一起传播，只出现一次。两种耦合极性相反，FEXT 可正可负；在均匀介质（带状线）中相互抵消。

$$k_{rx} = \frac{k_{cx} + k_{lx}}{4},\qquad k_{fx} = \frac{k_{cx} - k_{lx}}{2}$$

（推导见 Dally 6.3.2.3。FEXT 的幅度还与耦合长度和跳变时间之比有关。）

### 片外串扰

- 主要发生在封装和板间连接器里。
- FEXT 被信道响应衰减，呈**带通**特性；NEXT 直接耦合进受害线，呈**高通**特性。

### 信号回流串扰

共用的回流路径阻抗有限，回流电流在信号之间引起串扰：

$$V_{xr} = \frac{Z_R}{Z_0}V = k_{xr}V$$

## 9.8 码间干扰

- 脉冲响应的定义和峰值失真分析见第 4 讲。最坏眼高例子：$2(0.540 - 0.389 - 0.007) = 0.288$。

### 最坏眼与随机数据眼

- 最坏数据图样出现的概率可能**非常低**，按最坏情况考虑太悲观。
- 讲义对比了最坏眼与 100、1000、10⁴ 个随机位的眼：随机位数越多，眼越接近最坏眼，但收敛很慢。

### 构造 ISI 的概率密度函数

- 用 ISI 的 PDF 能更准确地估计 BER。
- 每个 ISI 项是一个两点分布：以 50% 概率为 $+a_k$（前一位为"1"），50% 概率为 $-a_k$（"−1"）。
- 把所有单项 ISI 的 PDF **卷积**起来，就得到总的 ISI PDF。

### 主标的 PDF 与 CDF

- **数据"1"的 PDF**：以主标值为中心，从最大正值一直延伸到峰值失真分析预测的最坏值；最坏值出现的概率很低。
- **CDF**：给定判决偏移 X，"1"出错的概率等于数据 1 的 CDF：

$$BER(X) = \int_{-\infty}^{X} PDF(x)\,dx$$

- 把"1"和"0"的 CDF 组合起来，再在每个采样相位上做一遍，就得到 **BER 分布眼图**（BER 等高线眼）。Stateye 等统计 BER 分析工具就用这种方法同时考虑 ISI 分布和其他噪声源。

## 9.9 随机噪声

- 无界，用统计方法建模，例如电路的热噪声和散粒噪声。
- 用连续随机变量描述：PDF、均值 μ、标准差 σ。
- 通常假设为**高斯分布**：

$$P_n(x) = \frac{1}{\sigma\sqrt{2\pi}}\exp\!\left(-\frac{(x - \mu)^2}{2\sigma^2}\right)$$

σ 越大分布越宽。信号上叠加高斯噪声，噪声把信号推过阈值的概率有限。

### CDF、误差函数与 Q 函数

- CDF 给出噪声小于等于某个值的概率。
- 误差函数 $\text{erf}(x) = \dfrac{2}{\sqrt\pi}\displaystyle\int_0^x e^{-u^2}du$；标准正态 CDF $\Phi(x) = \tfrac12\left[1 + \text{erf}(x/\sqrt2)\right]$。
- 互补误差函数给出噪声**超过**某个值的概率：$Q(x) = 1 - \Phi(x) = \tfrac12\text{erfc}(x/\sqrt2)$。

### 误码率

- 用 erfc 预测 BER：BER = 10⁻¹² 时需要约 **7σ**；峰峰值是它的 2 倍（约 14σ）。
- 还有一个偏保守的上界近似（同 EE273 第 5 讲的指数上界）。

## 9.10 噪声预算

判断每个噪声源是比例的还是独立的、有界的还是统计的，对做噪声预算很重要。

**例**：发送峰值差分摆幅 400 mVppd，经信道衰减 10 dB。

| 参数 | $K_n$ | RMS | 数值（BER 10⁻¹²） |
|---|---|---|---|
| 峰值差分摆幅 | | | 0.4 V |
| 接收失调 + 灵敏度 | | | 5 mV |
| 电源噪声 | | | 5 mV |
| 残余 ISI | 0.05 | | 20 mV |
| 串扰 | 0.05 | | 20 mV |
| 随机噪声 | | 1 mV | 14 mV |
| 衰减 | 10 dB = 0.684 | | 0.274 V |
| **总噪声** | | | **0.338 V** |
| **差分眼高裕量** | | | **62 mV** |

- 峰值摆幅的一半 200 mV 经 10 dB 衰减后约 63 mV，即眼的上下边在 ±63 mV；减去各项噪声后上下各剩约 31 mV，合计差分眼高裕量 62 mV。
- 这是**保守**分析：假设所有分布都在最坏处叠加。更好的方法是用统计 BER 链路仿真器。
