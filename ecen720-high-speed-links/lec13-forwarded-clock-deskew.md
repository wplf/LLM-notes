# 第 13 讲 前向时钟去偏斜电路

> [原讲义 PDF](https://people.engr.tamu.edu/spalermo/ecen689/lecture13_ee720_fwd_clk_deskew.pdf) · 参考方法来自 Casper 与 O'Mahony 的高速链路时钟教程（TCAS-I 2009）

提纲：前向时钟 I/O 概述 → 数据与时钟偏斜对性能的影响 → 抖动冲激响应与抖动传递函数 → 去偏斜架构（PLL/PI、DLL/PI、ILO；基频、超谐波、次谐波）。

## 13.1 前向时钟 I/O 概述

内容与第 11 讲 11.2 节相同，要点重述如下：

- 高速参考时钟从发送芯片转发到接收芯片，是**同频异相**系统；
- 用于处理器-内存接口（Intel QPI）和多处理器通信（HyperTransport）；
- 需要一条额外时钟通道；
- "相干"时钟允许抖动跟踪从低频覆盖到高频；
- 时钟经信道衰减，需要好的接收放大器。

**局限**：驱动强度和负载失配、互联长度失配造成的时钟偏斜；低通信道造成抖动放大；前向时钟的占空比变化。

**去偏斜**：逐通道去偏斜可大幅提高速率。做法是把采样时钟调到数据眼中央。实现：DLL + 相位插值器，或注入锁定振荡器。相位获取可以基于 BER（不需要额外的相位采样器），也可以基于鉴相器（额外的相位采样器定期上电）。

**电路**：发送 PLL、发送时钟分配、复制的发送时钟驱动器、信道、前向时钟放大器、接收时钟分配、去偏斜电路（PLL/PI、DLL/PI、ILO）。

## 13.2 数据与时钟偏斜对抖动跟踪的影响

- 高速前向时钟允许时钟和数据之间做抖动跟踪。
- 但**时钟与数据之间的偏斜**会使高频的时钟抖动和数据抖动在接收端变得不同相。

设数据抖动 $J_D = J_P\sin(2\pi f_j\,UI\cdot n)$，时钟抖动 $J_C = J_P\sin(2\pi f_j\,UI\cdot n + 2m\pi f_j\,UI)$，其中 $m$ UI 是时钟与数据之间的偏斜，则差分抖动：

$$J_{diff} = J_D - J_C$$

以 10 Gb/s（UI = 100 ps）、偏斜 5 UI 为例：

| 抖动频率 | 现象 |
|---|---|
| 100 MHz | 差分抖动较小 |
| 200 MHz | 差分抖动增大 |
| 400 MHz | 偏斜使时钟抖动的相位翻转得更快，差分抖动更大 |

**结论**（假设无限抖动跟踪带宽 JTB）：

- 给定偏斜，抖动频率越高，差分抖动越大，最大可达 **2 倍**（两路抖动完全反相）；
- 给定抖动频率，当偏斜为 $1/(6f_j)$ 时，差分抖动就会大于 1（即 1 UI）。

## 13.3 最佳抖动跟踪

- 用极点频率等于 JTB 的低通幅度响应来衰减时钟抖动，从而限制 JTB：

$$J_C = J_P'\sin\!\left(2\pi f_j\,UI\cdot n + 2m\pi f_j\,UI\right),\qquad J_P' = J_P\left|\frac{1}{1 + j\,f_j/f_{JTB}}\right|$$

- 目标是实现一个能给出**最小差分抖动**的最佳 JTB：10 Gb/s 系统中，抖动频率 200 MHz 时希望 JTB 在 70–800 MHz 范围内可调。

## 13.4 抖动冲激响应（JIR）与抖动传递函数（JTF）

（Casper & O'Mahony，TCAS-I 2009）

- **JIR**：系统对抖动冲激的响应；
- **JTF**：输出抖动与输入抖动之比随频率的变化，即 JIR 的离散时间傅里叶变换。

方法：给理想时钟叠加一个抖动冲激激励，得到输出时钟波形，减掉理想时钟就提取出 JIR（半速率系统中两个时钟沿都要用）。一个时钟系统对输入抖动序列的作用，可以看成该序列与 JIR 的**卷积**。

**频响与抖动传递的对应关系**

| 电路频响 | 等效的抖动滤波 |
|---|---|
| 低通（缓冲器、分配互联） | **高通**抖动滤波：高频抖动被**放大** |
| 高通（交流耦合电容） | 全通抖动滤波，只有奈奎斯特率抖动（占空比误差）例外 |
| 带通（带通滤波器） | **低通**抖动滤波，中心频率对准时钟基频 |

**抖动放大**：低通频响（缓冲器、分配互联）相当于高通抖动滤波。高频抖动在通过信道时被放大。

## 13.5 PLL 或 DLL/PI 前向时钟去偏斜

- 发送时钟沿独立信道转发到接收芯片，再分配到各接收通道。
- PLL 或 DLL 锁到前向时钟，充当**多相发生器**和**抖动滤波器**。
- 相位插值器混合相位，产生最佳相位（时序裕量或 BER 最大）的采样时钟。

### PLL/PI 实例（Prete ISSCC 2006，全缓冲 DIMM 收发器）

- PLL 的**低通抖动传递**特性滤除高频抖动：对**不相关**抖动是想要的，对**相关**的高频抖动不想要。
- 缺点：VCO 的抖动累积；稳定性；比 DLL 实现更复杂、面积更大。

### DLL/PI 实例（Balamurugan JSSC 2008）

- 优点：无抖动累积；天然稳定；比 PLL 简单、面积小。
- 缺点：DLL 延迟线的有限带宽可能造成抖动放大。
- DLL 呈现**全通**抖动传递：对**相关**抖动是想要的，对不相关的抖动不想要。

## 13.6 注入锁定（ILO）去偏斜

### 基本原理

- 自由运行的振荡器 = 理想正反馈放大器 + LC 谐振腔。
- 在反馈环路中引入相移，振荡频率就必须偏移（因为环路总相移必须是 2π 的整数倍）。
- 把注入信号加进来后，若振荡器"锁定"到注入电流上，就以相同频率振荡；因为锁定信号一般不在谐振中心频率，谐振腔会引入相移 $\Phi_0$（由注入信号的频率偏移决定，是固定的）。
- 晶体管电流由谐振腔电压提供（谐振腔电流乘谐振腔阻抗，引入 $\Phi_0$）；注入电流与振荡器电流之间的夹角 θ 必须使两者之和与谐振腔电流对齐。

### 锁定范围

- 锁定范围边缘处，注入电流与谐振腔电流正交。
- 对 L、C、$R_P$ 构成的二阶并联谐振腔，相移为 $\phi = -2Q(\omega - \omega_0)/\omega_0$（小偏移近似）。由此：

$$|\omega_{inj} - \omega_{osc}| \le \frac{\omega_0}{2Q}\cdot\frac{I_{inj}}{I_{osc}}$$

- **锁定范围与振荡器的 Q 成反比**。
- 例：$\omega_0$ = 10 GHz、Q = 5、$I_{inj}/I_{osc}$ = 0.1 时，$\Delta\omega_L$ 约 100 MHz。

### 数字控制振荡器（DCO）加注入锁定

用数字控制的开关电容阵列调谐 DCO 的自由振荡频率，从而调整前向时钟的相位，并补偿 PVT（Shekhar JSSC 2009）。

### ILO 的抖动传递

- ILO 对输入（注入时钟）抖动呈现**一阶低通**，对 VCO 抖动呈现**一阶高通**：

$$JTF(s) = \frac{\omega_{JTB}}{s + \omega_{JTB}}$$

（$\omega_{JTB}$ 为抖动跟踪带宽；相位偏移 $\Delta\omega = \frac{\omega_0}{2Q}\sin\theta_{ss}$，其中 $\theta_{ss}$ 是所需的去偏斜相位。）

- **JTB 随锁定点偏离自由振荡频率（即去偏斜相位越大）而下降**；
- **JTB 随注入强度增大而增大**。

### ILO 的相位噪声滤波

- 在抖动跟踪带宽以内，ILO 输出相噪由注入时钟主导（可能比 VCO 还好）；
- JTB 取决于所需的去偏斜相位；
- 高频处 VCO 相噪占主导。

$$S_{out} = |JTF|^2S_{inj} + |1 - JTF|^2S_{VCO}$$

### 超谐波 ILO

- 注入频率是振荡频率的整数分之一（$m$ 分频，例中 $f_{osc} = 2f_{inj}$）。典型应用：半速率发送端把时钟转发给四分之一速率接收端。
- **低频相噪比注入时钟还好 $m^2$ 倍**。

### 次谐波 ILO

- 转发低速时钟可以避免在低通信道上产生抖动放大。
- **用时钟信号注入**会引起明显的 ILO 幅度变化和次谐波杂散。
- **用脉冲串信号注入**可以减小幅度变化和杂散；调节脉冲宽度 $d$ 可以改变有效注入强度，从而调节抖动跟踪带宽。
- 脉冲间隔越大（次谐波频率越低），有效注入强度越小，抖动跟踪带宽越低；给定间隔下减小脉冲宽度 $d$ 也会降低有效注入强度和 JTB。

### 相位漂移与低开销 CDR

- 电压和温度变化会改变收发两端 ILO 的自由振荡频率，相位关系随时间漂移（讲义给出 < ±0.5 UI 的去偏斜范围和 PVT 相位漂移示意）。
- 在前向时钟系统里引入一个**低开销 CDR**，可以跟踪低频相位漂移，同时保持对相关抖动的跟踪。

### 实例：边沿旋转 5/4 倍子速率 CDR（Li 等，VLSI 2014）

> "A 0.8V, 560fJ/bit, 14Gb/s Injection-Locked Receiver with Input Duty-Cycle Distortion Tolerable Edge-Rotating 5/4X Sub-Rate CDR in 65nm CMOS"

- 额外加一个**周期性旋转**的边沿采样器，提供 4 个眼的相位信息给 CDR 逻辑；
- 可以跟踪相位漂移，并优化每个采样器的时序裕量（"跟踪非均匀的眼"）；
- 65 nm 原型：14 Gb/s，给出了有/无 CDR 时对相关抖动和不相关抖动的容限曲线。

## 13.7 带通滤波降低抖动

**时域**：带抖动的时钟 $c(t) = A\cos(2\pi f_c t + \beta\sin(2\pi f_m t))$，β 是相噪幅度，$f_m$ 是抖动频率。

**频域**：$C(f) \approx \frac{A}{2}\delta(f - f_c) - \frac{\beta A}{4}[\delta(f - f_L) - \delta(f - f_H)]$，其中 $f_L = f_c - f_m$、$f_H = f_c + f_m$。

经带通滤波后（$\alpha_c$、$\alpha_L$、$\alpha_H$ 为带通在 $f_c$、$f_L$、$f_H$ 处的增益），接收时钟的相噪幅度：

$$\beta_r \approx \frac{\alpha_L + \alpha_H}{2\alpha_c}\beta$$

通常 $\alpha_c \approx 1$ 且 $\alpha_L = \alpha_H < \alpha_c$，所以 $\beta_r < \beta$：**带通滤波减小了时钟抖动**。

带通函数对称、中心在 $f_c$ 时，可以等效为对偏离 $f_c$ 的频率的低通函数，于是抖动传递函数：

$$JTF_{BP}(j2\pi f) = \frac{1}{1 + jf/f_p},\qquad f_p = \frac{BW_{3dB}}{2}$$

**用 JIR/JTF 分析**：发送的抖动经过带通信道呈低通传递特性；接收端高频的不相关抖动可以被带通滤波器减小。

**最佳设计**：带通的 Q 越高、带宽越窄，抖动滤除越强。Q 在 3–30 之间可调时，5 GHz 时钟（UI = 100 ps）的 JTB 范围为 97–790 MHz。要在 10 UI 时钟偏斜下把 JTB 调到 70 MHz 以优化抖动跟踪，需要更高的 Q。

**实现**：Hollis AICSP 2008 的带通滤波器能有效滤除高频抖动，但滤波器的最大 Q 受无源电感 Q 限制（只有 2.6），因此只能调到较低的抖动跟踪带宽。
