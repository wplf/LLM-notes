# 第 5 讲 跨阻放大器（TIA）

> [原讲义 PDF](https://people.engr.tamu.edu/spalermo/ecen689_oi/lecture5_ee689_tias.pdf) · 参考 Sackinger 第 5 章、Razavi 第 4 章

提纲：光接收机概述 → TIA → 共栅 TIA → 反馈 TIA → 共栅与反馈的组合 → 差分 TIA → 积分型接收机 → 光前端的均衡。

## 5.1 跨阻放大器

- 位置：光电探测器把光功率转成电流，TIA 把电流转成电压，限幅放大器（LA）再把电压放大到逻辑电平。
- **关键设计目标**：跨阻增益高；输入电阻低（以获得高带宽和有效的增益）。

$$Z_T = \frac{\Delta v_{out}}{\Delta i_{in}}\ (\Omega)$$

也常用 dB 表示：$20\log_{10}(Z_T)$。

- **输入过载电流** $i_{ovl}$：能达到目标 BER 的最大峰峰输入电流。假设高消光比，$i_{ovl} = 2RP_{ovl}$。
- **线性工作的最大输入电流** $i_{lin}$：通常用量化增益压缩 1 dB 的电流来表示。要求 $i_{ovl} < i_{lin}$。

### 电阻性前端

直接用一个电阻 $R_L$ 做 I-V 转换，跨阻、带宽和噪声三者直接互相制约（Razavi）：

$$R_T = R_L,\qquad BW_{-3dB} = \frac{1}{2\pi R_LC_D},\qquad \overline{i_{n,in}^2} = \frac{4kT}{R_L}\Delta f$$

- 把 $R_L$ 的噪声在整个 RC 带宽上积分，输出噪声就是 $kT/C_D$，与 $R_L$ 无关；折合到输入的均方根电流噪声为 $\sqrt{kTC_D}/(R_LC_D)$ 量级。
- 提高 $R_L$ 可以增大跨阻、降低输入噪声电流，但带宽成反比下降——这就是为什么要用 TIA 电路把这个取舍解开。

## 5.2 共栅 TIA

- 把输入电阻（决定输入带宽）和跨阻解耦：

$$R_{in} \approx \frac{1}{g_m + g_{mb}},\qquad R_{out} \approx r_o(1 + g_mR_D)$$

- 频率响应中，**输入极点常常占主导**，因为光电二极管电容很大（100–500 fF）。忽略 $r_o$ 时：

$$\frac{v_{out}}{i_{in}} = \frac{R_D}{\left(1 + \dfrac{sC_{in}}{g_m + g_{mb}}\right)\left(1 + sR_DC_{out}\right)}$$

- **噪声**：偏置电流源和 $R_D$ 都对输入噪声电流有贡献。增大 $R_D$ 可以降低噪声，但受电压裕度（headroom）限制。
- **共栅 TIA 一般不适合低噪声应用**，但设计相对简单、稳定性好。

### 稳压共源共栅（RGC）TIA

（Park ESSCIRC 2000）用共源放大器给输入管的 $g_m$ 做增益提升，从而降低输入电阻；代价是需要额外的电压裕度，且共源级带来额外的输入等效噪声。

### 20 GHz CMOS TIA

（Kromer JSSC 2004）在反馈中再加一级共栅，进一步做 $g_m$ 提升，输入电阻更低；并联峰化电感在零功耗代价下扩展带宽，但面积代价很大。

## 5.3 反馈 TIA

### 理想放大器

- 输入带宽被 $(A+1)$ 倍扩展；跨阻近似等于 $R_F$。
- $R_F$ 可以取得大而不必担心电压裕度：

$$Z_T(s) = -\frac{A}{A + 1}\cdot\frac{R_F}{1 + s\dfrac{R_FC_T}{A + 1}},\qquad R_{in} = \frac{R_F}{A + 1}$$

### 有限带宽放大器

有限带宽的放大器（$A(s) = A/(1 + sT)$）把跨阻传递函数变成**二阶低通**：

$$Z_T(s) = \frac{R_T}{1 + \frac{s}{Q\omega_0} + \frac{s^2}{\omega_0^2}},\qquad R_T = \frac{A}{A + 1}R_F$$

其中 $\omega_0 = \sqrt{(A + 1)/(R_FC_TT)}$，$Q$ 由 $A$、$R_FC_T$ 与 $T$ 之比决定（讲义第 16 页有完整表达式，$C_T$ 为总输入电容）。

- **非零的放大器时间常数实际上可以增加 TIA 带宽**，但会在频域产生峰化、时域产生过冲和振铃。
- 常用 **Butterworth（$Q = 1/\sqrt2$，最大的平坦频响）**或 **Bessel（$Q = 1/\sqrt3$，最大的平坦群延迟）**响应。

### 跨阻极限

- 最大 $R_T$ 正比于放大器的增益带宽积（GBW）。
- 若放大器 GBW 受工艺 $f_T$ 限制，**要提高带宽，$R_T$ 必须按平方减小**。以 Butterworth 响应为例（Mohan JSSC 2000）：

$$R_{T,max} \approx \frac{A\,f_A}{2\pi C_T\,BW_{3dB}^2}$$

其中 $A f_A$ 是放大器的增益带宽积。

### 一个简单的反馈 TIA

用共源级放大、源跟随器缓冲（增益理想为 1）的结构，$A \approx g_mR_D$，跨阻约为 $R_F\cdot g_mR_D/(1 + g_mR_D)$。

- 电源电压下降时，留给 $R_D$ 的裕度不多，放大器增益随之恶化。

### CMOS 反相器式反馈 TIA

（Li JSSC 2014）反相器式 TIA 能在更低的电压裕度下工作；级联的反相器 gm 级加 TIA 级提供额外电压增益；用低带宽反馈环设定放大器输出的共模电平。

## 5.4 输入等效噪声电流

- TIA 噪声用**输入等效噪声电流源**建模：该电流源经过一个理想无噪 TIA 后，能重现实际的 TIA 输出噪声。
- 这个噪声源取决于源阻抗，而源阻抗主要由光电二极管电容决定。单位是 pA/√Hz。

### 噪声谱的形状

输入等效噪声电流谱通常由三部分构成：均匀（白）分量、高频 $f^2$ 分量、低频 $1/f$ 分量。比较不同 TIA 时，要把这张图看到 TIA 带宽的约 **2 倍**处（配合第 4 讲的噪声带宽表）。

### 输入等效均方根噪声电流

把输出均方根噪声电压除以 TIA 的中频跨阻值：

$$i_{n,TIAn}^{rms} = \frac{v_{n,TIAn}^{rms}}{Z_T|}_{mid}\quad\Longleftrightarrow\quad i_{n,TIAn}^{rms} = \sqrt{\int_{>}I_{n,TIAn}^2(f)\,df}$$

- 积分上限不太关键（推导时常用无穷，仿真时常用 2 倍带宽）。
- 这个均方根电流决定 TIA 的**电灵敏度**：

$$i_{sens} = 2Q\,i_{n,TIAn}^{rms}$$

- 要得到整个光接收机的灵敏度，还要考虑探测器噪声和响应度。

### 平均输入等效噪声电流密度

另一个量化指标：

$$\bar{i}_{n,TIAn} = \frac{i_{n,TIAn}^{rms}}{\sqrt{BW_{TIA}}}\quad (\text{pA}/\sqrt{Hz})$$

注意这和"对 $I_{n,TIAn}(f)$ 谱在带宽上取平均"不是一回事。

### 反馈 TIA 的噪声成分

$$I_{n,TIAn}^2(f) = I_{n,res}^2(f) + I_{n,front}^2(f)$$

- **反馈电阻分量**（与频率无关）：$I_{n,res}^2 = 4kT/R_F$。
- **栅极电流引起的散粒噪声**：$I_{n,G}^2 = 2qI_G$（CMOS 设计中通常很小）。
- **FET 沟道噪声**：$I_{n,D}^2 = 4kT\Gamma g_m$，$\Gamma$ 是沟道噪声因子，典型 0.7–3（取决于工艺）。

把沟道噪声折合到输入端（利用输入节点的高通传递函数，把输出接地后计算更简单），讲义最终给出的形式为：

$$I_{n,TIAn}^2(f) = \frac{4kT}{R_F} + 2qI_G + \frac{4kT\Gamma}{g_mR_F^2} + \frac{4kT\Gamma}{g_m}(2\pi C_T)^2f^2$$

即：反馈电阻（白）+ 栅极散粒（白）+ FET 沟道（白）+ FET 沟道（$f^2$）。

- 关键点：**TIA 输入等效噪声电流谱会在低于 TIA 带宽的某个频率就开始上升**（$f^2$ 项）。
- 其中 $C_T = C_D + C_I$ 是探测器电容与放大器输入电容之和。

## 5.5 共栅与反馈的组合

- 反馈 TIA 的稳定性取决于输入极点（由 $C_D$ 决定）与放大器极点的比值；$C_D$ 变化大时会破坏稳定性。
- 在反馈 TIA 前面加一级**共栅输入级**，把 $C_D$ 与放大器输入电容隔离开，就能在不同光电探测器下都保持稳定响应；跨阻仍约为 $R_FA/(1+A)$（Mohan JSSC 2000）。

**BJT 共基 + 反馈 TIA**（Li JSSC 2013）：用变压器做负反馈，以低功耗和低噪声代价提升 $g_m$；输入串联峰化电感把光电探测器电容与 TIA 输入电容隔离开；用这些高频技术实现 26 GHz 带宽、群延迟变化小于 19 ps。

## 5.6 差分 TIA

- 差分电路对电源/衬底噪声的抑制更好；差分输出便于直接用常见的差分主放大器/限幅放大器。代价是噪声和功耗更高。
- 问题：**单端光电流输入怎么得到差分输出**？两种常见做法，区别在于负输入端加多少电容。

| | 平衡（balanced）TIA | 伪差分（pseudo-differential）TIA |
|---|---|---|
| 负输入端电容 | $C_X \approx C_D$，两输入电容匹配 | $C_X \to \infty$，可近似为交流地 |
| 噪声抑制 | 最好（两个噪声传递函数相似） | 不能很好地抑制电源/衬底噪声，但能显著滤除 RF 噪声 |
| 噪声代价 | 电路加倍，输入等效均方根噪声电流增大约 $\sqrt2$ 倍 | — |
| 传递函数 | 与单端设计相同 | 差分跨阻约为单端的两倍 |

- **失调控制**：由于光电探测器的信号是单端的，差分输出信号从 0 摆到 $V_{ppd}$，会限制动态范围；加失调控制电路后输出可以摆到 $\pm V_{ppd}/2$。

## 5.7 积分型接收机

光接收机在工艺缩放下面临的问题：

- 传统上 TIA 要高 $R_T$、低 $R_{in}$，$R_T = R_FA/(A+1)$，$R_{in} \approx R_F/(A+1)$；
- 1 V CMOS 里裕度和增益都不够：放大器增益只有 $A \approx$ 2–3；
- 功耗和面积代价随带宽迅速增长：TIA 的电流大致随 $C_TR_F f_{3dB}^2$ 增长，LA 的电流随 $f_{3dB}$ 的更高次方增长（讲义第 39 页的估算式抽取不完整）。

**1 V 改进型积分接收机**：加差分缓冲器固定灵敏放大器的输入共模，改善速度和失调；减少回踢电荷（kickback）。代价是额外的功耗和噪声。输入范围 0.6–1.1 V。

**灵敏度分析例**（1 V、16 Gb/s）：

| 噪声源 | 数值 |
|---|---|
| 采样器的 $kT/C$ | $\sqrt{2kT/C_{samp}} \approx 0.92$ mV |
| 缓冲器 | 1.03 mV |
| 灵敏放大器 | 0.45 mV |
| 时钟抖动引起的噪声 | 约 0.65 mV（16 Gb/s 时） |
| **总输入噪声** | $\sigma_{tot} = \sqrt{\sum} = 1.59$ mV |
| 残余 SA 失调 | 1.15 mV |
| 最大 $\Delta V_{in}$（对应平均电流） | 0.6 mV |
| BER 10⁻¹⁰ 需要的 $\Delta V_b$ | 讲义按 $6.4\sigma_{tot}$ + 失调给出 11.9 mV（笔者按表中数字算得约 11.3 mV，差异可能来自未列出的项） |

平均光功率与 $\Delta V_b$ 的关系还要考虑积分节点上探测器电容和输入电容的充放电（讲义给出 $P_{avg} \propto \Delta V_b(C_{pd} + C_{in})/(\rho\,t_b)$ 的形式）。

- 测试条件：8B/10B 数据（6 位游程）与长游程数据（10 位游程），BER < 10⁻¹⁰（Palermo JSSC 2008）。
- **积分接收机加动态阈值调整**可以支持不编码的数据（Nazari ISSCC 2012）。

## 5.8 光前端中的均衡

### 低带宽 TIA + CTLE 前端（Li JSSC 2014）

- 把第一级的反馈电阻调大，得到一个**高增益、低带宽**的 TIA，灵敏度因此改善；
- 由此产生的 ISI 由后面的 **CTLE** 抵消。
- 好处：反馈电阻噪声显著降低；低频的输入噪声和后置放大器噪声也降低。
- 实测：25 Gb/s 眼图。

### 低带宽 TIA + DFE 接收机（Ozkaya JSSC 2017）

- 同样用高增益低带宽 TIA，ISI 由一个 1 抽头**循环展开的 DFE** 抵消。
- $R_F$ 增大时主标增大、SNR 改善（前提是 ISI 被 DFE 抵消）；一个低复杂度的 1 抽头 DFE 就能带来很大的性能收益。
- 用自参考（self-referenced）TIA 产生差分信号。
- 实际的 64 Gb/s 脉冲响应有一个明显的前标 ISI 抽头，需要 **2 抽头发送 FFE** 配合。
