# 第 4 讲 光接收机分析

> [原讲义 PDF](https://people.engr.tamu.edu/spalermo/ecen689_oi/lecture4_ee689_rx_analysis.pdf) · 主要参考 Sackinger 第 4 章

提纲：接收机模型 → 误码率 → 灵敏度 → Personick 积分 → 功率代价 → 带宽 → 均衡 → 抖动 → 前向纠错。

## 4.1 接收机模型

- **线性信道**：代表跨阻放大器（TIA）和主放大器（MA）的增益，可带一个可选的低通滤波器。
- **探测器**：带判决阈值 $D_{TH}$。
- 探测器建模为信号电流源 $i_{PD}$（与光功率线性相关）加噪声电流源 $i_{n,AMP}$（频谱近似均匀，且依赖信号）。
- **前端的线性传递函数** $H(f)$ 描述输出与输入电流的关系。从灵敏度的角度看信号很小，线性一般成立。可以用**单个输入等效噪声电流源**表示噪声，它经 $H(f)$ 后产生正确的输出噪声谱；一般 TIA 的输入等效噪声占主导。

**两类噪声的关键区别**

| | 探测器噪声 | 放大器噪声 |
|---|---|---|
| 平稳性 | **非平稳**，均方根值随位值变化，形式上要写成时变函数 $I_{n,PD}^2(f, t_{bit\_value})$ | **平稳**，均方根值与时间无关 |
| 频谱 | 均匀（白） | 非白，可建模为白分量加一个正比于 $f^2$ 的分量 |

**判决电路**：把线性信道输出 $v_O$ 与 $D_{TH}$ 比较。对二进制（OOK）调制：高于阈值判"1"，低于判"0"。

## 4.2 误码率

- 判决元件之前的接收前端输出可以建模为期望信号与噪声之和：$v_O(t_s) = v_S(t_s) + v_n(t_s)$。
- 偶尔噪声足够大，会越过判决阈值、造成误码；理想上这种事只在很低的概率（BER）下发生。

### 输出噪声

**放大器分量**（平稳）：

$$V_{n,amp}(f) = |H(f)|I_{n,amp}(f),\qquad v_{n,amp}^2 = \int^{BW_D}|H(f)|^2I_{n,amp}^2(f)\,df$$

$H(f)$ 一般滚降很快，积分上限的取法不太关键，可以取无穷。

**探测器分量**（非平稳）：

$$V_{n,PD}(t,f) = |H(f)|I_{n,PD}(t,f)\ \text{（形式写法）}$$

- 形式上要写成与前端冲激响应 $h(t)$ 的卷积，这意味着噪声不仅影响本位，还可能扩散影响其他位。
- 但一般假设噪声相对 $h(t)$ 变化很慢，可以简化：$v_{n,PD}^2 = \int^{BW_D}|H(f)|^2I_{n,PD}^2(t,f)\,df$。
- 对简单 OOK，用两个时刻相关的输出噪声功率值。

**总输出噪声**是互不相关的探测器噪声和放大器噪声的**平方和开根**：

$$v_{n,rms}(t) = \sqrt{v_{n,PD}^2(t) + v_{n,amp}^2(t)}$$

对 OOK 就有两个均方根值 $v_{n,0,rms}$ 和 $v_{n,1,rms}$。

### 误码率计算

- 噪声是高斯分布，标准差等于噪声电压的均方根值。
- 0 和 1 等概率时，把 $D_{TH}$ 设在两条分布的交点处误码最少。
- BER 是高斯分布的**尾部面积**；0 和 1 噪声统计相同时两个尾巴对称，只算一个：

$$BER = \int_Q^\infty \text{Gauss}(x)\,dx,\qquad Q = \frac{V_{DTH}}{v_{n,rms}}$$

**Personick Q** 是信号与噪声之比的度量：

$$BER = \frac12\text{erfc}\!\left(\frac{Q}{\sqrt2}\right)$$

- 要 BER = 10⁻¹²，需要 $Q$ = 7.035；0/1 噪声统计相同时，即峰峰信号 $v_S$ 要达到 $14.07\,v_{rms}$。

**噪声分布不相等时**：

$$BER = \int_Q^\infty \text{Gauss}(x)\,dx,\qquad Q = \frac{v_{1,mean} - v_{0,mean}}{v_{n,1,rms} + v_{n,0,rms}}$$

即 1 的分布较厚（噪声大）、0 的分布较薄，而误码率由两者的均方根值之和决定。

### 信噪比

光接收机分析中，SNR 常定义为**无均值（mean-free）的平均信号功率除以平均噪声功率**：

$$SNR = \frac{\left(\dfrac{v_{1,mean} - v_{0,mean}}{2}\right)^2}{\dfrac{v_{n,1}^2 + v_{n,0}^2}{2}}$$

对直流平衡的 NRZ 信号，分子就是信号功率，分母是噪声功率。

**两种极端**：

| 情形 | SNR 与 Q 的关系 | BER = 10⁻¹² 时 |
|---|---|---|
| 放大器噪声主导，0/1 噪声相等（$v_{n,1} = v_{n,0}$） | $SNR = Q^2$ | $Q$ = 7.0 → SNR = 49.0 → **16.9 dB** |
| 探测器/光放大器噪声主导，0/1 噪声不等（$v_{n,1} \gg v_{n,0}$） | $SNR = 2Q^2$ | $Q$ = 7.0 → SNR = 98 → **13.9 dB**（这是要求最低的情形） |

## 4.3 灵敏度

**电灵敏度**：在输入端达到目标 BER 所需的**最小峰峰信号电流**。

$$i_{sens,pp} = 2v_{sens}^{rms} = \frac{2Qv_n^{rms}}{|H_0|},\qquad i_{n}^{rms} = \frac{v_n^{rms}}{|H_0|}$$

$H_0$ 是 $H$ 的中频值；输入电流摆幅产生输出电压摆幅。

例：$i_{n,rms}$ = 380 nA、BER 10⁻¹²（$Q$ = 7.035）时 $i_{sens,pp} = 2\times380\,\text{nA}\times7.035 \approx 5.35$ μA。

**噪声分布不等时**：$v_{sens} = (i_{n,0}^{rms} + i_{n,1}^{rms})Q$。

注意以上都假设判决电路是理想判决器；真实判决器的最小输入信号和失调会恶化灵敏度。

**光灵敏度**：达到目标 BER 所需的、按时间平均的**最小光功率**。假设直流平衡信号和高的消光比：

$$P_{sens} = \frac{i_{sens}}{R} = \frac{(i_{n,1}^{rms} + i_{n,0}^{rms})Q}{R}$$

例：$R$ = 0.8 A/W、$i_{n,rms}$ = 380 nA、BER 10⁻¹² → $P_{sens}$ ≈ 3.34 μW = **−24.8 dBm**。

注意：**光灵敏度基于平均信号值，而电灵敏度基于峰峰信号值。**

### 排除探测器性能（理想探测器）

为了比较不同电接收机的相对性能，把探测器的量子效率除掉：

$$P_{sens} = \frac{i_{n}^{rms}Q}{\eta}\cdot\frac{hc}{q\lambda}$$

例：$R$ = 0.8 A/W、$\eta$ = 1（即用理想响应度）、1550 nm，$i_{n,rms}$ = 380 nA，BER 10⁻¹² → $P_{sens} = 380\,\text{nA}\times7.035\times0.8/1.24 \approx 1.7$ μW。讲义给出的结果是 **−26.7 dBm**，与上式算出的数值有出入（−26.7 dBm 对应约 2.1 μW），请以原讲义第 26 页为准。

### 过载与动态范围

- **灵敏度极限**是最弱信号；信号太强也会恶化 BER（脉冲宽度失真、数据相关抖动）。
- **过载极限**是能达到目标 BER 的最大信号。
- 动态范围 = 过载极限 / 灵敏度极限。

### 不同标准要求的 BER

| 标准 | 速率 | BER | Q | 光灵敏度（$i_{n,rms}$ = 380 nA、$R$ = 0.8 A/W） |
|---|---|---|---|---|
| SONET OC-48 | 2.5 Gb/s | ≤ 10⁻¹⁰ | 6.361 | −25.2 dBm |
| SONET OC-192 | 10 Gb/s | ≤ 10⁻¹² | 7.035 | −24.8 dBm |
| （更高要求） | | ≤ 10⁻¹⁵ | 7.942 | −24.2 dBm |

**灵敏度必须指明对应的 BER。**

### 计入探测器噪声后的灵敏度

假设 0 位的探测器噪声很小、消光比很高（$P_1 = 2P_{sens}$）：

**p-i-n 接收机**：

$$i_{n,0}^2 = i_{n,amp}^2,\qquad i_{n,1}^2 = i_{n,amp}^2 + i_{n,sens}^2 = i_{n,amp}^2 + 4R^2qP_{sens}BW$$

$$P_{PIN,sens} = \frac{Q i_{n,amp}^{rms} + Q^2qBW}{R}$$

**APD 接收机**（$M$ 为增益、$F$ 为过剩噪声因子）：

$$i_{n,1}^2 = i_{n,amp}^2 + M^2F\cdot 4R^2qP_{sens}BW,\qquad P_{APD,sens} = \frac{Qi_{n,amp}^{rms} + Q^2qF BW}{MR}$$

**光前置放大 p-i-n 接收机**（$G$ 为光增益、$\eta$ 为量子效率）：

$$i_{n,1}^2 = i_{n,amp}^2 + \eta GF\cdot 4R^2qP_{sens}BW,\qquad P_{OA,sens} = \frac{Qi_{n,amp}^{rms} + Q^2qF BW}{\eta GR}$$

**关键结论**：探测器增益越大，放大器噪声被抑制得越多，但散粒噪声随过剩噪声因子增大。

10 Gb/s 下的对比（$R$ = 0.8 A/W、$M$ = 10、$G$ = 100、BER 10⁻¹²；APD 的 $F$ = 6 即 7.8 dB；OA+p-i-n 的 $\eta$ = 0.64、$F$ = 3.16 即 5 dB）：

| 接收机 | 相对"只有放大器噪声"的灵敏度恶化 |
|---|---|
| p-i-n | 几乎不变 → **可以忽略散粒噪声** |
| APD | 约 1.3 dB → 忽略散粒噪声是合理估计，但要看链路预算裕量 |
| OA + p-i-n | 3.5 dB → **必须计入散粒噪声** |

### BER 曲线

把 BER 或 Q 对平均光功率作图：

- 低功率时遵循 $P_{PIN,sens} = (Qi_{n,amp}^{rms} + Q^2qBW)/R$；
- 对线性功率作图，Q 线性增长，BER 按 erfc(Q) 改善；对 dB 功率作图，10log(Q) 线性增长。
- 功率继续增大，BER 继续改善，直到散粒噪声项开始主导，出现 **BER 地板**；
- 再增大功率就会出现信号失真，达到**过载极限**，之后 BER 迅速恶化。

### 最优 APD 增益

- 灵敏度反比于 $M$、正比于 $F$，所以存在最优 $M$：

讲义给出了 $M_{opt}$ 的闭式解（由 $F(M)$ 代入灵敏度式求极值，含 $k_A$、$i_{n,amp}^{rms}$、$qBW$ 和 Q；抽取时乱码，请看原讲义第 36 页）。

- 放大器噪声越大，最优 APD 增益越高（因为 APD 增益能抑制这个噪声）。
- 对光前置放大 p-i-n，噪声系数随 $G$ 增大而下降，所以**$G$ 越高灵敏度总是越好**。

### 如果放大器完美无噪？

那就最终受限于探测器噪声：

| 接收机 | 极限灵敏度 |
|---|---|
| p-i-n | $P_{sens} = 2Q^2qBW$ |
| APD | $P_{sens} = 2Q^2qFBW/M$ |
| OA + p-i-n | $P_{sens} = 2Q^2qFBW/(\eta G)$ |

p-i-n 表现最好；APD 被 $F$ 恶化 7.8 dB；OA + p-i-n 被 $\eta F$ 恶化 3.1 dB。

### 量子极限

- 即使放大器和探测器都无噪，也至少要检测到**一个光子**才能判断"1"位。
- "1"位的光子数 $n$ 服从泊松分布；假设"0"位不发功率（这些位永远正确）。
- "1"位一个光子都没收到时才出错，概率为 Poisson(0) = $e^{-M}$（$M$ 是"1"位的平均光子数）。"1"和"0"各占一半：

$$BER = \frac12 e^{-M}\quad\Rightarrow\quad M = -\ln(2\,BER)$$

- BER = 10⁻¹² 时 $M \approx 27$ 个光子 /"1"位，平均每位约 13.5 个光子。对应的平均光功率：

$$P_{sens,quant} = \frac{M}{2}\cdot\frac{hc}{\lambda}\cdot B$$

（B 是比特率。讲义此页公式抽取不完整，以上是笔者按泊松模型写出的标准形式。）

对比前面 10 Gb/s 的例子的量子极限：p-i-n 接收机比它差 **+28.5 dB**；APD 差 +19.8 dB；OA + p-i-n 差 +12 dB。

## 4.4 Personick 积分

**总输入等效噪声**可以通过积分输出噪声谱、再除以中频增益得到：

$$v_n^2 = \int|H(f)|^2I_n^2(f)\,df,\qquad i_n^{rms} = \frac{v_n^{rms}}{|H_0|}$$

如果不能仿真输出噪声谱，就要从输入噪声谱积分，但**积分的上下限要非常小心**，因为 $f^2$ 分量增长很快。

把输入噪声谱写成 $I_n^2(f) = \alpha + \beta f^2$，引入两个**噪声带宽**：

$$BW_n = \frac{1}{|H_0|^2}\int^{BW_D}|H(f)|^2df,\qquad BW_{n2} = \frac{1}{|H_0|^2}\int^{BW_D}|H(f)|^2f^2\,df$$

则：

$$i_n^2 = \alpha BW_n + \beta BW_{n2}$$

- $BW_n$ 是接收机频响的噪声带宽，$BW_{n2}$ 是二阶噪声带宽，都只取决于接收机频响和判决电路带宽 $B_{WD}$。
- $B_{WD}$ 只要大于接收机带宽就影响不大。

**常见错误**：直接用 3 dB 带宽积分，即 $i_n^2 = \alpha BW_{3dB} + \beta BW_{3dB}$。这只对砖墙式低通正确。以二阶巴特沃斯响应为例，这样会**低估白噪声分量 1.11 倍、低估 $f^2$ 分量 3.33 倍**。

**Personick 积分 $I_2$、$I_3$** 就是归一化的噪声带宽，光接收机文献常用它们，关系为 $i_n^2 = I_2B\alpha + I_3B^3\beta$（B 是比特率）。

## 4.5 功率代价

- 实际接收机灵敏度会被整个光链路的各种非理想性恶化，用**功率代价 $PP$** 量化。
- 定义：为维持目标 BER，相对理想情况（没有该非理想性）所需的平均发送功率增量，用 $10\log(PP)$ 表示（dB）。

**典型非理想性**：

| 位置 | 项目 |
|---|---|
| 发送机 | 消光比、相对强度噪声（RIN）、输出功率变化 |
| 光纤 | 色散、非线性效应 |
| 探测器 | 暗电流 |
| TIA | 失真（ISI）、失调 |
| MA | 失真、失调、噪声系数、低频截止 |
| CDR | 判决阈值失调、判决阈值模糊、采样时刻偏移、采样时刻抖动 |

### 判决阈值失调代价

如果阈值有偏移 δ，信号摆幅必须增加 δ 才能保持相同的有效眼开：

保持阈值居中、两个电平各自外移 δ，峰峰摆幅从 $2Qv_n^{rms}$ 增加到 $2Qv_n^{rms} + 2\delta$：

$$PP = 1 + \frac{\delta}{Q\,v_n^{rms}}$$

（讲义的推导式抽取不完整，以上按这一思路写出，笔者。）

- 例 1：$v_{n,rms}$ = 1 mV、阈值偏移 1 mV、BER 10⁻¹²（$Q$ = 7.035）：$PP = 1 + 1/7.035 \approx 1.14$，约 0.58 dB（笔者计算）。
- 例 2：只允许 0.1 dB（PP = 1.023）时，偏移要小于 $0.023\times7.035\times1\,\text{mV} \approx 0.16$ mV（笔者计算）。
- 严格说，低电平那一侧的 BER 反而改善了，但计入它对代价影响很小。**结论：接收机必须做好失调控制。**

### 暗电流代价

- 暗电流本身一般不是大问题（假设接收机能减掉它），但它引起的散粒噪声会造成功率代价：

$$i_{n,DK}^2 = 2qI_{DK}BW$$

- 假设接收机噪声由放大器主导（这会稍微高估暗电流代价）：

$$PP = \sqrt{1 + \frac{2qI_{DK}BW_n}{i_{n,amp}^2}}$$

- 例 1：2.5 Gb/s 接收机，$i_{n,amp}$ = 380 nA、$BW_n$ = 1.9 GHz、$I_{DK}$ = 5 nA：暗电流噪声约 1.7 nA rms，代价约 $10^{-5}$，完全可以忽略（笔者计算）。
- 例 2：若是 APD 接收机（$M$ = 10、$F$ = 6），暗电流噪声要乘以 $M^2F$，代价随之放大。
- 例 3：同样的 2.5 Gb/s 接收机，要让代价小于 0.05 dB，暗电流必须小于 **5.53 μA**。
- **结论：有效暗电流在低 μA 或以下时，功率代价一般可以忽略。**

## 4.6 带宽

### 噪声与 ISI 的取舍

- 接收机带宽做得很宽，信号失真最小，但噪声随带宽增长。
- 只从灵敏度看，带宽越窄灵敏度越好；但这忽略了高频脉冲被滤掉造成的 ISI。
- 所以**从灵敏度角度存在一个最优带宽**，一般在比特率的约 2/3 处。

带宽对眼图的三组对比（二阶巴特沃斯接收机）：

| 情形 | 结果 |
|---|---|
| 带宽过窄（约 4/3 B） | 无 ISI，假设噪声（BER 10⁻¹²）正好等于眼高、没有裕量 |
| 带宽约 2/3 B | 仍然几乎没有 ISI；白噪声主导时均方根噪声降低 $\sqrt2$ 倍，功率可以降低同样倍数而 BER 不变 |
| 带宽约 1/3 B | 严重 ISI（约半个眼高）；虽然均方根噪声降为一半，总的垂直裕量和 4/3 B 时相同，**但时间上稍偏就拿不到目标 BER** |

### ISI 功率代价

为了得到相同的有效（垂直）眼开，必须增加光功率来克服 ISI。**注意这个代价偏保守**，因为产生眼闭合的最坏数据图样出现概率很低——这是峰值失真分析的功率代价。

### 最优接收机带宽

- 白噪声主导时，灵敏度随带宽减小而按平方根改善；
- 但在约 (2/3)B 以下，ISI 功率代价迅速上升；
- 综上看，**最优带宽在比特率的 60%–70% 附近**。

### （1/3）B 带宽的接收机行不行？

如果愿意接受 1.5 dB 的灵敏度恶化，40 Gb/s 接收机可以只用 13.3 GHz 带宽。但这样对**时序噪声（抖动）**敏感得多：虽然 (4/3)B 的接收机理论上灵敏度和它相同，但 (4/3)B 的有效眼高能在**宽得多的时间窗口**内保持。

### 带宽分配

整个接收机前端的等效带宽必须接近 (2/3)B，所以各个模块的带宽都要更大：

$$\frac{1}{BW^2} \approx \frac{1}{BW_{TIA}^2} + \frac{1}{BW_{MA}^2} + \cdots$$

（各级级联时带宽近似按平方倒数相加，笔者按讲义思路写出。）

三种分配策略：

| 策略 | 做法 | 适用 |
|---|---|---|
| 宽带宽电路 + 精密低通 | 常用 Bessel-Thomson 滤波器限制噪声 | 低速接收机（< 2.5 Gb/s） |
| 由 TIA 决定带宽 | TIA 增益更高、噪声更好；后续 MA 级带宽要宽得多 | 带宽比固定滤波器高，但控制更差 |
| 各模块带宽相近 | 最高速设计时无法过度设计任何一个模块 | 高速接收机（> 10 Gb/s） |

### 最优接收机响应

带宽 (2/3)B 只是从接收机自身 ISI 和噪声角度得到的最优。还要考虑：接收信号的 ISI、输入等效噪声谱、接收时钟抖动、比特估计方式。

### 低 ISI 输入的最优响应

- 如果输入 ISI 很小，**匹配滤波器**接收机能使采样信噪比最大：其冲激响应正比于接收脉冲 $x(t)$ 的**时间反转**。
- 对 NRZ 信号，这就是一个简单的**矩形滤波器**，冲激响应是长一个位周期的矩形脉冲。
- NRZ 输入与矩形滤波器卷积得到**三角形**输出波形；不在眼正中采样就会有功率代价。
- 频域上 $H(f) = \sin(\pi f/B)/(\pi f/B)\,e^{-j\pi f/B}$，噪声带宽 $2B$，−3 dB 带宽 0.443B。

### 积分型接收机与解复用接收机

- 积分型接收机（Emami VLSI 2002）的框图。
- 解复用接收机：用多个时钟相位提高数据率——数据率 = 时钟相位数 × 时钟频率；给灵敏放大器足够的判决时间；支持连续的数据判决。

## 4.7 均衡

如果系统有明显 ISI，积分型接收机就不再最优。更好的做法是用 (2/3)B 的带宽滤波噪声，再用电路**消除 ISI**。

- 最优实现是 Viterbi 解码器（最大似然序列检测），但功耗和面积太大；
- 实际常用**均衡器**：
    - **FIR（前馈均衡器，FFE）**：主要消除前标 ISI；
    - **判决反馈均衡器（DFE）**：消除后标 ISI。
- 前标 ISI 是本位**之后**的位造成的误差，后标 ISI 是本位**之前**的位造成的误差；ISI 可以跨越多个位周期。

### 接收 FIR

- 把模拟输入延迟，乘以均衡系数后求和。
- 优点：动态范围足够时可以放大高频（而非衰减低频）；能消除前标 ISI 和滤波器长度以外的 ISI；抽头可以自适应，不需要反向信道。
- 缺点：放大噪声/串扰；模拟延迟难实现；抽头精度有限。
- **线性接收均衡器不区分信号、噪声和串扰**：信号与失真（ISI）之比改善了，但 **SNR 不变**。
- 实例：Hernandez-Garduno，ISSCC 2007，1 Gb/s 5 抽头、抽头间隔 $T_b/2$，用三阶延迟单元。

### 接收 DFE

- 非线性均衡器：判决器先量化输入，再用反馈 FIR 把 ISI 从输入中直接减掉。
- 优点：能在不放大噪声和串扰的情况下提升高频；抽头可自适应、不需要反向信道。
- 缺点：不能消除前标 ISI；有误码传播的可能（实际链路 BER 10⁻¹² 时很小）；反馈路径时序关键；ISI 减法的时序使 CDR 鉴相复杂。
- 抽头系数：只用 DFE 时应等于未均衡信道脉冲响应的后标值；与其他均衡器一起用时等于 DFE 之前的脉冲响应后标值。DFE 给其他均衡器的优化带来灵活性。
- 实例：Payne JSSC 2005，6.25 Gb/s、4 抽头、半速率、自适应；TAP1 5 位，TAP2 4 位 + 符号，TAP3/4 3 位 + 符号；第 1 抽头的时序在半个 UI 内闭合。

### 自适应均衡

- 最简单是把均衡值固定（按实验室测量选最优），但对制造和环境变化敏感。
- 自适应可以针对不同信道、环境和速率优化。关键问题：提取误差信号、自适应算法和硬件开销、把修正信息送到均衡器。
- **误差提取**：调 FIR 时要在接收输入端测响应，通常是比较接收输入与期望符号电平 dLev，需要接收端额外的、阈值可编程的采样器。
- **符号-符号 LMS**：

$$w_{k+1}^{(n)} = w_k^{(n)} + \mu\,\text{sign}(e_k)\,\text{sign}(d_{k-n}),\qquad dLev_{k+1} = dLev_k + \mu\,\text{sign}(e_k)$$

## 4.8 抖动

- 链路必须在电压域**和**时间域都有裕量；为了让发送和接收能独立设计（互操作），规范里用**眼图模板**。
- **抖动直方图**用来提取抖动的 PDF，其中同时含确定性和随机分量，必须分解才能准确估计给定 BER 下的抖动。
- 抖动分类与总抖动（随机与确定性 PDF 的卷积）见 [ECEN 720 第 10 讲](../ecen720-high-speed-links/lec10-jitter.md)，两门课用的是同一套（Hall 书上的）体系。
- BER = 10⁻¹² 时抖动约 1675 ps、眼宽裕量约 200 ps；系统可能在达到 BER = 10⁻¹⁸ 之前都不受抖动限制。

### 系统抖动预算

$$UI \ge DJ_{sys}(\delta\delta) + 2Q(BER)\sigma_{RMS,sys}$$

- 各确定性抖动分量卷积近似为**线性相加**：$DJ_{sys} = \sum_i DJ_i$；
- 各随机抖动分量卷积为**平方和开根**：$\sigma_{sys} = \sqrt{\sum_i\sigma_i^2}$。

PCIe 系统的例子：

$$DJ_{sys} = DJ_{TX} + DJ_{channel} + DJ_{RX} + DJ_{clock},\qquad \sigma_{sys} = \sqrt{\sigma_{TX}^2 + \sigma_{channel}^2 + \sigma_{RX}^2 + \sigma_{clock}^2}$$

### 抖动的频率成分

- 时间间隔误差 $TIE = \Delta\phi/(2\pi f)$（$1/f$ 是理想时钟周期）。
- 用 $PN(f) = 20\log\{2\pi f \cdot TIE(f)\}$ 把相位噪声和抖动联系起来。
- **滤波后的均方根抖动** $= \sqrt{\int |H(f)|^2 \cdot TIE^2\,df}$。
- 抖动源在时钟系统里的位置不同，会被不同地整形/滤波。在 CDR（嵌入式时钟）系统里，考虑采样时钟与输入数据之间的相位误差时，参考时钟抖动会**被发送 PLL 低通滤波、被接收 PLL/CDR 高通滤波**。

## 4.9 前向纠错（FEC）

- 前面分析出：给定 BER 需要一定 SNR。NRZ 下 BER 10⁻¹²（0/1 噪声相等）需要 $Q^2$ 即约 **17 dB**。
- 能不能更好？可以——**在发送的比特里加冗余，接收端用它纠错**，这就是前向纠错。常用码：Reed-Solomon（RS）和 BCH。

### 香农信道容量定理

- 只要编码足够，加性高斯白噪声信道上的无差错传输是可能的，条件是：

$$B_I \le BW\cdot\log_2(1 + SNR)$$

- $B_I$ 是信息比特率，低于编码后的信道比特率 $B = B_I/r$（$r$ 为码率）。假设理想奈奎斯特信令，最小信道带宽 $BW = B/2$，于是：

$$SNR \ge 2^{2r} - 1$$

- 例：$r$ = 0.8（25% 数据开销）时 $SNR \ge 2^{1.6} - 1 = 2.03$，即 **3.08 dB**——比 17 dB 小得多。

### Reed-Solomon 实例

- SONET 标准常用 RS 码。RS(255,239)：每个码字有 $n$ = 255 个符号，但只有 $k$ = 239 个信息符号（其中 1 个用于定帧，不计入数据载荷）。
- 开销 $255/(239-1) = 1.071$，即 7.1%；等价于 $r = 238/255 = 0.933$。
- RS(n,k) 码每个码字可以纠正 $(n-k)/2$ 个符号错误；RS(255,239) 每码字可纠 8 个。

### 编码增益

- 总编码增益 = 达到目标 BER 所需的 SNR 之比（BER 10⁻¹² 时约 **5.9 dB**）。
- 公平比较时应考虑编码需要的带宽增加 1/r，得到**净电编码增益**（约 **5.6 dB**）。

### 软判决解码

- 前面说的都是二进制**硬判决**码。
- 使用更多"模拟"信息（**软判决**）可以再获得约 **2 dB** 的改善。软判决用于 turbo 码和低密度奇偶校验码（LDPC）。
- NRZ 系统中，软判决可以用两个带 δ 偏移的额外比较器，或者 ADC 前端实现；可能需要 AGC 环保持所需的线性度。
