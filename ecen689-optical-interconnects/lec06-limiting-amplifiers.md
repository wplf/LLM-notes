# 第 6 讲 限幅放大器（LA）

> [原讲义 PDF](https://people.engr.tamu.edu/spalermo/ecen689_oi/lecture6_ee689_limiting_amps.pdf) · 参考 Sackinger 第 6 章、Razavi 第 5 章 · 第一次考试覆盖到本讲

提纲：多级限幅放大器 → 带宽扩展技术 → 失调补偿。

## 6.1 限幅放大器的作用

- 把 TIA 的输出放大到可靠的电平，使给定的判决元件（比较器）能达到目标 BER。
- 带宽通常设计为数据率的 **1–1.2 倍**。
- 希望在关心的带宽内**群延迟变化 < 10%**，以限制数据相关抖动（DDJ）。

## 6.2 怎样得到超过 $f_T$ 的增益带宽积？

**例**：10 Gb/s 系统要一个 30 dB（31.6 倍）增益、10 GHz 带宽的放大器，总 GBW 需要 316 GHz。但工艺峰值 $f_T$ 只有 200 GHz，单级放大器能做到的 GBW 一般更低：

- 单级最大带宽 $f_{3dB} = 200\ \text{GHz}/31.6 = 6.3$ GHz，远低于 10 GHz 的要求。

**办法**：把放大器拆成多级，每级增益低、带宽高。从最大 GBW 的角度，最优选择是 **7 级**，每级增益 $A_s = 31.6^{1/7} = 1.64$。考虑多级带宽压缩后，总 GBW 达到 316 GHz 所需的单级 GBW 是 50.8 GHz，工艺可以支持。

## 6.3 多级放大器

若每级都是单极点放大器 $A_s/(1 + s/\omega_{3dB,s})$，n 级级联后：

$$\frac{v_{out}}{v_{in}} = \left(\frac{A_s}{1 + s/\omega_{3dB,s}}\right)^n$$

增益显著增加（$A_s^n$），带宽相对单级会压缩，但压缩得比增益增长慢得多：

$$\omega_{3dB,tot} = \omega_{3dB,s}\sqrt{2^{1/n} - 1}$$

所以多级放大器能显著提高 GBW。

## 6.4 最优级数

- 设工艺能支持的单级最大 GBW 为 $GBW_s$（rad/s），每级增益 $A_s = G_{tot}^{1/n}$，则：

$$\omega_{3dB,tot} = \frac{GBW_s}{G_{tot}^{1/n}}\sqrt{2^{1/n} - 1}$$

- 要高带宽，就要降低每级增益、增加级数；但级数多了带宽又会压缩，所以存在**最优级数**。
- 近似 $2^{1/n} - 1 \approx \ln2/n$，对 n 求导并令其为零（讲义推导过程略），得：

$$n_{opt} = 2\ln G_{tot},\qquad A_{s,opt} = \sqrt{e} \approx 1.65$$

**例**：总增益 100 的多级放大器，$n_{opt} = 2\ln100 = 9.21$，取 9 级，每级增益接近 1.65。

**实际取舍**：

- 这是从最大 GBW 角度的最优级数，但级数少一些带宽也不会掉得太厉害；
- 从功耗和噪声角度，用更少的级数可能更合理；
- **高增益 LA 一般用 3–7 级**。

## 6.5 无源带宽扩展技术

要提高多级放大器的带宽，就要提高每一级的带宽。无源技术：并联峰化、串联峰化、T 线圈峰化。

### 并联峰化（shunt peaking）

- 在负载电阻上串一个电感，在阻抗传递函数中引入一个零点；这个零点使阻抗随频率增加，补偿电容造成的下降，从而扩展带宽。
- 电感太大会出现频率峰化。
- 频响平坦时可获得约 **70%** 的带宽提升；允许 1.5 dB 峰化时最多可提升 **85%**。（$m$ 为 L/R 与 RC 两个时间常数之比。）

### 桥接并联峰化（bridged-shunt）

在电感两端并一个桥接电容，可以在获得最大并联峰化带宽提升的同时补偿频率峰化。实际电感总有寄生 $C_B$，所以即使不加电容 $k_B$ 也大于 0。

### 串联峰化（series peaking）

- 引入串联电感，把负载电容"拆开"为放大器漏极电容 $C_1$ 和下一级栅电容 $C_2$。
- 没有 L 时晶体管要同时给全部电容充电；有 L 时起初只给 $C_1$ 充电，漏极上升时间缩短，带宽提高。
- 电容越分散（$k_C$ 越大），带宽扩展比（BWER）越高：无峰化时最多 **2.5 倍**，允许一些峰化时更高。

### 桥接并联-串联峰化

结合两种峰化可以得到更高的带宽扩展；元件取值合适时可以在**不峰化的情况下接近 4 倍带宽提升**，但需要严格控制元件值，PVT 变化下很难。

### T 线圈峰化

- 输入管漏极电容 $C_1$ 较小时，并联-串联峰化的带宽扩展有限；T 线圈利用变压器的**磁耦合**，在这种情况下效果更好。
- $L_2$ 实现电容分割，起初的电流只给 $C_1$ 充电；电流开始流过 $L_2$ 后，磁耦合使 $L_1$ 中也有电流，提供更多电流给 $C_2$ 充电，改善带宽和跳变时间。
- 无峰化时可获得 **4 倍**带宽扩展；允许峰化时 BWER 可接近 **5**（取决于 $C_1$ 的大小）。

## 6.6 有源带宽扩展技术

无源技术功耗代价几乎为零，但缺点是面积大，并且需要工艺对电感/变压器的支持和表征。有源技术包括：负米勒电容、TIA 负载、有源负反馈。

### 负米勒电容

- 现代工艺中 $C_{gd}$ 占 $C_{gs}$ 的相当大比例（50% 到接近 100%）。
- 米勒效应会把 $C_{gd}$ 乘以增益，使放大器的有效输入电容大增：$C_{in} = C_{gs} + C_{gd}(1 - A)$，A 为负（差分增益）。
- 在放大器输入与输出之间加**交叉耦合电容** $C_n$：它上面的电荷替 $C_{gd}$ 充掉大部分电荷：

$$C_{in} = C_{gs} + C_{gd}(1 - A) + C_n(1 + A)$$

- 令 $C_n = C_{gd}$，则 $C_{in} = C_{gs} + 2C_{gd}$，只要放大器增益大于 1，有效输入电容就减小。

### TIA 负载

- 普通电阻负载：$A_v = g_mR_D$，$C_{in} = C_{gs} + C_{gd}(1 + g_mR_D)$。
- 用 TIA 做负载（跨导级 + 跨阻级）：$A_v = g_mZ_T$。可以证明在相同增益下，配 Butterworth 响应时带宽和输入电容都更好（$C_{in} = C_{gs} + C_{gd}(1 + g_mR_F/\ldots)$，讲义推导略）。
- 典型例子是 **Cherry-Hooper 放大器**。

### 有源负反馈

- 不用简单的一阶放大单元，而用带有源负反馈的**二阶单元**，可以提升带宽。
- 这个二阶单元可以针对不同目标优化；例如把反馈跨导 $G_{mf}$ 设到产生 Butterworth（最大平坦频响）响应，此时 $\omega_{-3dB} = \omega_n$。
- 二阶单元的增益带宽积**有可能超过工艺 $f_T$**。设 $G_m/C = \alpha\omega_T$，且 $G_{m1}/C_1 \approx G_{m2}/C_2 \approx \alpha\omega_T$，则：

$$A_{vo}\omega_{-3dB} = \frac{(\alpha\omega_T)^2}{\omega_{-3dB}} = \omega_T\cdot\frac{\alpha^2\omega_T}{\omega_{-3dB}}$$

当 $\omega_{-3dB} < \alpha^2\omega_T$ 时，GBW 就超过 $\omega_T$。

## 6.7 限幅放大器实例

- **Galal JSSC 2003**：同时用了电阻负载、有源负反馈、并联电感峰化、负米勒电容几种技术。
- **Proesel ISSCC 2012**：LA 各级使用 T 线圈，结合了串联和并联峰化，带宽扩展接近 3 倍。

## 6.8 失调补偿

- 限幅放大器的输入等效失调会恶化接收灵敏度，常用**功率代价**量化（见第 4 讲）。所以多级限幅放大器的失调必须最小化。

### 低频负反馈环

- 用低频负反馈环补偿 LA 的直流失调 $V_{os}$。理想情况下失调被降到 $V_{os}/(1 + A\cdot A_{EA})$ 的量级。
- 但如果误差放大器本身有失调，失调会变成 $V_{os,EA}$ 量级（两者不相关）。

### 低频截止

- 反馈环中的低通滤波会造成**低频截止**：

截止频率大致为反馈环滤波器的极点频率 $1/(2\pi RC)$ 乘以环路增益（主放大器增益 A 与误差放大器增益 $A_{EA}$ 的乘积）；讲义的式子还含一个与 50 Ω 驱动源相关的因子，抽取不完整。

- 所以反馈环带宽必须做得**远低于输入数据的最低频率成分**。
- 这可能需要很大面积的无源器件；有些设计利用误差放大器的**米勒电容倍增**来减小滤波器面积。
