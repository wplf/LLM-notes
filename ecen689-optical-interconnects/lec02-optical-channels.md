# 第 2 讲 光信道

> [原讲义 PDF](https://people.engr.tamu.edu/spalermo/ecen689_oi/lecture2_ee689_optical_channels.pdf) · 主要参考 Sackinger 第 2 章

提纲：光纤（一般属性、损耗与带宽、色散、非线性）→ 色散造成的脉冲展宽 → 硅光波导 → 链路预算实例。

## 2.1 光纤的一般属性

- 光纤靠高折射率纤芯与低折射率包层之间的**全内反射**约束光；光要在光纤中传播，从边界反射形成的模式必须满足谐振条件。
- 按支持的模式数分类：

| | 多模光纤（MMF） | 单模光纤（SMF） |
|---|---|---|
| 芯径 | 通常 50 或 62.5 μm | 通常 8–10 μm |
| 耦合 | 容易 | 需要仔细对准（成本高） |
| 模式 | 多个 | 只有一个（含两种正交偏振） |
| 主要限制 | **模式色散** | 长距离以**损耗**为主；色散和 PMD 在 < 10 km 时一般可忽略 |
| 规格 | 带宽-距离乘积：老式 MMF 200 MHz·km，优化 MMF > 2 GHz·km | 距离 > 100 km |
| 应用 | 楼内计算机互连 | 超长距、长距、城域、接入网 |

**为什么不都用 SMF**：耦合进 SMF 比 MMF 难得多，装配成本更高。但超大规模数据中心在规模和速率上不断扩张，可能会要求在互连尺度上使用 SMF 系统。

- **WDM**：单模光纤只支持一个模式，提高带宽密度的办法是用多个波长传独立信息，把光纤几个 THz 的带宽用许多波长、每个独立调制在几十 Gb/s。

## 2.2 损耗

- 损耗来自散射、材料杂质吸收等，用 dB/km 表示。
- 单模光纤在 1550 nm 处约 0.25 dB/km；射频同轴电缆在 10 GHz 处约 500 dB/km。

**标准石英光纤的传输窗口**：

| 波段 | 波长 | 说明 |
|---|---|---|
| C 波段（常规） | 1530–1565 nm | 损耗最低点附近，与 L 波段合计 95 nm / 11 THz 带宽 |
| L 波段（长波长） | 1565–1625 nm | |
| O 波段（原始） | 1260–1360 nm | 1310 nm 附近色散接近零，长距离常用 |
| — | 850 nm（800–900 nm） | 光源和探测器便宜，短距离常用 |

**塑料光纤（POF）**：绝大部分光纤是超纯石英玻璃，POF 是用于照明和低速短距数据链路的小众光纤。制造成本低，1 mm 大芯径极易耦合，但损耗高达 180 dB/km。IEEE 802.3 有千兆以太网走 POF 的研究组。

**光放大器**：掺铒光纤放大器（EDFA）在 1550 nm 提供增益；拉曼放大器可以在传输光纤中提供分布增益。虽然有效，但对高产量、短距离（< 10 km）的光互连来说太笨重、太贵——本课关注的就是这个范围。

## 2.3 光纤的两个"带宽"

- **光载波带宽**：假设频谱纯净，1550 nm 附近有 11 THz，非常大。
- **调制信号带宽**：常受色散限制。1 nm 线宽下，标准单模光纤 1 km 只有几十 GHz。
- WDM 用多个载波，每个调制在约 10 Gb/s，就能利用载波带宽实现 Tb/s 级的总通信容量。

## 2.4 色散

色散是高速脉冲在时间上的展宽，会造成 ISI 并恶化 BER。

| 类型 | 机理 |
|---|---|
| **模式色散** | 多模光纤中各模式传播延迟不同 |
| **色散（群速度色散）** | 单模光纤中调制光载波的不同频率成分速度不同 |
| **偏振模色散（PMD）** | 单模光纤中两个偏振态速度不同 |

### 模式色散

渐变折射率（GRIN）多模光纤的脉冲展宽近似为：

$$\Delta T \approx \frac{L\,n_{cor}}{8c}\left(\frac{n_{cor} - n_{clad}}{n_{cor}}\right)^2$$

例：L = 1 km、$n_{cor}$ = 1.48、$n_{cor} - n_{clad}$ = 0.02，得 $\Delta T \approx$ 113 ps（笔者按此式计算；讲义算式抽取不完整，页面标注的量级偏小，请对照原讲义）。若要求展宽只有位周期的 10%，1 km 下最高速率不到 1 Gb/s；10 Gb/s 时 MMF 长度典型为 100–300 m。

### 色散（群速度色散）

- 用色散参数 $D$ 表示：每 nm 波长、每 km 距离的群延迟变化。
- $D = \dfrac{1}{L}\dfrac{\partial\tau}{\partial\lambda}$；标准单模光纤在 1550 nm 处 $D$ = 17 ps/(nm·km)。
- **脉冲展宽**与发送端谱线宽度 $\Delta\lambda$ 和距离成正比：

$$\Delta T = D\cdot\Delta\lambda\cdot L$$

1 nm 谱线宽的光源，在 $D$ = 17 ps/(nm·km) 的标准单模光纤上 1 km 展宽 17 ps。

**抑制方法**：

- **色散补偿光纤（DCF）**：让信号经过一段很短、色散参数极性相反且绝对值很大的光纤（典型 $D$ = −100 ps/(nm·km)）。
- **电均衡器**：把复杂度放到接收 IC 里，可能比额外的 DCF 便宜；但检测过程中光的相位信息已经丢失，补偿效果可能不如 DCF。

### 偏振模色散（PMD）

- 光纤的偏振影响沿长度**随机**变化，所以 PMD 有统计不确定性：

$$\Delta T = D_{PMD}\sqrt{L}$$

- PMD 还是时变参数，补偿起来复杂。
- 老式光纤 $D_{PMD}$ = 2 ps/√km，新光纤 0.1 ps/√km。数据中心规模（< 10 km）一般可以忽略。
- 长距离的抑制手段：用短段保偏光纤配自适应偏振控制；或自适应电子均衡器。

## 2.5 非线性

前面讨论的损耗和色散都是**线性**效应。各种非线性效应会扭曲或衰减光信号，或者在 WDM 通道之间造成串扰：

| 效应 | 机理 |
|---|---|
| 自相位调制（SPM） | 光脉冲通过光学克尔效应引起折射率变化，产生相移 |
| 交叉相位调制（XPM） | WDM 系统中，一个波长通过克尔效应影响另一个波长的相位 |
| 受激拉曼散射（SRS） | 光子与热致振动的光纤分子散射，产生不同波长的光 |
| 受激布里渊散射（SBS） | 声波引起的移动折射率变化造成散射，产生不同波长的光 |
| 四波混频（FWM） | WDM 系统中 2 或 3 个波长相互作用产生 1 或 2 个新波长，类似电系统中的互调失真 |

**抑制方法**：非线性主要因为光纤里光功率太大，**降低光功率**并用前向纠错（FEC）补偿 BER 的恶化；另一个办法是让光纤带一点色散，使各波长以不同速度传播、减少相互作用。

## 2.6 非线性的通信信道

- 常见的直接检测光通信系统中，发送端调制光源的**功率（强度）**。
- 但光纤的色散对光的**电磁场**是线性响应，而场正比于强度的平方根。
- 接收端的光电探测器响应的又是光的强度，所以常叫"**平方律探测器**"。
- 这个非线性使线性系统理论不能严格适用。**但如果光源的频谱 $\Delta\lambda_s$ 远宽于调制引起的带宽**，就可以把发送总线宽 $\Delta\lambda$ 近似为光源线宽：

例：1550 nm 激光器 1 nm 线宽对应 125 GHz。这对宽线宽光源（LED、FP 激光器）成立，但对高性能 DFB 激光器可能不成立。在这个近似下，系统可以当作线性的。

### 光纤的冲激响应

假设光源是高斯型的：

$$h(t) \propto \exp\!\left(-\frac{t^2}{2\Delta T^2}\right),\qquad \Delta T = D\cdot\Delta\lambda\cdot L$$

理想冲激输入会展宽成 2σ 宽度等于 $\Delta T$ 的波形。例：1 km、$D$ = 17 ps/(nm·km)、1 nm 线宽下，冲激会展宽到 17 ps。

### 时域与频域分析

- 有了冲激响应就可以与任意输入卷积得到时域输出：$y(t) = x(t)*h(t)$，$H(f) = \mathcal{F}\{h(t)\}$。
- 若输入脉冲也是高斯型，两个高斯卷积还是高斯，输出宽度可以直接算：

$$\Delta T_{out} = \sqrt{\Delta T_{in}^2 + \Delta T^2}$$

例：100 ps 输入脉冲经 1 km、$D$ = 17 ps/(nm·km)、1 nm 光源，输出 2σ 宽度为 $\sqrt{100^2 + 17^2} \approx 101.4$ ps。

- 频域上 $|H(f)| = \exp(-2\pi^2\Delta T^2f^2)$，令其为 1/2 得到 3 dB 带宽：

$$BW_{3dB} \approx \frac{0.375}{D\cdot\Delta\lambda\cdot L}$$

例：1 km、$D$ = 17 ps/(nm·km)、1 nm 光源，3 dB 带宽约 22.1 GHz。

### 可接受的脉冲展宽

NRZ 系统一般要求 $\Delta T$ 小于半个位周期：

$$\Delta T \le \frac{1}{2B}\quad\Rightarrow\quad BW_{3dB} \ge B$$

对 10 Gb/s 系统希望有 7.5 GHz 的光纤带宽以避免过度失真。系统分析表明，脉冲宽度增加 12%（即 $\sqrt{1 + 0.5^2} = 1.12$）对应 **1 dB 功率代价**。

### 窄线宽光源的注意点

上述分析的关键假设是光源频谱远宽于调制带宽。对高性能 DFB 激光器这不成立；当调制信号决定带宽时，由于信道是非线性的，上面这些式子不能严格套用，但仍可以用来获得直觉。

## 2.7 硅光波导

- 硅芯（折射率约 3.5）加 SiO₂（约 1.5）包层，可以做成亚微米截面：线型波导宽 320 nm、高 220 nm。
- 芯外倏逝场通常在 300 nm 内衰减，所以平行波导可以排得很密；弯曲半径可以小于 5 μm，光子集成电路可以做得很紧凑。
- 片上波导一般是单横模，但支持 TE 和 TM 两种偏振。两种偏振的传播常数可能不同（片上距离内 PMD 可忽略）。TE 模在侧壁的场强更高，而侧壁在工艺中更难做光滑，所以 TE 模损耗通常更大。

| 工艺平台 | 损耗 | 说明 |
|---|---|---|
| SOI | 约 1 dB/cm | 埋氧层厚，能约束住光模 |
| 体硅 CMOS | 约 1000 dB/cm | 薄 STI 使光模大量漏进硅衬底 |
| 体硅 CMOS + 深槽隔离 | 约 10 dB/cm | 关键是在波导和衬底之间加**深槽隔离氧化层**，再加一次部分多晶硅刻蚀做脊型波导和更好的耦合器（Sun JSSC 2015） |
| 后端工艺（氮化硅） | 约 1 dB/cm | 做在金属化层之上；尺寸 450 nm × 500 nm |

### 进出芯片的耦合

把小的硅波导直接对接（端面耦合）效率低，常有约 20 dB 损耗，所以需要模式转换器或耦合器：

| 结构 | 做法 | 损耗 |
|---|---|---|
| 垂直渐缩波导 | 在芯片边缘附近增大波导高度形成绝热渐变 | 约 3 dB |
| 倒锥形波导 | 把波导高度渐缩到很小，使模式与光纤芯更好地匹配 | 可优于 1 dB |
| 表面光栅耦合器 | 光纤以特定角度引入，把垂直光耦合进水平波导；系统上更方便 | 1–1.5 dB，在 20 nm 范围（1537–1557 nm）内 |

## 2.8 链路预算实例

### VCSEL + 多模光纤

关键假设：850 nm VCSEL，$P_{avg}$ = 3.0 dBm，ER = 7.3 dB（OMA = 4.38 dBm = 2.74 mW）；短距离链路，光纤损耗和色散可忽略。

| 项目 | 损耗 (dB) | P1 (mW) | P0 (mW) | ΔP (mW) | Pavg (mW) |
|---|---|---|---|---|---|
| VCSEL | — | 3.36 | 0.63 | 2.74 | 2.00 |
| VCSEL 到 MMF 耦合 | −1.1 | 2.61 | 0.49 | 2.13 | 1.55 |
| MMF 损耗（2.3 dB/km） | 0 | 2.61 | 0.49 | 2.13 | 1.55 |
| MMF 到 PD 耦合 | −1.1 | 2.03 | 0.38 | 1.65 | 1.20 |
| 裕量 | −3 | 1.02 | 0.19 | 0.83 | 0.60 |
| **接收 OMA 灵敏度** | | | | | **−0.83 dBm** |
| ER 代价 | −1.64 | 0.83 | 0 | 0.83 | 0.41 |
| 理想 ER 的接收 Pavg 灵敏度 | | | | | −3.84 dBm |

链路距离可能受**光纤损耗**（接收灵敏度）限制，也可能受**模式色散**限制。高性能 OM5 多模光纤：损耗 2.3 dB/km，带宽 4.7 GHz·km。NRZ 下要求 $BW_{fiber} \ge 0.75\times\text{Data Rate}$。假设接收机 OMA 灵敏度 −8.0 dBm，这个距离适合 HPC 系统，但可能不适合大型数据中心。

### RRM + 单模光纤

关键假设：连续波（CW）源激光器 $P$ = 5.3 dBm；短距离链路，光纤损耗和色散可忽略。

- 距离可能受光纤损耗或**色散**限制。用 SMF-28 Ultra 光纤时：

$$L \le \frac{1}{D\cdot\Delta\lambda\cdot B}$$

（$\Delta\lambda$ 是信号带宽，NRZ 下近似为 $B$；$D$ 是光纤色散参数。）

- 假设接收机 OMA 灵敏度 −14.9 dBm，这个距离适合大型数据中心。**1310 nm 在更高速率下有明显的距离优势。**
