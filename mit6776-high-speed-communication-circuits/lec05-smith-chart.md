# 第 5 讲 广义反射系数与 Smith 圆图

> [原讲义 PDF](https://ocw.mit.edu/courses/6-776-high-speed-communication-circuits-spring-2005/resources/lec5-1/) · 公式按标准形式补写

## 5.1 广义反射系数

- 前面把负载阻抗与特性阻抗联系起来得到了负载处的反射系数。能否求出**负载以外位置**的反射系数？——广义反射系数。

### 电压电流波形

- 第 3 讲得到，正弦稳态下传输线中的波为 $Ae^{j(\omega t \mp kz)}$，"−"号对应沿 +z 方向的波，"+"号对应沿 −z 方向的波。
- 取负载在 z = 0，入射波 $V_ie^{j(\omega t - kz)}$，反射波 $\Gamma_LV_ie^{j(\omega t + kz)}$。

### 不同位置的电压电流

入射波和反射波相加：

$$V(z) = V_ie^{-jkz}\left(1 + \Gamma_Le^{j2kz}\right),\qquad I(z) = \frac{V_i}{Z_0}e^{-jkz}\left(1 - \Gamma_Le^{j2kz}\right)$$

**定义广义反射系数**：

$$\Gamma(z) = \Gamma_Le^{j2kz}$$

（负载在 z = 0、向源方向 z 为负时，Γ 在复平面上随距离**顺时针**转动，每 λ/2 转一圈。）

## 5.2 电压沿线的变化与驻波比

- 计算 $V(z,t)$ 的最大最小值：$|V|_{max} = |V_i|(1 + |\Gamma_L|)$，$|V|_{min} = |V_i|(1 - |\Gamma_L|)$。
- 可以**几何地**理解：$|1 + \Gamma(z)|$ 是单位圆心到点 −1 再到 Γ 的距离，随 Γ 转动而变化。
- 反射使幅度沿线变化。
- **电压驻波比（VSWR）**：

$$VSWR = \frac{|V|_{max}}{|V|_{min}} = \frac{1 + |\Gamma_L|}{1 - |\Gamma_L|}$$

从测得的驻波比可以推出反射系数的幅度。

## 5.3 阻抗随位置变化

$$Z(z) = \frac{V(z)}{I(z)} = Z_0\frac{1 + \Gamma(z)}{1 - \Gamma(z)}$$

- 注意它**不是时间的函数**，只是到负载距离的函数。
- $Z(z)$ 和 $\Gamma(z)$ 在 z 上以 **λ/2 为周期**变化。

### 例子

- **λ/4 处**：$\Gamma$ 转半圈变号，$Z(-\lambda/4) = Z_0^2/Z_L$——**阻抗被反转**（$Z_0$ 为实数）。这就是四分之一波长变换器。
- **短路负载、长度小于 λ/4**：$Z = jZ_0\tan(kl)$，**看起来像电感**。
- **开路负载、长度小于 λ/4**：$Z = -jZ_0\cot(kl)$，**看起来像电容**。

### 与理想 LC 谐振腔比较

- 理想 LC 并联谐振腔在谐振附近的输入阻抗可以写成 $Z \approx \dfrac{1}{j2C\Delta\omega}$ 之类的形式。
- **传输线版本**：短路负载、长度 λ/4 时，用广义反射系数算出的阻抗在 λ/4 对应频率附近也呈现这种形式——**看起来像 LC 谐振腔（但不止一个模式）**：在 3λ/4、5λ/4… 处还会再次谐振。

## 5.4 Smith 圆图

- 在以 Γ 为坐标的平面上工作；把 $z = Z/Z_0 = r + jx$ 代入 $\Gamma = (z - 1)/(z + 1)$，令实部和虚部分别相等，就得到 Smith 圆图：
    - 等电阻 r 的轨迹是圆，圆心 $(r/(1+r),\,0)$，半径 $1/(1+r)$；
    - 等电抗 x 的轨迹也是圆，圆心 $(1,\,1/x)$，半径 $1/|x|$。

### 阻抗求逆

在 Γ 平面中，把 Γ 旋转 180°（$\Gamma \to -\Gamma$）就把归一化阻抗变成了归一化导纳。

### 把 Smith 圆图当作匹配网络的计算器

- 同时画出阻抗曲线和导纳曲线：电导曲线由电阻曲线得到，电纳曲线由电抗曲线得到。
- **串联电路用阻抗**（串联阻抗相加）；**并联电路用导纳**（并联导纳相加）。
- 串联电感沿等电阻圆向上（感性）移动，串联电容向下；并联电容沿等电导圆移动，并联电感反向。
- 完整的 Smith 圆图把四种曲线叠在一起。参考 Agilent AN 95-1 的交互匹配页面。

## 5.5 例：在 2.5 GHz 把 RC 网络匹配到 50 Ω

1. 把负载阻抗归一化：$Z_{Ln} = Z_L/50$。
2. 在 Smith 圆图上画出起始阻抗（用导纳 $Y_{Ln}$）。
3. **制定匹配"方案"**：从图上看出，用一个串联电感 $L_m$ 和一个并联电容 $C_m$ 构成的 L 匹配网络可以把输入阻抗带到圆图中心 50 Ω（需要把阻抗升高）：
    - 电感 $L_m$ 沿电抗曲线把阻抗往上移；
    - 电容 $C_m$ 沿电纳曲线把阻抗往下移到中心。
4. 从圆图读出所需的电抗 $x$，$L_m = xZ_0/\omega$；读出所需的电纳 $b$，$C_m = b/(Z_0\omega)$。
5. 加上 $C_m$ 后实现匹配。
