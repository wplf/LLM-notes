# 第 1 讲 通信系统概览

> 2005-02-01 · [原讲义 PDF](https://ocw.mit.edu/courses/6-776-high-speed-communication-circuits-spring-2005/resources/lec1/)

提纲：调制技术（幅度调制：标准 AM、双边带 DSB、单边带 SSB、正交幅度调制 QAM；恒包络调制：PM、FM）→ 多址方式（FDMA、TDMA、CDMA）→ 超宽带（UWB：脉冲、OFDM）。

## 1.1 幅度调制

### 标准 AM

- 用基带调制信号改变载波频率 $f_o$ 上正弦波的幅度：$y(t) = [1 + m\,x(t)]\cos(2\pi f_ot)$。
- 基带信号的直流分量会影响发射信号和接收方式：直流值大于信号幅度时，包络就是基带信号本身，接收端可以用简单的**包络检波器**。
- 代价：在载频上发出一个**很强的载波单音**，它的频率和相位固定、不携带信息，浪费发射功率。

**频域看**：基带信号有直流分量，在 DC 处有一个冲激；调制后发射信号在载频处有一个冲激。

### 双边带抑制载波（DSB）

- 基带信号直流为零时，被调正弦的包络不再直接对应基带信号，而是基带波形的**绝对值**；基带取负值时载波相位翻转 180°。因此**不能再用包络检波器**。
- 去掉了不携带信息的载频单音，同样发射信噪比下需要的发射功率更少，功率效率更高。

### 相干检测接收机

- 用本振（LO）与接收信号相乘再低通滤波；无论基带信号直流是多少都能工作。
- 要求接收端本振在频率和相位上都与载波**准确对齐**。
- **相位失配的影响**：最坏情况是接收本振与载波相差 90°，此时解不出想要的基带信号（输出与 $\cos\theta$ 成正比，θ = 90° 时为零）。

### 单边带（SSB）

- 上边带（USB）和下边带（LSB）对称，携带相同的信息。
- 标准 AM 既不省功率也不省带宽；DSB 省了功率，但仍占两倍必要带宽。
- 大多数基带信号没有直流或极低频分量，所以可以在中频或射频把一个边带去掉（在中频滤更容易）。
- 用边带滤波器或移相法去掉一个边带后，**信号带宽减半**，带宽效率更高。

### 正交幅度调制（QAM）

- 利用相干接收机对与发射本振相位对齐的敏感性：实际上得到了两个**正交**的传输信道（I 和 Q）。
- 发射端把两个独立的基带信号（I、Q）调制到两个正交的正弦上；接收端用两个正交的正弦解调。
- 接收本振必须在频率和相位上与发射本振对齐；对齐后 I、Q 可以恢复。
- **90° 相位失配时**，I、Q 在接收端互换，但**没有丢失信息**——可以在基带 DSP 中把它恢复出来。
- 讨论中做简化：收发相位对齐、接收低通理想、收发 I/Q 只差一个比例因子。现实中 RF 信道会加入失真、造成衰落，由基带 DSP 纠正。

## 1.2 模拟调制与数字调制

- **模拟调制**：I/Q 在时间上取连续值；用于 AM/FM 收音机、（非高清）电视和第一代手机。新系统一般改用数字调制。
- **数字调制**：I/Q 在离散时刻取离散值，对应数字数据；接收端采样 I/Q，用**判决边界**判定每个时刻的数据。可以是二值的，也可以是多比特的。

**数字调制的优点**

- 信息可以"打包"：可以在时间上压缩、作为数据包通过网络高效发送；而模拟调制需要一直可用的连接，信息流中有空闲时会浪费无线信道。
- 可以做纠错，对无线信道的不理想不那么敏感。
- 可以压缩信息，更有效地使用信道。
- 支持各种信息内容：语音、文本、电子邮件、视频都可以表示成数字比特流。

### 星座图

- 在二维坐标系上看采样时刻的 I/Q 值；判决边界把平面划分为对应不同数据值的区域。
- 用**格雷码**编码，使噪声导致判错时出错的比特数最少（例：I、Q 各编码为 2 比特）。
- **噪声的影响**：采样值不再落在完全相同的位置，判决边界固定；噪声大时就会判错。**信道 SNR 决定了最多能用多少比特。**

## 1.3 恒包络调制

### 功率效率问题

- 在很多无线系统里，**功率放大器（PA）主导了功耗**；线性 PA 比非线性 PA 更耗电。
- 恒包络调制允许使用**非线性 PA**，功耗可以更低。

### 实现

- 恒包络调制只能是相位调制或频率调制。
- 用理想 VCO 就能同时实现相位和频率调制，可以拿来做分析模型；但用实际 VCO 几乎不可能做相位调制。

### 星座图

- I/Q 信号必须组合成恒定幅度，所以星座点都在 I/Q 平面的一个**圆**上；判决边界按相位区域划分。
- 恒包络的要求迫使星座点之间的**跳变也沿圆进行**，因此 I/Q 滤波不能各自独立进行——这会显著影响输出频谱。

## 1.4 多址方式

- 要让很多不同用户通信，而自由空间频谱是共享资源，必须在用户之间划分。可以按**时间**、**频率**，或通过对数据信号做（近似）**正交编码**来划分。

### 频分多址（FDMA）

把用户放在不同的频率信道；对单个用户的收发有两种处理方式：

| | 频分双工（FDD，全双工） | 时分双工（TDD，半双工） |
|---|---|---|
| 做法 | 频率信道分成发射频段和接收频段，可以同时收发；用**双工器**隔离接收机和发射机 | 收发用任意同一频率信道，但在不同时刻进行；用**开关**切换 |
| 用户间通信 | 不能直接在用户之间通信，只能在手机与基站之间 | 可以直接在用户之间通信（不一定是好事） |
| 优点 | 用户之间相互隔离 | 开关的插损比双工器低 |
| 缺点 | 双工器插损高（衰减通过的信号）；占两倍带宽 | 接收机对其他用户的发射信号更敏感 |

### 时分多址（TDMA）

- 把用户放在不同的时隙，某个时隙按帧周期重复。
- 常与 FDMA 结合，让多个用户占用同一频率信道。

### 码分多址（CDMA）

**正交编码的原理**：两个独立的随机伯努利序列相乘，结果仍是随机伯努利序列；同一序列与自身相乘，结果是 +1 或 −1（取决于相对极性）。

- 给每个发射机分配一个**唯一的码序列**；通过改变码序列的极性把数据编码进发射输出。数据序列中每个脉冲的周期为 $T_d$（代表二进制数据）；码序列中每个脉冲的周期为 $T_c$，称为**码片（chip）**。
- 接收机把输入与目标发射机的码做相关：目标发射机的数据被恢复，其他发射机的数据仍然是随机化的。
- **频域看**：数据和码片序列时间尺度不同，频谱宽度和高度也不同。CDMA 发射机把数据编码到码片序列上，**展宽了数据频谱**（扩频）；接收机与目标码相关后，目标信道的频谱恢复到原来的宽度，非目标信道的频谱仍然很宽，可以用低通"大部分"滤掉。

## 1.5 超宽带（UWB）

- 扩频通信的极端情况。利用香农定理：数据率随带宽**成比例**增长，而随 SNR 只按**对数**下降。每赫兹的辐射能量非常低。
- **标准**：FCC 最近开放了 3.1–10.6 GHz 给 UWB；IEEE 有两个标准在制定中。应用覆盖 1–100 m 距离、500 kb/s 到 500 Mb/s 速率：WLAN、定位/标签、无线 USB 与多媒体。

| | 脉冲 UWB | OFDM UWB |
|---|---|---|
| 原理 | 数据编码在冲激串中；（"马可尼发明了它！"）本质上是一种 TDMA | 利用窄带通信的大量已有知识 |
| 特点 | 可以利用多径；收发机里不需要窄带滤波器（RF 或基带）；**必须做到极其严格的时间同步** | 包含窄带系统常见的模块（滤波器、LNA 等）；每个信道带宽宽得多，滤波比窄带系统容易；每个信道的 SNR 要求低得多；数字处理比脉冲方式多；可以避开强干扰 |
