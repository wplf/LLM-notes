## 15.1 压控振荡器

- 加入调谐元件来调节振荡频率，通常用**可变电容（变容管）**代替（部分）固定电容。
- 注意总有一些固定电容去不掉（晶体管结电容、互连等），**固定电容会缩小调谐范围**。

### 电压到频率、电压到相位的模型

- 在偏置点附近用小信号方式建模，假设输入电压与频率偏移成线性关系：$f_{out}(t) = f_o + K_vv_{in}(t)$。
- 分析时相位比频率更方便，两者是积分关系：

$$\Phi_{out}(t) = 2\pi K_v\int v_{in}(t)\,dt$$

- 直观理解：频率是相位的变化率。
- 取拉普拉斯变换得到频域模型：$\Phi_{out}(s)/V_{in}(s) = 2\pi K_v/s$。

### 变容管的实现

| 类型 | 说明 |
|---|---|
| **二极管变容管** | 反偏二极管结，耗尽电容可变；电容大约随反偏电压的平方根下降。优点：可以在 CMOS 中完全集成。缺点：Q 低（常 < 20），调谐范围小 |
| **MOS 变容管**（近来流行） | MOS 管（NMOS 或 PMOS），反型沟道形成时电容突变。优点：容易在 CMOS 中集成。缺点：在过渡区 Q 较低；加在变容管上的是**大信号**，每个 VCO 周期都会扫过过渡区；**注意栅到衬底电容** |
| **提高 MOS 变容管 Q 的方法** | 切换高 Q 的金属电容做**粗调**，用低 Q 的 MOS 变容管做**细调**（Hegazi 等，"A Filtering Technique to Lower LC Oscillator Phase Noise"，JSSC 2001） |

### 电源牵引与推移（pulling/pushing）

- 电源电压会影响 VCO 频率：变容管两端电压变化导致电容变化；晶体管漏结两端电压变化导致耗尽电容变化。
- 解决办法：为 VCO 建一个稳压电源。

## 15.2 振荡器的注入锁定

**机理**

- 远离 $\omega_o$ 时 $G(j\omega)$ 的幅度仍然很大。
- 如果电路是纯线性的，输出就是 $\omega_o$ 处的振荡与 $\omega_o + \Delta\omega$ 处被放大的输入之和（叠加）。
- 实际振荡器的传递函数是**非线性**的，以保持幅度恒定（幅度反馈或饱和的 $G_m$）。

**直观理解（线性情况）**：设想让输出达到期望幅度（比如 1 V）后，采样保持 $G_m$、断开幅度反馈，使振荡器传递函数成为线性的；此时 $G_m$ 恰好使 $\omega_o$ 处的环路增益为 1，输出是恒定幅度的正弦。再注入一个频率为 $\omega_o + \Delta\omega$ 的小正弦，它会被大大放大。

**非线性情况**：重新接上幅度反馈，它会降低 $G_m$，使总幅度保持在 1 V；调整后的 $G_m$ 远低于维持 $\omega_o$ 振荡所需的值。于是输出只剩 $\omega_o + \Delta\omega$ 处的正弦，幅度 1 V——**VCO 频率被锁定到注入频率**，而不是自由振荡频率。

**不希望的注入锁定**：零差系统中 VCO 频率可能非常接近 RF 输入频率；如果隔离不够，就会发生注入锁定。办法：在 VCO 后面接一个反向隔离好的缓冲级。

## 15.3 近期 VCO 技术

- **$g_m$ 提升的 VCO**（Xiaoyong Li 等，ISSCC 2005）：回顾 $g_m$ 提升的 LNA 降低了噪声因子——表观上 $g_m$ 的提升来自栅和源上波形相差 180°。类似的概念可以用于 VCO 以降低相位噪声。变压器耦合可以实现，但占面积；也可以直接把输出反馈到源极来提升 $g_m$。
- **宽调谐范围 VCO**：Guermandi 等，"A 0.75 to 2.2GHz Continuously-Tunable Quadrature VCO"，ISSCC 2005。
- **极高频 VCO**。
- **圆形几何振荡器**（Aparicio & Hajimiri，ISSCC 2004）：
    - 平板（slab）电感比螺旋/圆形电感 Q 更高（电流拥挤和衬底损耗更少）；
    - 传统振荡器拓扑中，互连会附加电感/损耗；圆形几何振荡器消除了这个问题；
    - 实现：在直流处把输出短接以去掉稳定的直流工作点；在偶次谐波处把输出短接以抑制不希望的模式。
- **圆形驻波振荡器（CSWO）**：基于环形传输线中的驻波（波叠加注入能量），通过偶模抑制连接只保留期望模式。

## 15.4 混频器

### 无线系统混频器的设计指标

| 指标 | 说明 |
|---|---|
| 噪声系数 | 影响接收机灵敏度 |
| 线性度（IIP3） | 影响接收机阻塞性能 |
| 变频增益 | 降低后级的噪声影响 |
| 功率匹配 | 通常要的是最大电压增益而不是功率匹配 |
| 功耗 | 越低越好 |
| 隔离 | 尽量减少 RF、IF、LO 端口之间的相互作用 |
| 对工艺/温度的敏感性 | 要可制造 |

### 理想混频器行为

- 把 RF 频谱变换到较低的 IF 中心频率（IF：中频）。
- IF 非零：外差或低中频接收机；IF 为零：零差接收机。
- 在 IF 输出用滤波器去掉不需要的高频分量。

### 镜像混叠

- IF 非零时，对给定的期望信道存在一个**镜像频带**；镜像频带中的内容会与期望信道在 IF 输出处合并，**混频之后无法去除**。

### 本振馈通

- **正向**：LO 通过寄生电容、电源耦合等馈通到 IF 输出；由于 LO 比 RF 信号大得多，往往很显著。如果很大，占用 IF 输出的额外动态范围，可能使接收机灵敏度下降；如果小，一般可以用 IF 滤波器去掉。
- **反向**：LO 经寄生电容等馈通到 RF 输入。如果很大、LNA 隔离不够，LO 能量可能从天线漏出，违反辐射规范；必须保证到天线的隔离足够。
- **反向馈通的自混频**：RF 输入中的 LO 分量会再次经过混频器、被 LO 调制，在 IF 输出产生直流和 $2f_o$ 分量。对外差系统无关紧要，但对零差（零中频）系统会造成问题。

### 去除镜像干扰的三种办法

| 办法 | 说明 | 问题 |
|---|---|---|
| **1. 镜像抑制滤波器** | 在混频器前用滤波器阻止镜像混入期望信道 | 必须用**高中频**：滤波器带宽要足以通过所有信道，而 Q 不能无限高（低中频需要高 Q） |
| **2. 直接变到基带（零差）** | IF 为零，没有镜像频带 | LO 馈通的直流项如果时变会破坏信号；直流失调会吃掉 IF 输出的动态范围；1/f 噪声；经天线的反向辐射 |
| **3. 镜像抑制混频器** | 用与 SSB 产生类似的方法抑制镜像 | 受 RF 和 LO 路径幅度、相位匹配限制，典型 **40 dB**；必要时 RF 滤波器可以进一步减小镜像，否则可以省掉 RF 镜像抑制滤波器 |

讲义用两页频域图说明镜像抑制混频器中期望信号与镜像的符号关系，并指出：**无论 RF 信号的相位如何，镜像都能被抑制**。
