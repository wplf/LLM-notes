# 第 16 讲 混频器（续）

> [原讲义 PDF](https://ocw.mit.edu/courses/6-776-high-speed-communication-circuits-spring-2005/resources/lec16/) · 公式按标准形式补写 · 本讲之后有小测验

## 16.1 镜像抑制混频器（回顾与另一种实现）

- 不把镜像滤掉，而是用镜像抑制架构把它**抵消掉**；这样可以用低中频而不需要高 Q 滤波器。
- 抑制水平由路径之间的增益和相位失配决定；实际架构限于约 **40 dB**。

### 另一种实现

- 避免对**信号**做 90° 移相；
- 对 **LO 输出**做精确的 90° 移相容易得多：可以用正交 VCO 或分频器。

### 原理（四步）

讲义用四步频域图展示：RF 输入分别乘以 LO 的余弦和正弦，得到 c(t) 和 d(t)；再分别乘以第二本振的余弦和正弦；最后相减（或相加），期望信道保留、镜像抵消。

**实现问题**：

- 全模拟架构中，额外的混频器带来更多失配和噪声，限制镜像抑制和噪声系数；
- 可以把 c(t)、d(t) 数字化，在数字域完成后面的操作来解决；
- 用（例如）分频器可以产生准确的正交正弦信号。

### RF 输入为纯虚数时

- **期望信号和镜像都消失了！** 这种架构对 RF 输入的相位敏感。
- **修改**：在后半部分交换正弦和余弦解调器，并把两路相加而不是相减——这样纯虚数 RF 输入时期望信道出现；但问题是现在 RF 输入为实数时期望信道又被抵消。
- **总体架构：用 I/Q 解调**，让 RF 输入的实部和虚部都能通过。

### 实例：双变频镜像抑制混频器

Rudell 等，JSSC 1997（1.9 GHz 宽带中频双变频 CMOS 接收机）：6 个混频器实现 I/Q 镜像抑制；中频滤波是低通，易于单芯片集成；LO 频率不等于载频，LO 泄漏不是问题（见第 2 讲）。

## 16.2 混频器的噪声系数

### 单边带（SSB）噪声系数

- 问题：混频器或前端滤波器的宽带噪声会同时出现在**镜像带和期望带**，两者的噪声会在期望的 IF 输出中合并。
- 镜像抑制滤波器和信道滤波器都去不掉这部分噪声。
- SSB 噪声系数（正确地）计算了期望信号带和镜像带的噪声，而信号只在期望带。

### 双边带（DSB）噪声系数

- DSB NF 假设信号和噪声都在两个边带中（因此噪声系数**低 3 dB**）——对外差系统这有误导性，因为镜像带里没有信号。
- **对零中频**，没有镜像带，DSB 噪声系数是合适的：正负频率的噪声合并，但信号也合并。
- DSB 噪声系数比 SSB 低 3 dB，由于"听起来更好"常被引用。
- 对于有镜像的系统，要注意引用的是哪个。

## 16.3 方波本振

- 方波比正弦更容易产生。用作 LO 时如何影响混频？先复习傅里叶变换（级数）。

**两个重要的变换对**：时域冲激串的变换是冲激串；时域矩形脉冲的变换是 sinc 函数。

**把方波分解**：占空比为 W/T 的方波 = 矩形脉冲与冲激串的卷积，所以它的频谱是 sinc 包络下的冲激串：

- 谐波次数越高幅度越小；
- 占空比 50%（W = T/2）时只有奇次谐波；
- 若方波在 ±1/2（而不是 1 和 0）之间，则没有直流分量。基波幅度为 $2/\pi$。

**用方波作 LO 的分析**：LO 的每个频率分量都会与 RF 输入混频。如果 RF 输入频谱相对 $f_o$ 足够窄，由基波混出的期望输出可以用 IF 输出处的滤波器取出。

## 16.4 电压变频增益

- 定义为期望 IF 值与 RF 输入的电压比。
- **例**：理想混频器，RF 输入 $A\sin(2\pi(f_o + \Delta f)t)$，正弦 LO 为 $B\cos(2\pi f_ot)$，则 IF 分量幅度为 $AB/2$，变频增益为 $B/2$。
- 实际混频器的值取决于拓扑和 LO 信号（正弦还是方波）。

**高电压变频增益的影响**：

- 后级的噪声影响更小；
- 但可能伴随比其他做法更高的噪声系数；
- 也可能伴随限制干扰抑制的非线性（无源混频器一般比有源的更容易做线性）。

## 16.5 混频器的非线性

- 忽略动态效应，可以把混频器建模为理想混频器周围的若干非线性：
    - **非线性 A（RF 输入路径）**：影响与 LNA 相同；
    - **非线性 B（LO 路径）**：改变 LO 信号的频谱（方波就是一个极端情况）；
    - **非线性 C（IF 输出）**：引起 IF 输出的自混频。
- **主要关注 RF 输入路径的非线性**：B 在大多数情况下无害（LO 本来就常是方波）；C 可以通过使用线性负载（例如电阻）避免；A 会妨碍干扰抑制——和 LNA 一样用 IIP3 表征，用双音测试测量。

## 16.6 混频器的平衡

- **平衡信号**定义为直流分量为零的信号。
- 混频器中有两个相关信号：**不平衡的 RF 输入造成 LO 馈通；不平衡的 LO 信号造成 RF 馈通**。
- 问题：晶体管需要直流偏置（例如 $V_T$）。

### 带直流偏置时实现平衡的 LO

把 LO 相差 180° 的两条混频路径组合起来（一路减去另一路）。

### 单平衡混频器

- 先把 RF 输入电压转成电流，再在差分对两侧之间切换这个电流。
- 用上面的技巧实现 LO 平衡；两路相减由差分输出天然完成。
- LO 摆幅不要比完全切换开关管所需的更大；**方波最好**，可以使 M1、M2 的噪声最小。
- 跨导级要设计得高度线性。

### 跨导级的三种实现

| 实现 | 说明 |
|---|---|
| **1. 共源** | RF 信号加在共源放大器输入（晶体管在饱和区）；跨导与器件相同；高 $V_{bias}$ 让器件进入速度饱和，可以获得高线性度 |
| **2. 共栅** | RF 信号加在共栅放大器上；跨导由 $R_s$ 与 $1/g_m$ 串联的倒数决定，等效于退化，线性更高；$I_{bias}$ 可以设成大电流密度（速度饱和）以获得更高线性度 |
| **3. 带退化的共源** | 加源极退化；（若用电感退化）高频时阻抗增大，有助于滤掉高频干扰；一般不让电感与 $C_{gs}$ 谐振；IC 实现中一般不需要功率匹配 |

### 单平衡混频器的 LO 馈通

RF 输入的直流分量（偏置电流）造成很大的 LO 馈通；可以滤掉，也可以让 RF 输入直流为零来消除。

### 双平衡混频器

- LO 和 RF 信号的直流都为零（都平衡），**LO 馈通大大减小**！
- 但实际跨导需要偏置电流——用同样的技巧实现平衡的 RF 信号：两个跨导级反相，输出交叉耦合完成相减。

### Gilbert 混频器

- 用差分对实现跨导级；
- LO 可以是正弦或方波（**方波更好**）；
- 这是**大多数无线电应用首选的混频器实现**。

## 16.7 其他混频器

| 类型 | 说明 |
|---|---|
| **高线性 CMOS 模拟乘法器**（Song，JSSC 1986） | 晶体管工作在三极管区，乘积项相互抵消，实现线性乘法 |
| **高线性 CMOS 混频器**（Crols & Steyaert，JSSC 1995） | 晶体管被 LO 在截止和三极管区之间交替切换；在三极管区时 RF 信号改变沟道电阻；RF 输入需要大的偏置以进入三极管区；**线性度很高，但噪声系数很差** |
| **无源混频器** | 不用跨导级和/或运放，直接用开关实现混频；不需要偏置电流，可以低功耗工作；缺点：RF 输入是低阻抗 |
| **平方律混频器** | 利用 MOS 器件的非线性实现混频，理想平方律产生乘积项；不需要的分量必须滤掉；需要长沟道器件才有平方律行为；**LO 和 RF 端口之间没有隔离** |
| **平方律混频器的另一种实现** | 把 LO 和 RF 加在晶体管的不同端（例如栅和源），LO 与 RF 有一定隔离；但性能比基于乘法的混频器差：不需要的频谱分量多，LO 与 RF 隔离仍较差 |

## 16.8 Gilbert 混频器中的闪烁噪声

- 考虑用于直接变频接收机的 Gilbert 型混频器：
    - 跨导管（M1、M2）的 1/f 噪声被**上变频**到 LO 频率附近，影响不大；
    - 开关管（M3–M6）的 1/f 噪声：如果 LO 是理想方波则没有影响；
    - 但实际 LO 不是方波，在切换时刻斜率有限：M3–M6 的 1/f 噪声会调制切换时刻，从而出现在输出端。
- **分析**（Darabi & Chiu，"A Noise Cancellation Technique in Active RF-CMOS Mixers"，ISSCC 2005）：输出的 1/f 噪声**正比于偏置电流 I，反比于 LO 斜率 S**。
- **降低闪烁噪声**：在切换时刻注入电流，减小切换期间开关管中的电流。
- 讲义给出实际实现和 2 GHz 下的测量结果汇总。
