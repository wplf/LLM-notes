# 第 17 讲 VCO 中的噪声

> [原讲义 PDF](https://ocw.mit.edu/courses/6-776-high-speed-communication-circuits-spring-2005/resources/lec17/) · 公式按标准形式补写

## 17.1 VCO 噪声的影响

| | 无线系统 | 高速数据链路 |
|---|---|---|
| 接收机 | 灵敏度降低、阻塞性能变差 | 误码率（BER）升高 |
| 发射机 | 杂散发射增加（输出频谱必须满足模板） | 数据流抖动增加（发射机抖动必须低于规定值） |
| 表征方式 | **频域**（相位噪声） | **时域**（抖动） |

**影响 VCO 的噪声源**：VCO 自身器件的固有噪声；来自其他电路（包括 PLL）的噪声。

## 17.2 噪声分析的 VCO 模型

- 关注**相位噪声**（及相关的抖动），建模为输出正弦中的相位信号：$out(t) = 2\cos(2\pi f_ot + \Phi_{out}(t))$。
- 用三角恒等式，并利用相位噪声很小：

$$out(t) \approx 2\cos(2\pi f_ot) - 2\Phi_{out}(t)\sin(2\pi f_ot)$$

- 取傅里叶变换得到频谱（* 表示卷积）：相位频谱被搬到载波两侧。
- 相位谱密度一般分两类：**相位噪声**——$\Phi_{out}(t)$ 非周期；**杂散噪声**——$\Phi_{out}(t)$ 周期性。

### 相位噪声

- 假设 VCO 的输入噪声 $v_n(t)$ 是带限的非周期噪声，谱为 $S_{vn}(f)$，则相位谱 $S_{\Phi out}(f) = (K_v/f)^2S_{vn}(f)$。
- **用 dBc/Hz 测量相位噪声**：

$$L(\Delta f) = 10\log\left(\frac{S_{out}(f_o + \Delta f)}{P_{carrier}}\right) \approx 10\log S_{\Phi out}(\Delta f)$$

只有当 $\Phi_{out}(t)$ 偏离很小（即载波未被调制，如这里的假设）时才成立。

- **单边谱**：L(f) 的定义不变；因为 L(f) 是噪声与载波功率之比，用单边或双边谱都可以。

### 杂散噪声

- 用 dBc 测量：杂散音的功率与载波功率之比。假设双边谱，要在正负频率上积分得到功率；实践中单边或双边都可以用。

## 17.3 振荡器的固有相位噪声

噪声源分两类：谐振腔损耗带来的噪声；有源负阻带来的噪声。目标是确定它们如何影响输出相位。

### 等效模型

补偿后的谐振器（有源负阻抵消 $R_p$），加上来自谐振腔的噪声。

### 理想 LC 谐振腔在谐振附近的阻抗

$$Z(\omega_o + \Delta\omega) \approx -j\frac{\omega_oL}{2\Delta\omega/\omega_o}$$

用谐振腔 Q 参数化（$Q = R_p/(\omega_oL)$）：

$$|Z(\Delta f)| = R_p\frac{f_o}{2Q\Delta f}$$

### 总输出噪声谱密度

- 设有源负阻的噪声为谐振腔噪声的 $(F - 1)$ 倍，总噪声电流谱为 $F\cdot 4kT/R_p$；
- 输出噪声谱密度（单边）：

$$S_{vout}(\Delta f) = F\frac{4kT}{R_p}\cdot R_p^2\left(\frac{f_o}{2Q\Delta f}\right)^2$$

这代表同时影响振荡器输出**幅度和相位**的总噪声。

### 分离幅度噪声和相位噪声

- **均分定理**（Lee 教材第 1 版 534 页）：对正弦 $V_{sig}$，噪声的影响在幅度和相位之间**平均分配**；
- 幅度变化被振荡器中的反馈抑制，所以只剩一半作为相位噪声。

### 输出相位噪声谱（Leeson 公式）

所有功率计算都以谐振腔损耗为参考，$P_{sig} = V_{sig,rms}^2/R_p$：

$$L(\Delta f) = 10\log\left[\frac{2FkT}{P_{sig}}\left(\frac{f_o}{2Q\Delta f}\right)^2\right]$$

**例**：有源噪声与谐振腔噪声相同时，振荡器的噪声因子 F = 2。

## 17.4 实际情况复杂得多

- 谐振腔产生的噪声的影响容易估计；**晶体管产生的噪声复杂**：
    - M1、M2 的噪声被周期性地开关调制；
    - M3（尾电流源）的噪声被调制后才影响 $V_{out}$；
    - 晶体管还可能降低谐振腔的 Q。

### 实际振荡器的相位噪声

- 在很宽的频率范围内以 **−20 dB/十倍频**下降，但：
    - 低频：斜率增大（常为 **−30 dB/十倍频**）；
    - 高频：斜率变平（谐振腔不能滤除外部器件的噪声）。
- 拐点频率和幅度缩放用前面的分析方法不容易预测。

**Leeson 的经验修正**：

$$L(\Delta f) = 10\log\left[\frac{2FkT}{P_{sig}}\left(1 + \left(\frac{f_o}{2Q\Delta f}\right)^2\right)\left(1 + \frac{\Delta f_{1/f^3}}{|\Delta f|}\right)\right]$$

注意：他假设 F(Δf) 与频率无关。

## 17.5 更精细的分析方法：线性时变（LTV）模型（Hajimiri）

- 关心的是噪声电流注入谐振腔后引起的电压偏离：它同时引起幅度和相位偏离；幅度噪声被反馈（或后续缓冲级的限幅）抑制。
- 前面论证过，对正弦输出噪声影响平均分到幅度和相位。**非正弦输出时怎么办？**

### 相位与幅度扰动的建模

- 用冲激响应刻画电流噪声对幅度和相位的影响；幅度偏离会被抑制。
- **噪声电流的影响是时变的**：改变电流冲激注入的时刻，它对相位和幅度的影响就变了：
    - 冲激发生在输出**过零点附近**时，对相位影响大；
    - 冲激发生在输出**峰值**时，对相位影响小。

### 冲激灵敏度函数（ISF）Γ

- 把相位偏离作为冲激注入时刻的函数算出来，就构成 ISF；它是周期性的，周期与 VCO 输出相同。
- 用 ISF 表示相位冲激响应：

$$h_\phi(t,\tau) = \frac{\Gamma(\omega_o\tau)}{q_{max}}u(t - \tau)$$

其中 $q_{max}$ 是谐振腔上的最大电荷摆幅。

- **不同输出波形的 ISF**：Γ 大约正比于输出波形的**导数**；它的幅度表明 VCO 波形在哪里对注入谐振腔的噪声电流在相位方面最敏感。实际中从 VCO 仿真中得到。

### 用 LTV 框架分析相位噪声

- 对任意噪声电流计算相位偏离：$\Phi(t) = \dfrac{1}{q_{max}}\displaystyle\int_{-\infty}^{t}\Gamma(\omega_o\tau)i(\tau)d\tau$。
- 把 ISF 写成傅里叶级数（讲义的 $c_0$ 记法与教材不同）：

$$\Gamma(\omega_o\tau) = \frac{c_0}{2} + \sum_{n=1}^{\infty}c_n\cos(n\omega_o\tau + \theta_n)$$

- **框图理解**：电流源的噪声从不同的频带（直流、$f_o$、$2f_o$、…）被混频下来，按 ISF 系数加权。

### 白噪声输入的相位噪声

$$L(\Delta f) = 10\log\left[\frac{\overline{i_n^2}/\Delta f\cdot\sum_{n=0}^\infty c_n^2}{8\pi^2\Delta f^2q_{max}^2}\right] = 10\log\left[\frac{\overline{i_n^2}/\Delta f\cdot\Gamma_{rms}^2}{4q_{max}^2\Delta\omega^2}\right]$$

### 1/f 噪声的影响

- 设输入电流有拐角频率为 $\omega_{1/f}$ 的 1/f 噪声，它主要通过 $c_0$ 被上变频到载波附近，形成 $1/f^3$ 区。
- **$1/f^3$ 拐角频率**：

$$\Delta\omega_{1/f^3} = \omega_{1/f}\cdot\frac{c_0^2}{2\Gamma_{rms}^2}$$

### 振荡器波形对 $1/f^3$ 相位噪声的影响

- 决定 $1/f^3$ 噪声的关键傅里叶系数是 $c_0$：如果 ISF 的直流值为零，$c_0$ 也为零。
- **对称的输出波形**：ISF 直流值为零——**闪烁噪声不被上变频**（输出相位噪声没有 $1/f^3$ 区）！
- **不对称的输出波形**：ISF 直流值不为零——闪烁噪声被上变频，出现 $1/f^3$ 区。

### 计入噪声电流的调制

- 前面忽略了一点：晶体管产生的噪声会随其偏置条件变化而被调制——晶体管在饱和、三极管、截止之间切换时，噪声变化很大。
- 在 LTV 框架里，用**有效 ISF** $\Gamma_{eff}(x) = \Gamma(x)\alpha(x)$ 来包含这一点，α 是噪声调制函数。
- **最佳相位噪声的电流调制位置**：忽略 1/f 噪声时，最小化傅里叶系数平方和（即 $\Gamma_{eff}$ 的均方根值）可以得到最小相位噪声。
- **Colpitts 振荡器提供了最佳的位置**：电流在 VCO 波形的底部（ISF 最小处）注入谐振腔，伴随的噪声电流影响最小。

### LTV 相位噪声分析步骤小结

1. 用仿真计算每个振荡器噪声源的 ISF；
2. 用仿真计算每个噪声源的噪声电流调制波形；
3. 组合得到每个噪声源的 $\Gamma_{eff}(2\pi f_ot)$；
4. 计算每个 $\Gamma_{eff}$ 的傅里叶级数系数；
5. 计算每个振荡器噪声源的谱密度；
6. 代入相位噪声表达式求和。

## 17.6 负阻振荡器的另一种方法（Rael & Abidi）

- 回到 Leeson 公式：关键问题是**怎样确定 F(Δf)**。
- Rael 等给出了下面这种拓扑（NMOS 交叉耦合对 + 尾电流源）的闭式 F(Δf) 表达式，在相位噪声以 −20 dB/十倍频下降的区域：

$$F = 1 + \frac{4\gamma I_{bias}R_p}{\pi A} + \gamma\frac{4}{9}g_{m,tail}R_p\ \text{（三项分别记为 A、B、C）}$$

（A 为振荡幅度；三项依次对应谐振腔电阻、开关对、尾电流源，$g_{m,tail}$ 为尾电流管跨导。讲义公式抽取不出，这里按 Rael 论文的形式补写。）

参考：Rael & Abidi，"Physical Processes of Phase Noise in Differential LC Oscillators"，CICC 2000；Hegazi 等，"A Filtering Technique to Lower LC Oscillator Phase Noise"，JSSC 2001。

### 为最小相位噪声而设计

- 上面的公式提供了如何做的洞察；关键观察：**分量 (C)（尾电流源噪声）往往相当显著**。
- **消除分量 (C)**：在 $V_s$ 节点用电感提高 $2f_o$ 处的阻抗（Hegazi 的滤波技术），尾电流源的噪声就不再进入。
- **最小化分量 (B)**：它取决于偏置电流和振荡幅度。看起来 $I_{bias}$ 没有影响——并非如此：要最大化 A（即 $P_{sig}$）以获得最佳相位噪声。

### 电流受限与电压受限区

- **电流受限区**：幅度由 $I_{bias}R_p$ 决定；
- **电压受限区**：幅度饱和（受电源限制）；
- **最佳相位噪声出现在两个区域的边界处！**

## 17.7 结语

- **Hajimiri 方法**适合作为数值过程，提供了对 1/f 噪声上变频和噪声电流调制位置的洞察；
- **Rael 方法**适用于 CMOS 负阻振荡器：给出相位噪声的闭式解，提供大量设计洞察；
- Cadence 的 Spectre RF 现在对许多振荡器的相位噪声估计相当不错，可以用来验证设计想法和计算。
