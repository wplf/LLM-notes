# 第 14 讲 压控振荡器（VCO）

> [原讲义 PDF](https://ocw.mit.edu/courses/6-776-high-speed-communication-circuits-spring-2005/resources/lec14/) · 公式按标准形式补写

## 14.1 VCO 的设计指标

**窄带无线系统**：

| 指标 | 说明 |
|---|---|
| 调谐范围 | 要覆盖所有频率信道 |
| 噪声 | 影响接收机灵敏度 |
| 功耗 | 越低越好 |
| 隔离 | 尽量减少进入 VCO 的噪声通路 |
| 对工艺/温度变化的敏感性 | 要可制造 |

**宽带高速数据链路**：对噪声的要求通常没那么严格，但需要宽调谐范围、多相输出等。

## 14.2 常见的 VCO 结构

- **LC 振荡器**：相位噪声低，面积大；
- **环形振荡器**：容易集成，相位噪声较高。

## 14.3 巴克豪森振荡判据

在振荡频率 $\omega_o$ 处：环路增益幅度为 1，相位为 n·360°（n = 0, 1, 2, …）。

### 例 1：环形振荡器

- 增益由反相器的**饱和特性**设为 1；
- 用**奇数级**以避免稳定的直流工作点；
- 振荡频率处相位为 360°：反相提供 180°，各级延迟再提供 180°。设 N 级、每级相移 Δφ，则 $N\Delta\phi = 180°$；或者设每级延迟 Δt，则 $f_{osc} = 1/(2N\Delta t)$。

**更多信息**：由于相位噪声较差，环形振荡器在 RF 系统中很少用，但在高速数据链路中很常用。本讲关注 LC 振荡器。环形振荡器参考：Maneatis 等，"Precise Delay Generation Using Coupled Oscillators"，JSSC 1993；以及 Weigandt 的博士论文。

### 例 2：基于谐振器的振荡器

- 在振荡频率 $\omega_o$ 处满足巴克豪森判据：假设 $G_m$ 是纯实数，$Z(j\omega_o)$ 也必须是纯实数。
- 并联谐振器在谐振时看起来就是一个电阻（纯实数）；幅度条件通过令 $G_mR_p = 1$ 满足。

## 14.4 $G_m$ 取值的影响

- 用**根轨迹**看闭环极点位置随开环零极点和增益的变化：增益 $G_mR_p$ 增大时，闭环极点向右半平面移动。
- **$G_m$ 太小**：闭环极点在左半平面，振荡衰减。
- **$G_m$ 太大**：闭环极点在右半平面，振荡增长。
- **恰好**：闭环极点在 jω 轴上。问题是 $G_mR_p$ 必须**正好等于 1**——实际怎么做到？

### 幅度反馈环

一种想法是检测振荡幅度并调节 $G_m$，使其等于期望值；通过反馈可以精确达到 $G_mR_p = 1$。但复杂、耗电、加噪声。

### 利用放大器非线性作为反馈

- 实际跨导放大器有**饱和特性**；产生的谐波被谐振器滤掉。
- 关心的是输入与输出基波之间的关系：幅度增大时，从输入到输出基波的**等效增益下降**。
- 于是**自然形成幅度反馈**：稳态时 $G_mR_p = 1$。

## 14.5 单端口视角

- 用一个**有源负阻**抵消谐振腔的损耗；持续振荡要求 $-1/G_m = -R_p$。
- 单端口建模需要一个**并联 RLC** 网络：由于 VCO 只在很窄的频带内工作，总可以通过串并联变换得到并联网络。
- 警告：实际 RLC 网络可能有第二个（甚至更多）谐振频率，引起寄生振荡；等效并联网络在手算中会掩盖这个问题，**仿真会暴露它**。

## 14.6 负阻振荡器

- 这种结构非常流行：差分实现（适合驱动差分电路），可以做到良好的相位噪声。

**分析**

1. 推出包含谐振腔损耗的并联 RLC 网络（损耗一般由电感的串联电阻主导）。
2. 把振荡器拆成半电路分析：利用源极 $V_s$ 可以近似为增量地（不完全如此，但足够接近）。识别出一个带有交叉耦合的"二极管连接"器件，它呈现负阻 $-2/G_m$（$G_m$ 是**大信号**跨导）。

**设计**

- 把谐振腔元件设计成高 Q，使 $R_p$ 尽可能大；
- 选择偏置电流 $I_{bias}$ 以获得大摆幅（但不要让晶体管进入深三极管区）；
- 选择晶体管尺寸以获得足够大的 $g_{m1}$：通常取 $1/R_{p1}$ 的**两倍**以保证起振。

**摆幅估算**

- 正弦振荡的最大值：幅度大时，$I_{bias}$ 在正弦的峰和谷处被完全导向一侧；
- 方波极限：幅度很大时可以假设流入谐振腔的电流 $I_1(t)$ 是幅度为 $\pm I_{bias}/2$（相对平均值）的方波，取其基波（直流和谐波被谐振腔滤掉），基波幅度为 $(4/\pi)(I_{bias}/2)$，所以单侧摆幅约为：

$$V_{amp} \approx \frac{2}{\pi}I_{bias}R_p\quad(\text{差分幅度为其两倍，笔者按标准推导补写})$$

**变体**

- 偏置可以从顶部或底部提供；
- 跨导可以用 NMOS、PMOS 或两者：同时用 NMOS 和 PMOS 交叉耦合对，看起来在给定功耗下相位噪声更好（Hajimiri 等，"Design Issues in CMOS Differential LC Oscillators"）。

## 14.7 Colpitts、Clapp 与 Hartley 振荡器

### Colpitts 振荡器

- 源自分立设计（那时单端更简单）：**只用一个晶体管**实现负阻；也可以做差分结构。
- 可以达到良好的相位噪声，但在 CMOS 应用中看不出比负阻振荡器有明显优势。

**电容变压器分析**

- 电容分压降低了 $R_L$ 上的电压；假设在谐振频率处电容的阻抗小于 $R_L$（简化分析）。
- $V_1$ 与 $V_{out}$ 之比由电容决定，与 $R_L$ 无关：$N = C_1/(C_1 + C_2)$。
- 由功率守恒得到变压器关系。

**简化模型**：减小了源极节点的摆幅（对双极版本重要）；变压器比按最佳噪声性能设定。

**设计**

- 选偏置电流获得大摆幅（不要深入三极管区）；
- 选变压器比获得最佳噪声：按 Lee 的经验法则取 **N = 1/5**；
- 选晶体管尺寸获得足够大的 $g_{m1}$。

**摆幅与 $I_{bias}$ 的关系**：$I_1(t)$ 由一串脉冲组成，形状和宽度取决于晶体管行为和变压器比；近似为宽度为 W 的窄方波脉冲，其基波约为 $2I_{bias}$，于是 $V_{amp} \approx 2I_{bias}R_p$（窄脉冲极限）。

### Clapp 振荡器

- 与 Colpitts 相同，只是把谐振腔的电感部分与器件漏极隔离开；
- 允许电感上的电压摆幅更大，而不超过漏极的最大允许电压；**有利于降低相位噪声**；
- 小心寄生谐振！

### Hartley 振荡器

- 与 Colpitts 相同，但用**抽头电感**而不是串联电容实现变压器；
- 在 IC 中不流行，因为电容比电感容易做；同样要小心寄生谐振。

## 14.8 集成谐振器结构

| 结构 | 说明 |
|---|---|
| 螺旋电感 + 横向电容 | 螺旋电感 Q 中等（5–10），但完全集成、容差紧（< ±10%） |
| 键合线电感 | Q 高（> 40），但没那么"集成"，容差差（> ±20%） |
| 变压器式谐振器 | 利用自感和互感实现谐振（Straayer 等，"A low-noise transformer-based 1.7 GHz CMOS VCO"） |
| 四分之一波长谐振器 | 阻抗计算见第 4、5 讲；用讲究的材料可以做到很高的 Q；缺点是面积较大（过去在片外实现），但频率越高越小 |

**其他谐振器**

- **晶体**：Q 非常高，谐振频率非常准确稳定；限于低频（< 200 MHz）；用来做低噪声、准确的"参考"振荡器。
- **SAW 器件**：频率范围宽、便宜（见第 9 讲）。
- **MEMS**：悬臂梁有望实现高 Q，但不可调，还没进入 GHz 范围。
- **FBAR**：Q > 1000，但不可调、精度差。
