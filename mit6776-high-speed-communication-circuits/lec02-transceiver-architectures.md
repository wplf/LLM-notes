# 第 2 讲 收发机架构

> 2005-02-03 · [原讲义 PDF](https://ocw.mit.edu/courses/6-776-high-speed-communication-circuits-spring-2005/resources/lec2/)

提纲：调幅收发机（发射机：开关调制器、Gilbert 乘法器、平衡调制器、QAM、SSB；接收机：包络检波、放大、反射、多级 RF、超再生、外差、超外差、镜像抑制、零差、直接变频、双变频、低中频）→ 恒包络调制的收发机（窄带相位调制、间接/直接 FM、PLL 调频、ΣΔ 小数分频调频；鉴频器、FM-AM 转换、延迟线、PLL 解调）。

## 2.1 调幅发射机

### 调幅回顾

$x'(t) = 1 + m\,x(t)$ 调制载波；直流分量大于信号幅度时可以用简单的包络检波器，但会产生一个浪费功率的载频单音（见第 1 讲）。

### 开关调制器

- 用开关（乘以方波）实现调制，再用低通或带通滤波取出所需分量。
- 例：差分对的尾电流被基带信号调制，差分对被载波完全切换。

### Gilbert 乘法器

- 由于电流（$b$）必须为正，得到的输出是标准 AM。
- 优点：谐波少，输出滤波器不必很有选择性；缺点：直流功耗较大。

### 平衡调制器（DSB 发射机）

两个 Gilbert 乘法器组合：**去掉载波分量**；同时改善调制线性度（二次谐波失真相互抵消）。

### QAM 发射机

两个平衡调制器分别乘以同相和 −90° 移相后的载波，相加后经 RF 滤波器和功放输出。

### SSB 发射机

- **移相法 SSB 调制器**：基带信号和载波都分成 0°/−90° 两路，分别经平衡调制器后相加（或相减），一个边带相互抵消。边带抑制取决于**相位和幅度的匹配**。
- **外差 SSB 调制器**：先在中频（IF）做平衡调制并用 SSB 滤波器去掉一个边带，再上变频到 RF。需要两个振荡器（$f_{IF}$ 和 $f_c - f_{IF}$）。

### 外差发射机的道理

- 边带滤波需要很高的选择性，在较低的中频滤比在射频滤容易得多。例如中频的声表面波（SAW）滤波器选择性很高、插损低、噪声系数低，而且相对便宜。
- 同样的道理适用于接收机——这也是"超外差"接收机几十年来一直占主导的原因。

## 2.2 调幅接收机的演进

| 架构 | 结构 | 特点 |
|---|---|---|
| **包络检波器（矿石收音机）** | 可调 LC 的 RF 滤波器 → 包络检波 → 高效率晶体（压电）耳机 | 只适用于标准 AM（直流偏移的基带）；无有源器件，非常简单便宜；灵敏度低，只能收强台；选择性差（只有一个 RF 滤波器）；基带输出功率低 |
| **放大式接收机** | RF 滤波 → RF 放大 → 包络检波 → 音频（AF）放大 | RF 放大提高灵敏度，AF 放大可驱动扬声器；RF 选择性仍是问题；有源器件很贵时成本高（要两个有源器件） |
| **反射式接收机** | 一个有源器件同时放大 RF 和 AF 信号 | 性能同放大式，但只用一个有源器件 |
| **多级 RF 放大** | 多个调谐 RF 放大器级联 | 灵敏度高；由于放大倍数高，**必须有高选择性**（高 Q 调谐电路）；每级都要单独调谐，靠反复试凑，非常繁琐 |
| **超再生接收机** | 正反馈放大器 + 熄灭（quench）电路 | 熄灭电路要么是振荡器（定期熄灭），要么是幅度检测器（到达预定幅度时熄灭）；单级就能得到很大的有效 RF 增益（便宜）；无信号时会放大热噪声，产生特有的嘶嘶声 |
| **外差接收机** | RF 放大 → 变频器把 RF 混到较低的中频 → 中频滤波 → 中频放大 → 包络检波 | 在较低的中频滤波，选择性更好；中频放大进一步提高灵敏度 |
| **超外差接收机** | 本振频率**高于**载波（所以叫"超"外差）；本振频率通过"联动"的可变电容跟着 RF 滤波器的频率走 | 电路实例：天线线圈、自动音量控制（AVC）、混频/本振、中频、包络检波、音频放大，共 5 个晶体管 |

## 2.3 镜像问题

- **关键点**：与本振频率等距的**镜像信号**会变频到同一个中频频带。
- **RF 滤波器必须去掉镜像**（镜像抑制滤波器）。
- 为了容易抑制镜像，希望中频**高**（期望信号与镜像相距 $2f_{IF}$）；但为了中频滤波容易，又希望中频**低**（分数带宽更小）。
- 折中：中频一般选在 RF 频段的一半左右（例如 AM 广播 500–1700 kHz，FM 广播 88–108 MHz）。
- 另一种做法是用**镜像抑制混频器**。

### 镜像抑制混频器

- 用与 SSB 产生类似的方法抑制镜像：RF 信号分两路分别与 0° 和 −90° 的本振混频，其中一路再移相 90° 后相加。
- 镜像抑制受 RF 和 LO 路径的**幅度和相位匹配**限制，典型约 **40 dB**。
- 必要时 RF 滤波器还能进一步减小镜像；否则可以省掉 RF 镜像抑制滤波器。
- 讲义用两页频域图说明期望信号和镜像在两路中的符号关系。

## 2.4 零中频类接收机

### 零差（相干）接收机

- 把 RF 信号与载频混频，**直接变到基带**，没有镜像需要抑制。
- 如果发射信号中有**导频载波**，就不需要本振——直接从发射信号中提取载波（DSB 或 SSB 需要插入载波，因此与标准 DSB/SSB 传输不兼容）。否则需要一个载频上的本振（见后面的直接变频接收机）。
- 载波提取器可以是窄带滤波器、PLL，或被载波同步的振荡器。
- 是直接变频接收机的一种，优缺点相同。

### 直接变频（零中频）接收机

- 结构：固定频率 RF 滤波器 → LNA → 正交混频器（由频率合成器提供 I/Q 本振）→ 基带滤波 → 基带放大 → ADC → DSP。
- 是零差接收机的一种；用相干检测，需要精确本振（用频率合成器）。
- **没有中频滤波，可以做成单芯片**；信道（电台）选择在基带完成。
- 由于 RF 滤波器选择性不高，基带滤波器要抑制干扰：基带电路需要**高得多的动态范围/SNR 和高选择性**；信道滤波通常由 DSP 完成。
- 没有镜像。
- **本振泄漏造成的时变直流失调**是一个重要问题：直流失调可能比信号还大，会使基带电路饱和。

### 双变频接收机

（Rudell 等，"A 1.9-GHz Wide-Band IF Double Conversion CMOS Receiver for Cordless Telephone Applications"，JSSC 1997）

- 用 **6 个混频器**实现 I/Q 镜像抑制；
- 中频滤波是低通，单芯片集成更容易；
- 本振频率不等于载频，**本振泄漏不成问题**。
- 镜像抑制原理类似 Weaver SSB 产生器（作业 1），靠相位关系而不是无源元件；但受 6 个混频器幅度和相位匹配的限制。

### 低中频接收机

- 原理相同，但镜像在**数字域**中抑制，所以中频可以非常低。
- 中频滤波器、ADC 和 DSP 都工作在低中频上，容易单芯片集成。
- 镜像抑制仍受正交混频器幅度和相位匹配的限制。

## 2.5 恒包络调制的收发机

### 发射机

| 方式 | 说明 |
|---|---|
| 窄带相位调制（NBPM） | 平衡调制器 + 90° 移相实现 |
| 间接调频 | NBPM 后接 n 倍频器，FM 带宽扩大 n 倍，得到窄带 FM |
| **直接调频（VCO）** | $f_o$ 是 VCO 的"自由振荡"频率；一般用**变容管**改变振荡频率。难以保持精确的输出频率（VCO 频率漂移），相位噪声高。讲义给出 Albert Jerng 的 NMOS 和 PMOS VCO 实例 |
| **基于 PLL 的调频** | 环路带宽必须低于信号的最低频率；中心频率由晶振参考精确保持 |
| **基于小数分频合成器的数字调频** | 模 n/n+1 分频器的占空比被信号调制；输入信号先经 ΣΔ 调制，把量化噪声推到环路带宽以外 |

### FM 解调

| 方法 | 说明 |
|---|---|
| **鉴频器** | 限幅器 → 频率鉴别器（$|H(f)|$ 的斜坡把频率变成幅度）→ 包络检波 → 隔直。线性的 f-v 范围小，所以用**平衡（差分）鉴频器**：两个不同中心频率 $f_{o1}$、$f_{o2}$ 的响应相减 |
| **FM 到 AM 转换** | 限幅器 → 微分器（把 FM 变成 AM）→ 包络检波 → 隔直；寄生的 AM 必须由限幅器抑制 |
| **延迟线解调器** | 用传输线延迟 τ 实现微分器 |
| **PLL 解调** | 限幅器 → 鉴相器 → 环路滤波 → VCO；把 VCO 的输入电压当作输出。VCO 在反馈环内，输入输出特性是 VCO 函数的逆，因此实现了频率到电压的转换 |
