# 第 6 讲 MOS 管、无源器件与宽带放大器的增益带宽问题

> [原讲义 PDF](https://ocw.mit.edu/courses/6-776-high-speed-communication-circuits-spring-2005/resources/lec6/) · 公式按标准形式补写

## 6.1 MOS 管的大信号与小信号行为

- 大信号：定性和定量（平方律）行为回顾。
- 放大器分析一般关注**小信号**行为，用混合 π 之类的线性化模型。

### 直流小信号模型

$$g_m = \sqrt{2\mu_nC_{ox}(W/L)I_D}\quad(\lambda V_{DS} \ll 1),\qquad g_{mb} = \chi g_m,\qquad r_o \approx \frac{1}{\lambda I_D}$$

### 饱和区的电容

- 交叠电容：$C_{ov} = WL_DC_{ox} + WC_{fringe}$；
- 栅到沟道电容：$C_{gc} = \tfrac23C_{ox}W(L - 2L_D)$；
- 沟道到衬底电容：本课忽略；
- 于是 $C_{gs} = C_{gc} + C_{ov}$，$C_{gd} = C_{ov}$；$C_{sb}$、$C_{db}$ 为面积加周长的结电容。

## 6.2 布线寄生

| | 电容 | 电阻 | 电感 |
|---|---|---|---|
| 栅 | 多晶到衬底和金属层 | 多晶栅有电阻（用硅化物降低），长布线有电阻 | 多晶栅本身可忽略，长布线需要考虑 |
| 漏和源 | 金属布线到衬底和其他层 | 扩散区有电阻（用硅化物降低），长金属线有电阻 | 长导线时成为问题 |

这些寄生要从版图中**提取**。

## 6.3 CMOS 器件的频率性能

两个常用品质因数：

- $f_t$：**电流增益**为 1 的频率；
- $f_{max}$：**功率增益**为 1 的频率。

增益带宽积是守恒的；MOS 器件的 $f_t$ 是偏置的函数，这对高频放大器设计影响很大。

### $f_t$ 的推导

- 假设输入是电流，器件输出短接到电源电压（栅极需要一个电压偏置），算出的 $f_t$ 是这个偏置的函数：

$$f_t = \frac{g_m}{2\pi(C_{gs} + C_{gd})}$$

**为什么 $f_t$ 依赖偏置**：

- $f_t$ 是 $g_m$ 与栅电容之比；$g_m$ 随栅偏置变化，而（强反型下）栅电容基本不变。
- 一阶关系：$g_m = \mu C_{ox}(W/L)(V_{GS} - V_T)$，所以栅偏置越高 $f_t$ 越高：

$$f_t \approx \frac{3}{2}\cdot\frac{\mu(V_{GS} - V_T)}{2\pi L^2}\quad(\text{长沟道})$$

- 也可以说 $f_t$ 是电流密度的函数，**在最大电流密度（和最小 L）处最大**。

### 单位功率增益频率 $f_{max}$

$$f_{max} \approx \frac12\sqrt{\frac{f_t}{2\pi r_gC_{gd}}}\quad(\text{教材形式之一})$$

- $r_g$ 是栅的串联寄生电阻；
- 把栅电阻做小，$f_{max}$ 可以比 $f_t$ 高得多；
- 输出电容对 $f_{max}$ 没有影响（可以用电感调谐掉）。

### NMOS 与 PMOS 的速度

在典型体硅 CMOS 中 NMOS 迁移率远高于 PMOS：同样电容和栅偏置下，NMOS 提供约 **2.5 倍**的 $g_m$ 和约 2.5 倍的 $I_d$。

## 6.4 RF 电路中的集成无源器件

- 本课只考虑无源器件；一般希望高 Q、低寄生、线性好（偏置电路例外）。
- 阱电阻、扩散电阻、多晶-n+ 电容乃至多晶-多晶电容在 RF 下表现都不太好。

| 器件 | 特点 |
|---|---|
| **多晶硅电阻** | 用**非硅化**多晶做电阻；方块电阻通常 100–200 Ω/□；寄生电容通常很小；适合高速放大器；精度一般 ±15% |
| **MOS 电阻** | 把 MOS 管偏置在三极管区；小面积就能做到很大的阻值（几十平方微米做到 MΩ）；寄生电容大（栅电容）；适合小摆幅电路或直流（偏置）电路 |
| **高密度电容（偏置、去耦）** | MOS 器件单位面积电容最大；电压必须足够高使沟道反型；0.18 μm 下原始电容约 8–8.5 fF/μm²；Q（串联电阻）在最小 L 时最大（与面积效率取舍）；把 NMOS 电容放在 N 阱里可以在更低电压下工作；它的非线性常在 VCO 设计中被当作变容管利用 |
| **高 Q 电容（信号通路）** | 横向金属电容：多层金属叠在一起（最好用顶层）、用最大密度的过孔连接；Q 高、寄生对称，寄生一般小于电容值的 10% |
| **叠层横向通量电容** | 例：0.24 μm、7 层金属工艺，最小线宽和间距 0.24 μm、金属厚 0.53 μm，得到 1.5 fF/μm²（Aparicio JSSC 2002） |
| **分形电容** | 最大化周长，单位面积电容最多提高 10 倍（Shahani ISSCC 1997） |
| **螺旋电感** | 用顶层金属做成螺旋形（可加图形化的地屏蔽）；Q < 10，L 为 1–10 nH，关键还有自谐振频率；放在顶层以减小串联电阻；用 Mohan 等的公式（JSSC 1999）估算，用 ASITIC 验证 |
| **键合线电感** | 从封装键合到芯片；约 1 nH/mm，通常 1–5 nH；阻值难以控制（取决于芯片-封装几何）；Q 比螺旋电感高得多，典型 > 40 |
| **集成变压器** | 利用相邻导线之间的磁耦合；参数是初级和次级的自感 L 和耦合系数 k；用 ASITIC 等设计 |
| **T 线圈网络** | 带中心抽头的电感，两半之间有互感（Galal & Razavi，ISSCC 2003 的限幅放大器、激光/调制器驱动器和宽带 ESD 保护） |

## 6.5 宽带放大器的增益带宽问题

- 对输入信号通常做的第一件事就是**放大**，把信号提升到可用的水平。

### 增益带宽的取舍

- 单极点放大器：增益 $g_mR_L$，带宽 $1/(R_LC_{tot})$（$C_{tot}$ 是输出节点的总电容），增益带宽积 $GB = g_m/C_{tot}$——称为"**原点极点**"。
- 给定 $g_m/C_{tot}$，只能用增益换带宽；要改善 GB，必须提高 $g_m/C_{tot}$。

### 提高增益带宽积

- 假设放大器的负载是一个相同的放大器、固定的布线电容可以忽略：$GB \approx g_m/(C_{gs} + C_{db} + \ldots) \propto f_t$。
- 要在给定工艺中得到最大的 GB：用最小栅长，把晶体管偏置在最大电流密度。
- 进入速度饱和后，更高的 $V_{GS} - V_T$ 不再提高 $g_m$。
- 固定布线电容很大时，提高功率（器件尺寸）可以改善 GB，直到器件电容与布线电容相当。

### 观察

- 增益带宽积恒定只是**单极点滚降**的结果，**并不是根本限制**！
- 这意味着单极点频响可能不是获得增益和带宽的最好方式。
- 某些电路（例如为了稳定性）需要单极点滚降，但宽带放大器不需要——这为后面几讲的带宽扩展技术铺路。
