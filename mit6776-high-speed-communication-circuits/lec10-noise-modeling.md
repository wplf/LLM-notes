## 10.1 记号：均值、方差与相关

- 考虑随机变量 x、y，其概率密度为 $f_x(x)$、$f_y(y)$，以及联合概率密度。
- $\bar{x} = \int xf_x(x)dx$；**方差**（假设均值为零）$\overline{x^2} = \int x^2f_x(x)dx$；相关 $\overline{xy} = \iint xyf_{xy}(x,y)dxdy$。若相关为零，称 x 与 y **不相关**。
- 讲义的惯例：常把 $\overline{v_n^2}$ 这类量直接当作随机变量（噪声）而不是它的均值。

## 10.2 方差与谱密度

- **单边谱**定义在正频率上，其幅度是对应的双边谱的两倍。本课后面假设使用单边谱。
- **滤波对谱密度的影响**：随机信号通过传递函数为 $H(f)$ 的线性时不变系统后，$S_y(f) = |H(f)|^2S_x(f)$；若 x(t) 被放大了 A 倍，则谱密度放大 $A^2$ 倍。

## 10.3 无源器件的噪声

- **电阻**：可以用电压源 $\overline{v_n^2} = 4kTR\,\Delta f$ 或电流源 $\overline{i_n^2} = 4kT\Delta f/R$ 描述；一般假设室温 27 °C。
- **理想电容和电感没有噪声**；实际器件有寄生电阻，用串联/并联电阻参数化，并把寄生电阻的噪声源包含进来。

## 10.4 CMOS 晶体管的噪声（假设在饱和区）

| 噪声源 | 说明 |
|---|---|
| **漏极热噪声** | 沟道中被热搅动的载流子产生：$\overline{i_{nd}^2} = 4kT\gamma g_{do}\Delta f$，$\gamma$ 的典型值约 2/3（长沟道）；与器件尺寸和偏置有关 |
| **漏极 1/f 噪声** | 用 $K_f$ 和指数 n 参数化（一般 n ≈ 1），由工艺厂提供：$\overline{i_{nf}^2} = \dfrac{K_f}{f}\cdot\dfrac{g_m^2}{WLC_{ox}^2}\Delta f$。为最小化它需要**大面积（大 WL）** |
| **感应栅噪声** | 由沟道感应，与器件尺寸和偏置有关；与漏极噪声部分相关 |
| **栅极噪声（感应 + 布线寄生）** | 由到栅极的布线电阻（包括多晶栅的电阻）造成；用正确的版图（例如叉指）可以做得可以忽略 |

- 计算 $Z_{gs}$；

## 10.7 宽带与窄带放大器的噪声考虑

| | 宽带（> 1 GHz） | 窄带 |
|---|---|---|
| 主要问题 | 漏极热噪声（1/f 拐角一般低于 1 MHz；栅噪声只在很高频才有影响） | **栅噪声是重要问题**；在源极使用电抗元件会大大改变它 |
| 指标 | 通常给**输入等效电压噪声** | 通常给**噪声系数（NF）** |

### 源极带电感 $Z_s = R_s + sL_g$ 时栅噪声的影响

- 设 $L_g$ 与 $C_{gs}$ 在关心的中心频率 $\omega_o$ 处谐振（$\eta = 1$ 的假设下计算 $Z_{gsw}$）。
- 由前面的关键噪声表达式可知：**栅噪声的贡献是 Q 的函数**。

### 栅噪声在什么 Q 值下超过漏噪声

- 求交叉点：临界 Q 值主要**由工艺决定**。
- 计算输出端信号谱：先求 $v_{in}$ 与 $i_{out}$ 的关系，再算谐振频率处输出信号的谱密度。
- **Q 对 SNR 的影响**（假设谱恒定、忽略 $R_s$ 噪声）：
    - 栅噪声 < 漏噪声的小 Q 区：SNRout 随 Q 增大而**大幅改善**；
    - 栅噪声 > 漏噪声的大 Q 区：SNRout 随 Q 增大改善很小。

## 10.8 噪声因子与噪声系数

- 计算噪声因子（第一部分）：先算 SNRout，**必须计入 $R_s$ 噪声**（$R_s$ 噪声的计算方式与 $v_{in}$ 相同）。
- 第二部分：整理表达式。
- 第三部分：用 Q 和 $\omega_t$ 的表达式改写分母，得到噪声因子表达式：**主要取决于 Q、$\omega_o/\omega_t$ 和工艺参数**。

### 最小噪声因子

- 对 Q 求导并令导数为零，可解出使噪声因子最小的 Q。
- Lee 教材 272–277 页给出了 MOS 共源放大器（无退化）在谐振处的最小噪声因子。
- 讲义给出噪声因子缩放系数随 Q 的曲线（0.18 μm NMOS）。

### 达到最小噪声因子

- 对无源极退化的共源放大器：只有栅噪声与漏噪声**不相关（c = 0）**时，才能在谐振处达到最小噪声因子。
- 由于实际 c ≠ 0，通常必须工作在**略微偏离谐振**的频率上才能达到最小噪声因子。
