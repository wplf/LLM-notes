# 第 12 讲 低噪声放大器（LNA）

> [原讲义 PDF](https://ocw.mit.edu/courses/6-776-high-speed-communication-circuits-spring-2005/resources/lec12/) · 公式按标准形式补写

## 12.1 无线系统窄带 LNA 的设计指标

| 指标 | 影响 |
|---|---|
| 噪声系数 | 接收机灵敏度 |
| 线性度（IIP3） | 接收机的阻塞性能 |
| 增益 | 高增益降低 LNA 之后各级噪声的影响 |
| 功率匹配 | 希望 $Z_{in} = Z_o$（通常 50 Ω） |
| 功耗 | 希望功耗低 |
| 带宽 | 需要覆盖目标无线电应用的整个 RF 频段（所有相关信道） |
| 对工艺/温度变化的敏感性 | 需要可重复的设计 |

本讲的重点是**功耗对设计的影响**。

## 12.2 几种输入级的噪声因子

### 共源放大器直接输入端接

- 为了功率匹配，在 CS 放大器输入端并一个端接电阻；
- 端接电阻会**增加热噪声**；
- 更适合宽带而不是窄带。

**低频噪声因子**（忽略栅电流噪声，看短路输出电流）：

端接电阻 $R_s$ 与源内阻相同，它自己就贡献了和源一样多的噪声，所以 **$F \ge 2$（3 dB）**，再加上晶体管噪声更高（笔者按标准结论补写）——即使低频也过高，一般不能作为 LNA 使用。

### 共栅放大器

- 有可能**不需要显式的端接电阻**就实现功率匹配（输入阻抗约 $1/g_m$，令 $g_m = 1/R_s$）；
- 比共源好，但噪声系数会恶化：

匹配时（$g_m = 1/R_s$）低频噪声因子约为 $F \approx 1 + \gamma/\alpha$（标准结果，忽略栅噪声；长沟道 γ/α ≈ 2/3，约 2.2 dB）。

- 对宽带放大器可以接受；对窄带放大器，可以在保持功率匹配的同时大幅改善噪声系数。

### 电感退化的共源放大器

- 与第 10 讲的放大器相同，只是加了源极电感（注意 Lee 教材的噪声分析表 12.1 没有包含电感退化）。

**关键假设：按功率匹配设计**

- 调整参数使在频率 $\omega_o$ 处输入阻抗为纯电阻 $R_s$：

$$Z_{in} = j\omega L_s + \frac{1}{j\omega C_{gs}} + \frac{g_mL_s}{C_{gs}} = sL_g + \frac{1}{sC_{gs}} + g_m\frac{L_s}{C_{gs}}$$

- 加栅极电感 $L_g$ 多了一个自由度，可以同时设定 $\omega_o$ 和实部 $R_T$：

$$\omega_o = \frac{1}{\sqrt{(L_g + L_s)C_{gs}}},\qquad R_T = \frac{g_mL_s}{C_{gs}} = \omega_tL_s = R_s$$

- 于是：

$$L_s = \frac{R_s}{\omega_t},\qquad L_g = \frac{1}{\omega_o^2C_{gs}} - L_s,\qquad Q = \frac{1}{\omega_oR_sC_{gs}} = \frac{\omega_o(L_g + L_s)}{R_s}$$

**与不退化的对比**（第 10 讲 $L_{deg}$ = 0 时 $\omega_o^2 = 1/(L_gC_{gs})$）：

- 现在 $(g_m/C_{gs})L_{deg} = R_s$，$\omega_o^2 = 1/[(L_g + L_s)C_{gs}]$；
- 讲义给出两者的噪声因子缩放系数-Q 曲线对比，退化版本的噪声因子明显更低。

### 0.18 μm 中可达到的噪声系数

- 目标：1.8 GHz 中心频率的窄带 LNA，0.18 μm CMOS，相关系数 $c = -j0.55$；
- 由 Hspice 得 NMOS（W = 1.8 μm、L = 0.18 μm）在 $V_{gs}$ = 1 V 时的 $g_m$、$g_{do}$ 和 $f_t$（$f_t$ ≈ 47.8 GHz）；
- 由曲线，$Q \approx 1.4$ 时噪声因子缩放系数 ≈ **3.25**。

### 最小 NF 且满足功率匹配的元件值

- 假设 $R_s$ = 50 Ω、Q = 1.4、$f_o$ = 1.8 GHz、$f_t$ = 47.8 GHz，按上面的式子算得 $C_{gs}$ ≈ 1.26 pF、$L_s$ ≈ 0.17 nH、$L_g$ ≈ 6.0 nH（笔者计算）。

## 12.3 偏置点选择

### $V_{gs}$ = 1 V 的偏置点好不好？

- 讲义给出 0.18 μm NMOS 的 $V_{gs}$、$g_m$、$g_{do}$ 随电流密度的曲线。
- 问题：**器件进入了速度饱和**；而且 IIP3 也是 Q 的函数。
- 计算偏置电流：由曲线读电流密度，再由 Hspice 仿真（假设 L = 0.18 μm）得 W，也可以基于 $C_{ox}$ 计算。

## 12.5 加入负载（谐振腔）

- 加输出负载以获得电压增益（实际中要用共源共栅管）；这里忽略 $C_{gd}$。
- 计算增益。
- **增益的设定**：
    - $g_m$ 和 Q 已由噪声系数和 IIP3 确定；
    - 注意 Q 是**输入匹配网络**的 Q，不是放大器的 Q；
    - $R_L$ 是自由参数，用它设定所需增益；
    - 给定谐振频率和电容负载时，$R_L$ 越大，$Q_L$（放大器输出谐振腔的 Q）越高；
    - 增益和放大器带宽之间有取舍。一般按接收机整体噪声和 IIP3 要求设 $R_L$（增益高对噪声有利），但增益太大会导致后级饱和。

## 12.6 封装寄生与版图

- **键合线（和封装）电感造成两个问题**：退化电感的值被改变；其他电路的噪声耦合进 LNA。
- **差分 LNA**：退化电感的值更容易控制；对其他电路噪声的敏感度低得多；代价是功耗是单端的两倍，而且需要芯片外的差分输入。
- **衬底接触要放足**：附近有大量衬底接触可以
    - 降低闩锁风险；
    - 降低 $R_{sub}$ 及其噪声；
    - 影响 LNA 的背栅效应（$g_{mb}$）；
    - 吸收其他电路的杂散电子；
    - 缺点：多占一点面积。

## 12.7 宽带 LNA 设计

- 大多数宽带系统对噪声的要求不如无线系统严格；常给**等效输入电压噪声**而不是噪声系数。
- 通常用一个电阻实现宽带匹配——第 12 讲的分析说明这会限制噪声系数。
- 在噪声系数重要的场合，有没有别的宽带匹配方式？

### 反馈电阻放大器

- 总输出噪声（假设 A 很大且无噪）和源电阻贡献的输出噪声；
- 输入阻抗（回顾米勒效应）：$Z_{in} \approx R_F/(1 + A)$；
- 若选择 $Z_{in}$ 匹配 $R_s$，则 $R_F = (1 + A)R_s$，反馈电阻可以比 $R_s$ **大得多**，它的噪声电流 $4kT/R_F$ 也就小得多。所以**把电阻放在反馈里，比直接用电阻端接的噪声系数低**（讲义给出了两者的对比）。
- **例：并联-串联放大器**：第 7 讲分析过；Lee 教材指出这种拓扑实际上用在**噪声系数测量系统**里（因为它很可能用了性能好得多的晶体管）。
